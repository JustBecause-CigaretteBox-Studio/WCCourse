第 1 小节

逻辑运算符：把多个条件串起来

and / or / not && / || / !

第五章之前，if 后面只放了一个条件。但真实代码里经常需要同时判断多个条件，例如「成绩大于 60 并且 出勤率大于 80」。这时就要用到逻辑运算符。

含义PythonC++
并且and&&
或者or||
取反not!

先看一个生活化的例子：判断一首歌能不能进播放列表。

logic_demo.py
score = 85      # 评分 0~100
 listened = True # 是否已经听过

 # 评分高并且没听过，就加入播放列表
 if score >= 80 and not listened:
     print("加入播放列表")
 else:
     print("跳过")

 # 只要评分极高或者已经听过且喜欢，就推荐给别人
 if score >= 95 or (listened and score >= 70):
     print("推荐给朋友")
logic_demo.cpp
#include <iostream>
using namespace std;

int main() {
    int score = 85;
    bool listened = true;

    if (score >= 80 && !listened) {
        cout << "加入播放列表" << endl;
    } else {
        cout << "跳过" << endl;
    }

    if (score >= 95 || (listened && score >= 70)) {
        cout << "推荐给朋友" << endl;
    }
    return 0;
}
⚡ 短路求值

逻辑运算符有一个省事的特性：如果前半句已经能决定结果，后半句就不会执行。例如 a > 0 and b / a > 2，如果 a > 0 不成立，Python 不会计算 b / a，所以不会报错。

组合条件的优先级

当一句话里同时出现 and / or / not（或 C++ 的 && / || / !）时，电脑会按固定顺序理解：

  1. not / ! 最先算；
  2. and / && 其次；
  3. or / || 最后。

例如 a > 0 and b > 0 or c > 0，电脑会先算两个 and，再算 or。如果你本来想表达「a 和 b 都大于 0，或者 c 大于 0」，这么写是对的；但如果你想表达「a 大于 0，并且（b 大于 0 或 c 大于 0）」，就必须写成 a > 0 and (b > 0 or c > 0)。

写组合条件时，善用括号 () 可以让优先级一目了然。记不住优先级的时候，直接加括号，永远是最安全的选择。

第 2 小节

三元表达式：一行写完 if / else

值 if 条件 else 另一个值 条件 ? 值 : 另一个值

有时候判断很简单，只是为了给变量选两个值中的一个。如果专门写四五行 if / else 就显得啰嗦。三元表达式就是用来解决这种场景的。

语言写法
Python值 if 条件 else 另一个值
C++条件 ? 值 : 另一个值

例如：根据分数是否及格，给出一个评价。

ternary.py
score = 72
result = "及格" if score >= 60 else "不及格"
print(result)

# 嵌套也可以，但 readability 会下降
grade = "A" if score >= 90 else "B" if score >= 80 else "C"
print(grade)
ternary.cpp
#include <iostream>
using namespace std;

int main() {
    int score = 72;
    string result = (score >= 60) ? "及格" : "不及格";
    cout << result << endl;

    // 不建议嵌套太多层
    string grade = (score >= 90) ? "A" : (score >= 80) ? "B" : "C";
    cout << grade << endl;
    return 0;
}
💡 使用建议
三元表达式适合「二选一」的简短判断。如果逻辑复杂，还是乖乖写 if / else，不要为了少写几行而牺牲可读性。
第 3 小节

位运算：直接操作 0 和 1

& / | / ^ / ~ / << / >>

前面学过，计算机里所有数据最终都是 0 和 1。位运算就是直接对这些二进制位进行操作，速度极快，常用于权限、开关、压缩等场景。

运算符名称含义
&按位与两位都为 1，结果才为 1
|按位或有一位为 1，结果就为 1
^按位异或两位不同，结果才为 1
~按位取反0 变 1，1 变 0
<<左移所有位向左移动，右侧补 0
>>右移所有位向右移动

最典型的例子是「权限开关」。假设一个用户有三个权限：读（001）、写（010）、执行（100），可以用一个数字同时表示。

bitflags.py
READ = 1    # 001
WRITE = 2   # 010
EXEC = 4    # 100

# 给一个用户同时赋予读和写权限
permission = READ | WRITE   # 011，即 3
print(permission)

# 检查是否有读权限
if permission & READ:
    print("可以读")

# 去掉写权限
permission = permission & ~WRITE
if not (permission & WRITE):
    print("写权限已关闭")

# 左移一位相当于乘 2
print(5 << 1)  # 10
print(5 >> 1)  # 2
bitflags.cpp
#include <iostream>
using namespace std;

int main() {
    int READ = 1, WRITE = 2, EXEC = 4;

    int permission = READ | WRITE;  // 011 = 3
    cout << permission << endl;

    if (permission & READ) {
        cout << "可以读" << endl;
    }

    permission = permission & ~WRITE;
    if (!(permission & WRITE)) {
        cout << "写权限已关闭" << endl;
    }

    cout << (5 << 1) << endl; // 10
    cout << (5 >> 1) << endl; // 2
    return 0;
}
🧠 位运算与逻辑运算的区别

&& 和 || 判断的是「真假」；& 和 | 是对二进制位逐位计算。大多数情况下写判断用 && / ||，只有需要对二进制位做文章时才用 & / |。

第 4 小节

列表切片与遍历技巧

in / zip / enumerate / [start:end] 数组下标与循环遍历

第二章学过用下标取数组元素，例如 arr[0]。但如果想取「第 2 到第 4 个元素」，或者想同时拿到「下标和值」，就要用到下面这些小技巧。

1. in 运算符：判断「在不在」

in 用来检查一个值是否在列表/字符串里，非常直观。

in_demo.py
fruits = ["苹果", "香蕉", "橙子"]
if "香蕉" in fruits:
    print("有香蕉")

if "瓜" not in "苹果":
    print("苹果里没有瓜")
in_demo.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "apple";
    // C++ 没有 in，但 string 有 find
    if (s.find("ban") == string::npos) {
        cout << "没找到 banana" << endl;
    }
    if (s.find("app") != string::npos) {
        cout << "找到了 app" << endl;
    }
    return 0;
}

2. 切片：一次取一段

Python 的切片写法是 列表[start:end]，C++ 可以用循环或标准库实现类似效果。

slice.py
nums = [10, 20, 30, 40, 50]
print(nums[1:4])   # [20, 30, 40]
print(nums[:3])    # [10, 20, 30]
print(nums[2:])    # [30, 40, 50]
print(nums[::2])   # [10, 30, 50]，每隔一个取一个
slice.cpp
#include <iostream>
using namespace std;

int main() {
    int nums[] = {10, 20, 30, 40, 50};
    // 手动取 1~3（包含 1，不包含 4）
    for (int i = 1; i < 4; i++) {
        cout << nums[i] << " ";
    }
    cout << endl;
    return 0;
}

3. enumerate 与 zip：同时拿多个信息

enumerate 让你在遍历列表时同时拿到下标和值；zip 可以把两个列表「拉链」到一起同时遍历。

loop_tricks.py
names = ["Alice", "Bob", "Carol"]
scores = [85, 92, 78]

# 同时拿下标和值
for i, name in enumerate(names):
    print(i, name)

# 同时遍历两个列表
for name, score in zip(names, scores):
    print(name, score)
loop_tricks.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string names[] = {"Alice", "Bob", "Carol"};
    int scores[] = {85, 92, 78};
    int n = 3;

    for (int i = 0; i < n; i++) {
        cout << i << " " << names[i] << endl;
    }

    for (int i = 0; i < n; i++) {
        cout << names[i] << " " << scores[i] << endl;
    }
    return 0;
}
第 5 小节

字符串格式化：让输出更漂亮

f-string 与 % 格式化 printf 格式化

第一章用 print 输出变量时，经常要把字符串和变量拼在一起。如果变量很多，用加号拼接会又臭又长。格式化字符串可以让输出更清晰。

1. Python：f-string（推荐）

在字符串前面加一个 f，就可以在大括号 {} 里直接放变量或表达式。

fstring.py
name = "小圆"
score = 92.5

print(f"{name} 考了 {score} 分")
print(f"{name} 的两倍分数是 {score * 2:.1f}")  # .1f 表示保留 1 位小数

# 对齐也很好用
for i in range(1, 4):
    print(f"第 {i:2d} 名")

2. C++：多种方式

C++ 传统上可以用 << 拼接，也可以用 printf 格式化。现代 C++20 还有 std::format，但这里先介绍最通用的 printf。

printf.cpp
#include <cstdio>
using namespace std;

int main() {
    char name[] = "小圆";
    double score = 92.5;

    printf("%s 考了 %.1f 分\n", name, score);
    printf("%s 的两倍分数是 %.1f\n", name, score * 2);

    for (int i = 1; i <= 3; i++) {
        printf("第 %2d 名\n", i);
    }
    return 0;
}
格式符含义
%d整数
%f浮点数
%.2f保留两位小数
%s字符串
%c单个字符
第 6 小节

文件读写：让数据离开内存

open / with fstream

前面程序的数据都只在运行时存在，程序一关就消失了。想让数据永久保存，就要读写文件。文件就像硬盘上的一张纸，程序可以往上面写，也可以从上面读。

file_io.py
# 写文件：with 会自动关闭文件
with open("note.txt", "w", encoding="utf-8") as f:
    f.write("hello, file!\n")
    f.write("第二行\n")

# 读文件
with open("note.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

# 逐行读
with open("note.txt", "r", encoding="utf-8") as f:
    for line in f:
        print("行：", line.strip())
file_io.cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    // 写文件
    ofstream out("note.txt");
    out << "hello, file!" << endl;
    out << "第二行" << endl;
    out.close();

    // 读文件
    ifstream in("note.txt");
    string line;
    while (getline(in, line)) {
        cout << "行：" << line << endl;
    }
    in.close();
    return 0;
}
💡 模式说明
"r" / ifstream 表示读；"w" / ofstream 表示写（会覆盖原文件）；"a" 表示追加（在后面接着写）。
第 7 小节

综合实战：学生成绩小工具

把这一章的语法串起来用一次

现在把前面学的语法拼成一个完整的小程序：读取一组学生成绩，判断每个学生的等级，把结果格式化后写进文件。

grade_tool.py
names = ["Alice", "Bob", "Carol", "David"]
scores = [92, 58, 77, 85]

with open("grades.txt", "w", encoding="utf-8") as f:
    for i, (name, score) in enumerate(zip(names, scores)):
        level = "A" if score >= 90 else "B" if score >= 80 else "C" if score >= 60 else "D"
        pass_text = "通过" if score >= 60 else "未通过"
        line = f"{i+1}. {name:8s} {score:3d}分 等级{level} {pass_text}\n"
        f.write(line)

print("成绩已写入 grades.txt")
grade_tool.cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    string names[] = {"Alice", "Bob", "Carol", "David"};
    int scores[] = {92, 58, 77, 85};
    int n = 4;

    ofstream out("grades.txt");
    for (int i = 0; i < n; i++) {
        char level;
        if (scores[i] >= 90) level = 'A';
        else if (scores[i] >= 80) level = 'B';
        else if (scores[i] >= 60) level = 'C';
        else level = 'D';

        string pass_text = (scores[i] >= 60) ? "通过" : "未通过";
        out << (i + 1) << ". " << names[i]
            << " " << scores[i] << "分 等级" << level
            << " " << pass_text << endl;
    }
    out.close();

    cout << "成绩已写入 grades.txt" << endl;
    return 0;
}
