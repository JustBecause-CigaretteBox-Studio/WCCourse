📦 使用说明

  • Windows：下载 .exe 文件后双击直接运行，无需安装，学习进度自动保存在本地。
  • macOS：下载 .tar.gz 后解压，将应用拖入「应用程序」文件夹即可使用。
  • 课程支持深色模式、C++ / Python 双语切换、章节打卡与进度保存。
  • 如果遇到问题，请前往 GitHub Issues 反馈。
