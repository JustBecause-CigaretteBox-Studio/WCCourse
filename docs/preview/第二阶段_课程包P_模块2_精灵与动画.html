第 1 小节

什么是精灵

在游戏里，角色、敌人、子弹、金币这些「能动的东西」通常都叫精灵（Sprite）。你可以把精灵理解成皮影戏里的小人：它有一张图（表面），还有一个控制位置的框。

Pygame 里最简单的精灵就是一个 Surface（图像表面）加上一个 Rect（矩形位置框）。

sprite.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

# 创建一个 50×50 的红色方块作为精灵图像
image = pygame.Surface((50, 50))
image.fill((255, 80, 80))

# Rect 控制精灵的位置
rect = image.get_rect()
rect.center = (400, 300)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((30, 30, 30))
    screen.blit(image, rect)       # 把精灵画到屏幕上
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

get_rect() 会自动生成和图像一样大的矩形，并且可以通过 rect.center、rect.x 等方式快速定位。

第 2 小节

让精灵动起来

动画的本质和翻页小画册一样：连续显示略有不同的画面，人眼就觉得它在动。在游戏中，我们只需要每帧稍微改变精灵的位置或图像。

下面这个例子让精灵每帧向右移动，超出右边界后回到左边：

move.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

image = pygame.Surface((50, 50))
image.fill((80, 200, 255))
rect = image.get_rect()
rect.center = (0, 300)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    rect.x += 3
    if rect.left > 800:
        rect.right = 0           # 从左侧重新进入

    screen.fill((20, 20, 20))
    screen.blit(image, rect)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

如果把 rect.x += 3 改成 rect.x += 1，精灵就会移动得更慢；改成 rect.y += 3，它就会向下移动。

等等——为什么 y 变大是「向下」？

这儿有个新手最容易踩的坑：游戏里的坐标系，和数学课上的坐标系是反的。

两种坐标系对比

为什么屏幕要反着来？因为屏幕是从上往下一行一行画出来的—— 从早期的 CRT 显示器到今天的液晶屏，像素都是先画第一行、再画第二行。 所以这里的「y」本质上就是行号：第 1 行在最上面，行号越大越往下，和看书、看文章一模一样。

记住这三条，就不会搞混：

  • x 轴和数学一样：向右为正，rect.x += 3 是向右移。
  • y 轴和数学相反：向下为正，rect.y += 3 是向下移。
  • 想让角色往上跳，y 要减小：rect.y -= 5。

顺便记一下 800×600 屏幕上的几个关键位置：左上角是 (0, 0)，右下角是 (800, 600)，正中间是 (400, 300)。 所以前面那句 rect.center = (400, 300)，意思就是「把精灵放到屏幕正中央」。

但是在实际开发中，通常会写WORLD_WIDTH = 800，其他数据和函数同理，这样更方便修改和适配不同比例的屏幕

第 3 小节

碰撞箱

游戏要知道「两个东西有没有碰到」，但直接用图像像素判断太麻烦。所以每个精灵都会带一个碰撞箱，通常就是一个矩形 Rect，通过检测碰撞箱的接触来判断碰撞。

hitbox.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

player = pygame.Surface((50, 50))
player.fill((0, 200, 255))
player_rect = player.get_rect()
player_rect.center = (400, 300)

coin = pygame.Surface((30, 30))
coin.fill((255, 220, 0))
coin_rect = coin.get_rect()
coin_rect.center = (600, 300)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  player_rect.x -= 4
    if keys[pygame.K_RIGHT]: player_rect.x += 4
    if keys[pygame.K_UP]:    player_rect.y -= 4
    if keys[pygame.K_DOWN]:  player_rect.y += 4

    if player_rect.colliderect(coin_rect):
        coin_rect.center = (-100, -100)   # 碰到后把金币移出画面

    screen.fill((30, 30, 30))
    screen.blit(player, player_rect)
    screen.blit(coin, coin_rect)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

colliderect() 会判断两个矩形是否重叠，返回 True 或 False。这是游戏里最常用的碰撞检测方式之一。

第 4 小节

综合实战：控制小人走动

把精灵、移动和碰撞箱结合起来，做一个可以用方向键控制的小人。为了看得更清楚，我们再画一个目标物，碰到后目标物会变色。

walk.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

hero = pygame.Surface((50, 50))
hero.fill((0, 200, 255))
hero_rect = hero.get_rect()
hero_rect.center = (400, 300)

target = pygame.Surface((60, 60))
target.fill((255, 100, 100))
target_rect = target.get_rect()
target_rect.center = (600, 300)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  hero_rect.x -= 5
    if keys[pygame.K_RIGHT]: hero_rect.x += 5
    if keys[pygame.K_UP]:    hero_rect.y -= 5
    if keys[pygame.K_DOWN]:  hero_rect.y += 5

    if hero_rect.colliderect(target_rect):
        target.fill((150, 255, 150))    # 碰到后变绿色

    screen.fill((25, 25, 25))
    screen.blit(hero, hero_rect)
    screen.blit(target, target_rect)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

练习：给小人增加边界限制，让它不能跑出窗口；或者添加多个目标物，用列表来管理它们。
