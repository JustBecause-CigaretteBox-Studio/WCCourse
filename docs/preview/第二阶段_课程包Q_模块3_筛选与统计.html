第 1 小节

筛选数据：按条件取子集

用布尔索引找到想要的数据

Excel 里筛选数据要点很多下鼠标：点筛选、勾选条件、看结果。Pandas 里只需要一句话。核心思路是：先写出一个「判断条件」，再用这个条件去框选整行。

比如 df["成绩"] >= 90 会返回一列 True/False。把这一列放回 df[...] 里，Pandas 就会只保留为 True 的行。这种写法叫「布尔索引」，是筛选的灵魂。

filter_basic.py
import pandas as pd

df = pd.DataFrame({
    "姓名": ["阿明", "小红", "小刚", "小丽"],
    "班级": ["A班", "B班", "A班", "B班"],
    "成绩": [85, 92, 78, 88]
})

# 筛选成绩 >= 90 的同学
excellent = df[df["成绩"] >= 90]
print(excellent)

# 筛选 A 班同学
class_a = df[df["班级"] == "A班"]
print(class_a)

多条件组合也很自然：& 表示「且」，| 表示「或」。注意每个条件要加括号，因为 & 和 | 的优先级比 == 高，不加括号会报错。

filter_multi.py
# A 班且成绩 >= 80 的同学
result = df[(df["班级"] == "A班") & (df["成绩"] >= 80)]
print(result)

学会筛选之后，很多原本需要手动翻找的操作都能自动化。下一节我们学习如何对筛选后的结果做统计。

第 2 小节

聚合统计：比透视表更直观

分组、求和、求平均、计数

Excel 的透视表能把数据按某个字段分组，然后求和或求平均。Pandas 的 groupby() 就是做这件事的，而且写起来更短、更易复用。

基本流程是：按哪一列分组 → 对哪一列做什么统计。例如 df.groupby("班级")["成绩"].mean() 就是「按班级分组，求各班平均成绩」。

groupby_demo.py
import pandas as pd

df = pd.DataFrame({
    "姓名": ["阿明", "小红", "小刚", "小丽", "小军"],
    "班级": ["A班", "B班", "A班", "B班", "A班"],
    "成绩": [85, 92, 78, 88, 95]
})

# 各班平均成绩
avg_by_class = df.groupby("班级")["成绩"].mean()
print(avg_by_class)

# 各班人数
print(df.groupby("班级").size())

除了 .mean() 和 .size()，常用的聚合方法还有 .sum()、.max()、.min()、.count()。你甚至可以用 .agg() 一次算多种统计。

agg_demo.py
# 同时算每个班的最高分、最低分和平均分
summary = df.groupby("班级")["成绩"].agg(["max", "min", "mean"])
print(summary)

到这里，你已经能完成 Excel 透视表 90% 的功能。下一节把筛选和聚合串起来，做一个实用的小工具。

第 3 小节

动手：电商商品分析

筛选热销品类并统计销售额

假设你经营一家小网店，有一批订单记录。你想知道：哪些品类总销售额最高？单价超过 100 的商品平均卖了多少件？用筛选 + 聚合，几行代码就能回答。

sales_analysis.py
import pandas as pd

df = pd.read_csv("sales.csv")

# 1. 先计算销售额
df["销售额"] = df["单价"] * df["销量"]

# 2. 按品类汇总
revenue = df.groupby("品类")["销售额"].sum().reset_index()
print("各品类销售额：")
print(revenue.sort_values("销售额", ascending=False))

# 3. 筛选单价 > 100 的商品，再算平均销量
expensive = df[df["单价"] > 100]
print("\n单价 > 100 的商品平均销量：", expensive["销量"].mean())

这里出现了两个新朋友：sort_values() 用于排序，reset_index() 用于把分组结果重新变成普通 DataFrame。它们都是数据分析的常用工具，慢慢会熟悉的。

第 4 小节

综合实战：班级成绩排名与分班统计

筛选、聚合、排序一次搞定

班主任给你一份全年级成绩表，要求你做三件事：按班级统计平均分和最高分、找出年级前 3 名、列出所有有不及格科目的学生。用 Pandas 可以一次性完成。

grade_analysis.py
import pandas as pd

df = pd.DataFrame({
    "姓名": ["阿明", "小红", "小刚", "小丽", "小军", "小芳"],
    "班级": ["A班", "A班", "B班", "B班", "A班", "B班"],
    "语文": [85, 92, 58, 76, 88, 95],
    "数学": [90, 88, 62, 95, 70, 85],
    "英语": [78, 95, 70, 82, 65, 90]
})

# 1. 计算总分
df["总分"] = df["语文"] + df["数学"] + df["英语"]

# 2. 按班级统计
print("=== 各班统计 ===")
print(df.groupby("班级")[["语文", "数学", "英语", "总分"]].agg(["mean", "max"]))

# 3. 年级前 3 名
print("\n=== 年级前 3 名 ===")
print(df.sort_values("总分", ascending=False)[["姓名", "班级", "总分"]].head(3))

# 4. 有不及格科目的学生
print("\n=== 需补考 ===")
failed = df[(df["语文"] < 60) | (df["数学"] < 60) | (df["英语"] < 60)]
print(failed[["姓名", "班级", "语文", "数学", "英语"]])

这个项目把模块 1、2、3 的核心技能串在了一起：创建 DataFrame、列运算、分组聚合、筛选、排序。下一次，我们会把这些冰冷的数字变成直观的图表。

进阶挑战：在每个班里分别排出前 2 名。提示：用 df.groupby("班级").apply(...) 或 df.sort_values(...).groupby("班级").head(2)。
