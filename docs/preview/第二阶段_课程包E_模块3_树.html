第 1 小节

认识树

像家谱一样的分层数据

树是一种分层结构：最上面有一个根节点，根下面分出若干子节点，子节点下面又可有子节点。它很像家谱——爷爷奶奶在根，父母是孩子，你又是父母的孩子。

计算机里的文件夹、HTML 标签的嵌套关系、组织架构图，都可以用树来表示。树中的节点之间没有环，任意两个节点之间只有一条路径。

最常用的一种树是二叉树：每个节点最多只有两个子节点，分别叫左孩子和右孩子。

图：一棵简单的二叉树（A 是根节点；B、C 是 A 的左右孩子；D、E 是 B 的左右孩子）
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

# 手动搭建一棵简单二叉树
root = TreeNode("A")
root.left = TreeNode("B")
root.right = TreeNode("C")
root.left.left = TreeNode("D")
root.left.right = TreeNode("E")
struct TreeNode {
    char value;
    TreeNode* left;
    TreeNode* right;
    TreeNode(char v) : value(v), left(nullptr), right(nullptr) {}
};

第 2 小节

二叉树的三种遍历

前序、中序、后序

遍历树就是按某种顺序访问所有节点。二叉树最常见的三种遍历方式取决于「什么时候访问根节点」：

  • 前序遍历：根 → 左子树 → 右子树
  • 中序遍历：左子树 → 根 → 右子树
  • 后序遍历：左子树 → 右子树 → 根

如果把二叉搜索树按中序遍历，得到的结果会是有序的，这是二叉树很实用的性质。

def preorder(node):     # 前序
    if node:
        print(node.value, end=' ')
        preorder(node.left)
        preorder(node.right)

def inorder(node):      # 中序
    if node:
        inorder(node.left)
        print(node.value, end=' ')
        inorder(node.right)

def postorder(node):    # 后序
    if node:
        postorder(node.left)
        postorder(node.right)
        print(node.value, end=' ')

preorder(root)   # A B D E C

void preorder(TreeNode* node) {     // 前序
    if (node) {
        cout << node->value << " ";
        preorder(node->left);
        preorder(node->right);
    }
}

void inorder(TreeNode* node) {      // 中序
    if (node) {
        inorder(node->left);
        cout << node->value << " ";
        inorder(node->right);
    }
}

void postorder(TreeNode* node) {    // 后序
    if (node) {
        postorder(node->left);
        postorder(node->right);
        cout << node->value << " ";
    }
}

第 3 小节

递归与树

树是天然的递归结构

树的定义本身就是递归的：一棵树的子树还是树。所以处理树的问题时，递归通常是最直观的写法。

比如想求一棵二叉树的高度，可以这样想：如果树为空，高度是 0；否则高度等于左右子树中较高的那个加 1。

def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))

print(height(root))   # 上面那棵树的高度是 3
tree_height.cpp
int height(TreeNode* node) {
    if (node == nullptr) return 0;
    return 1 + max(height(node->left), height(node->right));
}

cout << height(root);   // 上面那棵树的高度是 3
第 4 小节

综合实战：统计叶子节点

没有孩子的节点有多少个

叶子节点是指没有左孩子也没有右孩子的节点，就像家谱里最小的一代。统计叶子节点可以帮我们理解递归在树上的应用。

思路：如果当前节点为空，返回 0；如果当前节点没有左右孩子，返回 1；否则返回左右子树叶子节点数之和。

def count_leaves(node):
    if node is None:
        return 0
    if node.left is None and node.right is None:
        return 1
    return count_leaves(node.left) + count_leaves(node.right)

print("叶子节点数：", count_leaves(root))   # 3
count_leaves.cpp
int countLeaves(TreeNode* node) {
    if (node == nullptr) return 0;
    if (node->left == nullptr && node->right == nullptr) return 1;
    return countLeaves(node->left) + countLeaves(node->right);
}

cout << "叶子节点数：" << countLeaves(root);   // 3
