第 1 小节

打开浏览器的「X 光眼镜」

前面五节都是从「写程序」的角度理解网络。这节课换个视角：用浏览器自带的开发者工具（DevTools），观察一次真实的网络请求长什么样。几乎所有现代浏览器（Chrome、Edge、Firefox、Safari）都有这个功能。

打开方式很简单：

1. 在网页空白处点击右键，选择「检查」或「审查元素」。

2. 找到顶部菜单里的 Network（网络） 标签。

3. 刷新页面，你会看到一长串请求列表。

💡 Network 面板是什么？

它是浏览器的「交通监控中心」。所有进出浏览器的数据包请求都会在这里显示：请求的地址、方法、状态码、耗时、大小、类型，一应俱全。

列表里常见的类型有：

document
最开始的 HTML 页面本身，通常只有一条。
xhr / fetch
JavaScript 向服务器请求的数据，很多动态内容都在这里。
script / stylesheet
网页引用的 JS 文件和 CSS 样式文件。
image / media
图片、视频、音频等资源。

本节没有 Python 代码，但你可以立刻动手：打开任意一个网站，按 F12 进 Network 面板，刷新页面，数数一共发了多少个请求。

第 2 小节

解剖一次请求：Headers 与 Timing

在 Network 面板里点击任意一条请求，右侧会展开详情。重点关注几个区域：

1. General（概览）：请求 URL、方法、状态码、远程地址、Referrer Policy 等。

2. Request Headers（请求头）：浏览器发给服务器的信息，比如 User-Agent（浏览器身份）、Accept（能接受什么格式）、Cookie（身份凭证）。

3. Response Headers（响应头）：服务器返回的信息，比如 Content-Type、Content-Length、Set-Cookie。

4. Timing（时间）：请求各阶段耗时，包括 DNS 查询、建立连接、发送、等待响应、接收数据。

这些信息对调试网络问题非常有用。比如网页加载慢，可能是某个图片请求耗时太长；某个接口返回 500，可以直接定位到具体的请求。

⚠️ 小技巧

如果请求列表太多，可以用类型过滤器（XHR、JS、CSS、Img 等）只看某一类；也可以在请求上右键选择「Copy as cURL」，把请求复制成命令行格式。

下面这段 Python 代码演示了如何在程序里模拟浏览器请求头。有些网站会拒绝没有 User-Agent 的请求，所以伪装成浏览器是常见做法：

fake_browser.py
from urllib.request import Request, urlopen

url = "https://www.example.com"
req = Request(url, headers={
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 Chrome/115.0 Safari/537.36"
})

with urlopen(req, timeout=5) as resp:
    print("状态码：", resp.status)
    print("响应头：")
    for key, value in resp.headers.items():
        print(f"  {key}: {value}")
第 3 小节

看响应：预览、原始数据与 JSON

请求发出去，服务器会返回响应。在 DevTools 里，响应通常有这几个视图：

1. Preview（预览）：浏览器把 HTML/JSON/图片渲染后的样子。

2. Response（响应）：服务器返回的原始文本。

3. Timing（时间）：各阶段耗时。

如果响应类型是 application/json，Response 视图会显示格式化的 JSON，Preview 视图会显示成可折叠的树形结构。很多现代网站（微博、B 站、天气网站）的动态数据都是通过这种方式返回的。

我们也可以用 Python 抓取这些 JSON 响应，然后用 json 模块解析。下面这个例子访问一个测试 API，并把响应完整地打印出来：

inspect_response.py
from urllib.request import Request, urlopen
import json

url = "https://httpbin.org/get"
req = Request(url, headers={
    "User-Agent": "Mozilla/5.0",
    "Accept": "application/json"
})

try:
    with urlopen(req, timeout=5) as resp:
        print(f"状态码：{resp.status}")
        print(f"Content-Type：{resp.headers.get('Content-Type')}\n")
        body = resp.read().decode("utf-8")
        data = json.loads(body)
        print("响应 JSON：")
        print(json.dumps(data, indent=2, ensure_ascii=False))
except Exception as e:
    print(f"请求失败：{e}")

运行后你会发现，httpbin.org/get 返回的 JSON 里包含了你发送的请求头信息。这正好验证了「请求头也会作为数据的一部分返回给你」。

第 4 小节

综合实战：抓一次自己的请求

用 DevTools 观察并用 Python 复现它

现在把本模块和前面模块的知识串起来，完成一次完整的「观察 + 复现」实战。

任务步骤：

  1. 打开 Chrome/Edge，访问 https://www.example.com。
  2. 按 F12，切换到 Network 面板，刷新页面。
  3. 点击第一个 document 类型的请求。
  4. 记录：请求方法、URL、状态码、Remote Address、Content-Type。
  5. 切换到 Response 标签，查看服务器返回的 HTML 前 200 字符。
  6. 用下面的 Python 代码复现这个请求，对比状态码和返回内容。
replay_request.py
from urllib.request import urlopen

url = "https://www.example.com"
with urlopen(url, timeout=5) as resp:
    print(f"方法：GET")
    print(f"URL：{resp.url}")
    print(f"状态码：{resp.status}")
    print(f"Content-Type：{resp.headers.get('Content-Type')}")
    print(f"\n返回内容前 200 字符：")
    print(resp.read(200).decode("utf-8"))

如果你想挑战进阶版，可以尝试：

1. 找一个有搜索框的网站，输入关键词后观察 Network 面板里多出来的 XHR/Fetch 请求。

2. 记录下它的 URL 和参数。

3. 用 Python 的 urllib 直接请求那个 URL，看看能不能拿到 JSON 数据。

⚠️ 提醒

练习时请遵守网站的 robots 协议和使用条款，不要高频爬取或抓取私人数据。学习网络请求的目的是理解原理，而不是给别人的服务器添麻烦。

🔑 模块 6 小结

浏览器开发者工具是观察网络请求的「X 光眼镜」。通过 Network 面板可以看到请求的完整生命周期：方法、URL、请求头、响应头、状态码、响应体和耗时。学会用它，你就能从「只会写代码」进化到「会调试真实网络问题」。
