栈与括号匹配

后进先出的妙用

什么是括号匹配问题？ 给你一个只由括号组成的字符串，比如 ({[]}) 或 (a+b)*[c/d] 里抽出来的括号部分，要判断它们「配不配对」：每一个左括号 ( [ { 都要有一个同类型的右括号 ) ] } 与之对应，而且必须是「先开的后闭」——就像剥洋葱，最后套上去的那层要先剥掉。

合法的例子：({[]}) —— 开 (、开 {、开 [，然后闭 ] 配 [、闭 } 配 {、闭 ) 配 (，层层抵消。非法的例子：(] —— 开了 ( 却用 ] 来闭，类型不对；(( —— 开了两个却一个都没闭；()) —— 第一个 ) 闭掉之后，又多出一个 ) 没有左括号可配。

为什么用栈？ 括号「最后打开、最先闭合」的顺序，正好就是栈「后进先出（LIFO）」的特点。所以我们用一个栈来记住「当前还没被闭合的左括号」：

  • 从左到右扫描每个字符；
  • 遇到左括号，把它压入栈顶（记下「我现在在等它的右半边」）；
  • 遇到右括号，先看栈是不是空的——空说明没有左括号可配，直接判非法；不空就弹出栈顶，检查它和这个右括号是不是「一家人」（( 配 ) 等），不是就非法；
  • 扫完所有字符后，栈必须是空的才算合法（所有左括号都被闭合了）。

拿 ({[]}) 走一遍：压入 ( → 压入 { → 压入 [ → 遇 ] 弹出 [ 配对成功 → 遇 } 弹出 { 成功 → 遇 ) 弹出 ( 成功 → 栈空，合法。整个过程栈里始终装着「还没闭合的左括号」，非常直观。

def is_valid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in ')]}':
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
    return len(stack) == 0

print(is_valid("({[]})"))   # True
print(is_valid("(]"))       # False
bracket_match.cpp
bool isValid(string s) {
    stack<char> st;
    for (char ch : s) {
        if (ch == '(' || ch == '[' || ch == '{') st.push(ch);
        else {
            if (st.empty()) return false;
            char top = st.top();
            if ((ch == ')' && top != '(') ||
                (ch == ']' && top != '[') ||
                (ch == '}' && top != '{')) return false;
            st.pop();
        }
    }
    return st.empty();
}
第 2 小节

队列与任务调度

先来先服务

队列（Queue）是「先进先出」的结构：先进入队列的元素先被处理，就像排队买票，先到的人先服务。

在程序里，队列常用于任务调度：打印机依次处理打印任务、CPU 调度进程、网络请求排队等。队列的特点是只能从一端加入、从另一端取出，所以「先到先得」，不会出现后来者插队的情况。

from collections import deque

queue = deque()
queue.append("打印报告")
queue.append("下载文件")
queue.append("发送邮件")

while queue:
    task = queue.popleft()   # 从左端取出，保证先进先出
    print("处理任务：", task)
queue_task.cpp
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> q;
    q.push("打印报告");
    q.push("下载文件");
    q.push("发送邮件");

    while (!q.empty()) {
        cout << "处理任务：" << q.front() << endl;
        q.pop();
    }
    return 0;
}
第 3 小节

BFS 与队列

一层一层往外探索

广度优先搜索（BFS）常借助队列实现。思路是：从起点出发，先把起点的所有邻居入队；处理完这一层后，再把下一层邻居入队。这样能保证离起点越近的节点越先被访问。

例如在一个迷宫里找最短路径，BFS 每次向四个方向扩展，第一次到达终点时走的步数就是最少步数。

图：BFS 从起点 A 出发，按「层」向外扩展（颜色越深，离起点越远）

看图：BFS 先把起点 A 的所有邻居（B、C）入队，再处理 B、C 的邻居（D、E），最后到 F。同一层的节点一定比下一层更早被访问——所以第一次碰到终点时，走的一定是最短路径。队列在这里的作用，就是保证「先入队的先处理」，从而严格地一层一层往外推。

from collections import deque

# graph: 邻接表表示的简单图
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C']
}

def bfs(start):
    visited = set([start])
    queue = deque([start])
    while queue:
        node = queue.popleft()
        print(node, end=' ')
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

bfs('A')   # 输出类似 A B C D
bfs.cpp
#include <queue>
#include <set>
#include <iostream>
#include <map>
#include <vector>
using namespace std;

map<char, vector<char>> graph = {
    {'A', {'B', 'C'}},
    {'B', {'A', 'D'}},
    {'C', {'A', 'D'}},
    {'D', {'B', 'C'}}
};

void bfs(char start) {
    set<char> visited;
    queue<char> q;
    visited.insert(start);
    q.push(start);
    while (!q.empty()) {
        char node = q.front();
        q.pop();
        cout << node << " ";
        for (char neighbor : graph[node]) {
            if (!visited.count(neighbor)) {
                visited.insert(neighbor);
                q.push(neighbor);
            }
        }
    }
}

int main() {
    bfs('A');   // 输出类似 A B C D
    return 0;
}
第 4 小节

综合实战：判断回文字符串

用栈辅助验证正读反读相同

回文字符串是指正着读和反着读一样的字符串，比如 level、abcba。利用栈的「后进先出」特性，可以轻松把字符串后半段反转，再与前半段比较。

更简单的做法是：遍历字符串，把每个字符压入栈，然后依次弹出，弹出的顺序就是原字符串的逆序。如果和原字符串相同，就是回文。

def is_palindrome(s):
    stack = []
    for ch in s:
        stack.append(ch)
    reversed_s = ""
    while stack:
        reversed_s += stack.pop()
    return s == reversed_s

print(is_palindrome("level"))   # True
print(is_palindrome("hello"))   # False
palindrome.cpp
bool isPalindrome(string s) {
    stack<char> st;
    for (char ch : s) st.push(ch);
    string rev;
    while (!st.empty()) {
        rev += st.top();
        st.pop();
    }
    return s == rev;
}

练习：尝试用队列实现同样的功能，观察栈和队列在「反转」这件事上的不同表现。
