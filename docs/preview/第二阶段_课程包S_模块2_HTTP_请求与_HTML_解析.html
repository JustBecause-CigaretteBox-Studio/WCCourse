第 1 小节

HTTP：浏览器和服务器之间的对话

请求与响应，像点外卖一样简单

当你在浏览器地址栏输入 example.com 并按下回车，浏览器会向服务器发送一条请求（Request）：「你好，请把 example.com 这个网页发给我。」服务器收到后，会返回一条响应（Response）：「好的，这是 HTML 内容。」

这个过程很像点外卖：你是顾客（客户端），饭店是服务器。你下单（GET 请求），饭店出餐（返回网页）。HTTP 就是这套「点餐语言」的规则。

请求有几种常见「动作」：

  • GET：获取资源，最常用。
  • POST：提交数据，例如登录、发表评论。
  • PUT / DELETE：更新或删除资源，爬虫用得较少。

服务器返回的响应里，有一个状态码，告诉你结果如何。例如：

  • 200：成功。
  • 404：页面不存在。
  • 500：服务器内部出错。
  • 403：禁止访问，常见于反爬。
🔑 本小节小结

爬虫模拟浏览器发送 HTTP 请求，读取服务器返回的响应，再从中提取数据。理解请求、响应、状态码，是调试爬虫的第一步。

第 2 小节

用 requests 获取网页

Python 里最方便的 HTTP 库

requests 是 Python 中处理 HTTP 请求的明星库，语法简洁，适合新手。如果你还没安装，可以先运行：

终端命令
pip install requests

安装好后，用下面三行代码就能拿到一个网页的 HTML：

fetch_page.py
import requests

url = "https://example.com"
resp = requests.get(url)           # 发送 GET 请求
print(resp.status_code)            # 200 表示成功
print(len(resp.text))              # 返回的 HTML 长度

resp.text 是服务器返回的字符串形式的 HTML。如果状态码不是 200，说明请求出了问题，可以先检查网址、网络连接，以及是否被反爬。

⚠️ 注意

本课程示例中的 example.com 是一个专门用于测试的网站。练习时请使用允许抓取的公开站点，或只解析本地保存的 HTML 文件。

如果想把网页存到本地慢慢研究，可以这样做：

save_html.py
import requests

url = "https://example.com"
resp = requests.get(url)

with open("example.html", "w", encoding="utf-8") as f:
    f.write(resp.text)

print("已保存，大小：", len(resp.text), "字符")
第 3 小节

HTML 结构初探

网页其实是一棵标签树

服务器返回的 HTML，本质上是纯文本。它由一堆标签嵌套组成，比如 <html>、<body>、<p>、<a>、<div>。爬虫要做的，就是在这棵标签树中找到我们需要的节点。

看一段简单的 HTML：

sample.html
<html>
  <head>
    <title>示例页面</title>
  </head>
  <body>
    <h1>欢迎</h1>
    <p>这是一个示例页面。</p>
    <a href="https://example.com/about">关于我们</a>
  </body>
</html>

在这段 HTML 中：

  • <title> 里的是网页标题。
  • <h1> 是主标题。
  • <p> 是段落。
  • <a href="..."> 是链接，href 是链接地址。

下一模块会学习用 BeautifulSoup 精准提取这些内容。在本模块，先练习用 requests 把页面拿到手，并打印出它的前 500 个字符，确认内容正确。

peek_html.py
import requests

url = "https://example.com"
resp = requests.get(url)
print(resp.text[:500])   # 只看前 500 个字符
第 4 小节

综合实战

抓取页面并检查状态码与标题

把本模块内容串起来，写一个小程序：请求一个网页，检查状态码，再打印网页标题和 HTML 长度。这里我们用 requests 自带的方式提取 <title>（先用字符串查找，下一模块再学更优雅的方法）。

mini_project.py
import requests

url = "https://example.com"
resp = requests.get(url)

print("状态码：", resp.status_code)
print("内容长度：", len(resp.text))

# 用字符串方法粗略提取 title
start = resp.text.find("<title>")
end = resp.text.find("</title>")
if start != -1 and end != -1:
    title = resp.text[start + 7:end]
    print("网页标题：", title)
else:
    print("未找到标题")

练习任务：把 url 换成其他允许抓取的公开网站，观察不同网站返回的状态码和 HTML 长度。注意：第一次请求新网站前，务必先查看它的 robots.txt。

✅ HTTP 是客户端与服务器的对话协议。

✅ requests.get() 可以获取网页内容。

✅ 状态码告诉我们请求是否成功。

✅ HTML 是标签树，后续将用 BeautifulSoup 解析。
