第 1 小节

Python：从圣诞假期里诞生的语言

Python 诞生于 1991 年，作者是荷兰程序员 Guido van Rossum。传说他在圣诞假期里为了打发时间，设计了一门新语言，并借了自己喜欢的英国喜剧团体 Monty Python 之名，取名为 Python。

Python 的设计哲学强调可读性和简洁性。它用缩进来表示代码块，而不是 C 风格的大括号；它内置了列表、字典等高级数据结构，让日常任务可以用很少代码完成。

这些设计让它迅速流行，如今被广泛用于：数据分析、人工智能、自动化脚本、Web 后端、科学计算、教育入门等领域。可以说 Python 是程序员口袋里的一把瑞士军刀。

Python
print("Hello, Python!")
C++
#include <iostream>

int main() {
    std::cout << "Hello, C++!" << std::endl;
    return 0;
}

仅这一行就能在屏幕上输出文字，不需要写 main 函数、不需要声明类型、不需要手动编译。Python 把一切非必要的仪式都去掉了。

第 2 小节

胶水语言：把不同世界粘在一起

Python 常被称为“胶水语言”，因为它最擅长的不是从零造轮子，而是把别人造好的轮子拼成一辆新车。它可以调用 C/C++ 写的高性能库，可以操作 Excel、数据库、网络接口，也能驱动深度学习框架。

比如你想处理一张图片，不需要自己写图像解码算法，直接调用 PIL/Pillow 库：

Python
from PIL import Image

img = Image.open("photo.jpg")
small = img.resize((200, 200))
small.save("thumb.jpg")
C++
// C++ 做同样的事需要借助第三方图像库（如 OpenCV）
// 下面是用 OpenCV 的伪代码/思路展示：
// #include <opencv2/opencv.hpp>
// cv::Mat img = cv::imread("photo.jpg");
// cv::Mat small;
// cv::resize(img, small, cv::Size(200, 200));
// cv::imwrite("thumb.jpg", small);

这三行代码背后，是 Pillow 用 C 语言写好的高性能图像处理逻辑。Python 提供了友好的“门面”，让复杂工作变得简单。这正是胶水语言的魅力。

在企业里，Python 经常负责“把 A 系统的数据拿过来，处理一下，再塞给 B 系统”。它不需要速度最快，但要求写得快、读得懂、生态全。

第 3 小节

动手试一试：列表推导与字典

Python 有很多“内置魔法”。其中列表推导式（list comprehension）是最具 Pythonic 风格的小技巧之一：用一行代码生成一个新列表。

Python
# 普通写法
squares = []
for x in range(1, 6):
    squares.append(x * x)
print(squares)  # [1, 4, 9, 16, 25]

# 列表推导式
squares2 = [x * x for x in range(1, 6)]
print(squares2)  # [1, 4, 9, 16, 25]
C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> squares;
    for (int x = 1; x <= 5; x++) {
        squares.push_back(x * x);
    }

    for (int v : squares) {
        std::cout << v << " ";
    }
    std::cout << std::endl;
    return 0;
}

Python 的字典则把“键值对”做成了原生数据类型，非常适合表示现实中的映射关系：

Python
student = {
    "name": "小明",
    "age": 18,
    "scores": {"语文": 90, "数学": 95}
}

print(student["name"])          # 小明
print(student["scores"]["数学"])  # 95
C++
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, std::string> student;
    student["name"] = "小明";
    student["age"] = "18";

    std::map<std::string, int> scores;
    scores["语文"] = 90;
    scores["数学"] = 95;

    std::cout << student["name"] << std::endl;
    std::cout << scores["数学"] << std::endl;
    return 0;
}

这些内置结构让 Python 在处理数据时非常顺手。你不需要关心内存怎么分配，只需要专注于数据本身。

第 4 小节

综合实战：读取文件并统计词频

感受 Python 的胶水与简洁

这个实战展示 Python 如何只用几行代码完成“读取文本、清洗、统计”的完整流程。同样的功能用 C 写，会明显更冗长。

Python
from collections import Counter
import re

# 读取文件
with open("story.txt", "r", encoding="utf-8") as f:
    text = f.read()

# 拆成单词并统计
words = re.findall(r"\b\w+\b", text.lower())
counts = Counter(words)

# 输出出现最多的 5 个词
for word, times in counts.most_common(5):
    print(f"{word}: {times}")

对比 C 语言版本，C 需要自己管理文件指针、缓冲区、字符串分割、哈希表等细节。Python 则把文件、正则、计数器都封装成现成工具：

C
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// C 版本需要手动打开文件、读取缓冲区、
// 拆分单词、维护哈希表或数组来统计。
// 完整代码通常需要 80~150 行。

这不是说 C 不好，而是两者的定位不同：C 控制底层，Python 快速易读。真正的大型项目里，它们经常一起出现——用 C 写性能核心，用 Python 写业务逻辑。
