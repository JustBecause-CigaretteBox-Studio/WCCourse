第 1 小节

pip：Python 的「应用商店」

Python 自带很多功能，但不可能面面俱到。如果需要发 HTTP 请求、处理 Excel、画图表等， 往往要借助别人写好的 第三方库。pip 就是安装这些库的工具。

pip 通常在安装 Python 时就已经装好了。打开终端（Windows 用命令提示符或 PowerShell，Mac/Linux 用 Terminal），输入下面的命令就能安装库：

终端命令
# 安装 requests 库
pip install requests

# 安装指定版本
pip install requests==2.31.0

# 查看已安装的库
pip list

如果系统里同时有 Python 2 和 Python 3，可能需要使用 pip3 而不是 pip。 安装成功后，在 Python 代码里用 import 即可使用。

第 2 小节

import 的三种方式

安装完库后，需要把它导入到当前程序中才能使用。最常用的写法有三种，各有适用场景。

import_styles.py
# 方式 1：导入整个模块
import requests
response = requests.get("https://api.github.com")

# 方式 2：从模块里导入指定函数
from random import randint
print(randint(1, 100))

# 方式 3：给模块起别名
import json
import datetime as dt
now = dt.datetime.now()
print(now)

推荐优先使用方式 1 或方式 2。方式 3 适合模块名较长的情况，比如 import numpy as np。 不建议用 from 模块 import *，因为它会导入所有名字，容易造成冲突。

第 3 小节

虚拟环境：给每个项目一个独立房间

假设项目 A 需要 requests==2.28，项目 B 需要 requests==2.31， 如果把所有库都装在全局环境里，版本就会打架。虚拟环境能隔离不同项目的依赖。

终端命令
# 创建虚拟环境（venv 是 Python 自带的工具）
python -m venv myenv

# Windows 激活虚拟环境
myenv\Scripts\activate

# Mac / Linux 激活虚拟环境
source myenv/bin/activate

# 激活后，安装 requests 只会装到这个环境里
pip install requests

# 退出虚拟环境
deactivate

养成习惯：每个新项目先建一个虚拟环境，再在里面安装依赖。这样既干净又不容易出错。

第 4 小节

综合实战：安装 requests 并写一个小脚本

从安装到 import 再到运行的完整流程

按照下面的步骤，在虚拟环境里完成一个小程序：安装 requests，然后请求一个公开接口并打印结果。

终端命令
# 1. 创建并进入项目文件夹
mkdir api_demo
cd api_demo

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活（Windows 示例）
venv\Scripts\activate

# 4. 安装 requests
pip install requests

然后新建一个 demo.py：

demo.py
import requests

url = "https://api.quotable.io/random"
response = requests.get(url)
quote = response.json()

print(quote["content"])
print("——", quote["author"])

运行 python demo.py，如果能看到一条随机名言，说明你已经完整走通了 「安装库 → 导入 → 调用 API」的全流程。
