第 1 小节

从 CSV 到 DataFrame

让 Pandas 读取真实文件

现实世界里，数据很少直接写在代码里。它们通常以 CSV、Excel 或数据库的形式存在。CSV 是最常见的一种格式，本质就是「用逗号分隔的文本文件」，Excel 可以轻松地把它另存为 CSV。

Pandas 读取 CSV 只需要一行代码：pd.read_csv("文件名.csv")。它会自动把第一行当成列名，剩下的内容变成 DataFrame。读 Excel 也类似，用 pd.read_excel("文件名.xlsx") 即可，不过需要先安装 openpyxl 库。

students.csv
姓名,年龄,成绩
阿明,18,85
小红,20,92
小刚,19,
read_csv.py
import pandas as pd

# 读取同目录下的 CSV 文件
df = pd.read_csv("students.csv")
print(df)

注意上面的 CSV 里，小刚的「成绩」是空的。这种空值在 Pandas 里会被识别为 NaN（Not a Number），意思是「这里缺数据」。下一节我们就来学习怎么处理这些脏数据。

第 2 小节

脏数据长什么样

识别并处理空值、重复与异常

所谓「脏数据」，就是不能直接用、需要先清洗的数据。常见类型有三种：空值（缺数据）、重复值（同一行出现多次）、异常值（明显不合理的数据，比如年龄填成 200）。

Pandas 提供了很多现成的工具来检查这些问题。df.isnull() 会标出所有空值，df.duplicated() 会标出重复行，而 df.describe() 可以快速查看数值列的最大、最小、平均，帮你发现异常。

inspect_dirty.py
import pandas as pd

# 假设 orders.csv 有订单数据
# 列：订单号, 金额, 日期
# 其中金额列有些是空的，有些日期重复
df = pd.read_csv("orders.csv")

# 1. 查看空值数量
print("每列空值数量：")
print(df.isnull().sum())

# 2. 查看重复行
print("\n重复行数：", df.duplicated().sum())

# 3. 数值列统计
print("\n金额统计：")
print(df["金额"].describe())

找到问题之后，处理方式因场景而异：空值可以用 df.dropna() 删除，也可以用 df.fillna(值) 填充；重复行用 df.drop_duplicates() 删除。关键是先检查、理解数据，再决定怎么处理。

第 3 小节

动手：清洗一份订单数据

把脏数据变成干净数据

现在把读取和清洗串起来。假设你拿到一份电商订单数据，里面有一些空价格和重复订单。目标是：删除重复、把空价格填成 0、然后把处理好的数据存成新的 CSV。

orders.csv
订单号,商品,金额
A001,耳机,199
A002,鼠标,89
A003,键盘,
A002,鼠标,89
A004,显示器,1299
clean_orders.py
import pandas as pd

df = pd.read_csv("orders.csv")

# 1. 删除重复订单
df = df.drop_duplicates()

# 2. 把空的金额填成 0
df["金额"] = df["金额"].fillna(0)

# 3. 保存为新的 CSV
df.to_csv("orders_clean.csv", index=False)

print("清洗完成：")
print(df)

这里有两个细节：index=False 表示不要把 DataFrame 自带的行号也写进 CSV；df["金额"].fillna(0) 会把「金额」这一列的空值单独处理，不影响其他列。这种「按列清洗」的写法是 Pandas 的精髓。

第 4 小节

综合实战：员工考勤清洗器

从读文件到输出报告

假设你是 HR，每天要处理一份考勤打卡记录。记录里有些员工忘了打卡（缺数据），有些记录重复上传了，有些时长异常（比如 25 小时）。现在用 Pandas 写一个小工具，自动清洗并输出一份干净的统计。

attendance.csv
姓名,日期,工作时长
阿明,2026-08-01,8
小红,2026-08-01,7.5
小刚,2026-08-01,
阿明,2026-08-02,8
小红,2026-08-02,7.5
小红,2026-08-02,7.5
小丽,2026-08-02,25
clean_attendance.py
import pandas as pd

df = pd.read_csv("attendance.csv")

# 1. 删除完全重复的行
df = df.drop_duplicates()

# 2. 空时长先标记为 0
df["工作时长"] = df["工作时长"].fillna(0)

# 3. 过滤掉不合理的异常时长（> 24 小时）
df = df[df["工作时长"] <= 24]

# 4. 保存并输出统计
summary = df.groupby("姓名")["工作时长"].sum().reset_index()
print("各人总工时：")
print(summary)

df.to_csv("attendance_clean.csv", index=False)

这个项目里，我们用到了读取、去重、填空、异常过滤、分组统计、保存文件。几乎涵盖了数据分析流程的一半工作。后面两个模块会继续学习筛选、聚合和可视化，让这份报告变得更直观。
