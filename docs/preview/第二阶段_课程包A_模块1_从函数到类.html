从函数到类

为什么需要把数据和函数打包在一起

开始模块 1 第 1 小节 → 模块 1 · 4 个小节 · 进度自动保存
第 1 小节

从「散装变量」到「打包管理」

在写小程序时，我们习惯用一个变量记录一个信息。比如要描述一个游戏角色，可能会写出这样一串变量：

player_vars.py
player_name = "主角"
player_x = 100
player_y = 200
player_hp = 80
player_speed = 5
player_vars.cpp
#include <iostream>
using namespace std;

string player_name = "主角";
int player_x = 100;
int player_y = 200;
int player_hp = 80;
int player_speed = 5;

当角色越来越多，或者函数需要用到这些信息时，麻烦就出现了：每次调用函数都要把这些变量当作参数传进去。

move_player.py
def move(name, x, y, hp, speed, direction):
    if direction == "右":
        x += speed
    print(name, "移动到", x, y)
    return x, y
move_player.cpp
#include <iostream>
using namespace std;

int movePlayer(string name, int x, int y, int hp, int speed, string direction) {
    if (direction == "右") {
        x += speed;
    }
    cout << name << " 移动到 " << x << " " << y << endl;
    return x;
}

参数一长串，不仅写起来累，还容易搞错顺序。如果以后还要加入攻击力、防御力、背包，参数列表会变得更加恐怖。于是程序员开始思考：有没有办法把这些相关的数据和函数打包在一起？

第 2 小节

用结构把数据「装盒」

第一步改进，是把同类数据装进一个「盒子」。在 Python 里可以用字典在 C++ 里可以用结构体 struct。这样，原本散落在各处的变量就有了一个统一的名字。

player_dict.py
player = {
    "name": "主角",
    "x": 100,
    "y": 200,
    "hp": 80
}

print(player["name"], "的血量是", player["hp"])
player_struct.cpp
#include <iostream>
using namespace std;

struct Player {
    string name;
    int x;
    int y;
    int hp;
};

int main() {
    Player p = {"主角", 100, 200, 80};
    cout << p.name << " 的血量是 " << p.hp << endl;
    return 0;
}

「装盒」之后，数据的组织清晰多了。但操作这些数据的函数仍然游离在外，我们还是要写 move(player)、attack(player, enemy) 这样的函数。下一步，就是让函数也住进这个盒子里。

第 3 小节

类：把数据和行为一起打包

类（class）是更高级的盒子：它既能装数据，也能装操作这些数据的函数。在 Python 里，类里的函数叫方法在 C++ 里，类里的变量叫成员变量，函数叫成员函数。

player_class.py
class Player:
    def __init__(self, name, x, y, hp):
        self.name = name
        self.x = x
        self.y = y
        self.hp = hp

    def move_right(self):
        self.x += 5

    def show(self):
        print(self.name, "位于", self.x, self.y, "血量", self.hp)

hero = Player("主角", 100, 200, 80)
hero.move_right()
hero.show()
player_class.cpp
#include <iostream>
using namespace std;

class Player {
public:
    string name;
    int x, y, hp;

    void moveRight() {
        x += 5;
    }

    void show() {
        cout << name << " 位于 " << x << " " << y
             << " 血量 " << hp << endl;
    }
};

int main() {
    Player hero = {"主角", 100, 200, 80};
    hero.moveRight();
    hero.show();
    return 0;
}

现在，hero 不仅保存了角色的所有信息，还自带了移动和显示的方法。调用 hero.move_right()调用 hero.moveRight() 时，函数自然知道要修改 hero 自己的 x，不再需要手动传一大堆参数。这就是「把数据和函数打包在一起」的核心好处。

第 4 小节

综合实战：把玩家代码改成类

把本模块内容用起来

下面的代码用「散装变量」描述了一个敌人，并写了一个独立的受伤函数。请你把它改写成一个 Enemy 类，让数据和行为住在一起。

enemy_before.py
enemy_name = "史莱姆"
enemy_hp = 50

def take_damage(name, hp, damage):
    hp -= damage
    print(name, "受到", damage, "点伤害，剩余血量", hp)
    return hp

enemy_hp = take_damage(enemy_name, enemy_hp, 10)
enemy_before.cpp
#include <iostream>
using namespace std;

string enemy_name = "史莱姆";
int enemy_hp = 50;

int takeDamage(string name, int hp, int damage) {
    hp -= damage;
    cout << name << " 受到 " << damage << " 点伤害，剩余血量 " << hp << endl;
    return hp;
}

int main() {
    enemy_hp = takeDamage(enemy_name, enemy_hp, 10);
    return 0;
}

参考答案：

enemy_class.py
class Enemy:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def take_damage(self, damage):
        self.hp -= damage
        print(self.name, "受到", damage, "点伤害，剩余血量", self.hp)

slime = Enemy("史莱姆", 50)
slime.take_damage(10)
enemy_class.cpp
#include <iostream>
using namespace std;

class Enemy {
public:
    string name;
    int hp;

    Enemy(string n, int h) {
        name = n;
        hp = h;
    }

    void takeDamage(int damage) {
        hp -= damage;
        cout << name << " 受到 " << damage << " 点伤害，剩余血量 " << hp << endl;
    }
};

int main() {
    Enemy slime("史莱姆", 50);
    slime.takeDamage(10);
    return 0;
}

改写后，name 和 hp 不再作为参数传来传去，而是由 slime 对象自己保管。尝试再给史莱姆加一个 is_alive()isAlive() 方法，判断血量是否大于 0。
