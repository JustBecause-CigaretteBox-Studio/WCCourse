第 1 小节

事件队列

玩家按键、点击鼠标、关闭窗口……这些动作都会被 Pygame 装进一个叫事件队列的「信箱」里。程序要一封一封地取出来处理。

最常用的取信方式就是 pygame.event.get()。它会返回当前帧内发生的所有事件。

events.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            print("按下了键盘：", event.key)
        if event.type == pygame.MOUSEBUTTONDOWN:
            print("点击了鼠标：", event.pos)

    screen.fill((30, 30, 30))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

KEYDOWN 表示按下的瞬间，MOUSEBUTTONDOWN 表示鼠标按下的瞬间。它们都是「一次性事件」，适合用来触发跳跃、开枪等动作。

第 2 小节

键盘输入

如果想知道「某个键现在是否正被按住」，可以用 pygame.key.get_pressed()。它返回一个很大的布尔表，按下为 True，没按为 False。

这特别适合需要持续移动的场景，比如按住方向键让人物一直走。

keyboard.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

player = pygame.Surface((50, 50))
player.fill((100, 255, 150))
rect = player.get_rect()
rect.center = (400, 300)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  rect.x -= 5
    if keys[pygame.K_RIGHT]: rect.x += 5
    if keys[pygame.K_UP]:    rect.y -= 5
    if keys[pygame.K_DOWN]:  rect.y += 5

    screen.fill((20, 20, 20))
    screen.blit(player, rect)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

注意区分：KEYDOWN 是「按下去的那一刻」；key.get_pressed() 是「当前是否按住」。前者适合点按，后者适合持续操作。

第 3 小节

鼠标输入

鼠标是最直观的输入设备之一。Pygame 可以获取鼠标的位置、按键状态和滚轮事件，非常适合做点击类游戏。

mouse.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

box = pygame.Rect(350, 250, 100, 100)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            if box.collidepoint(event.pos):
                print("点中了方块！")

    mouse_x, mouse_y = pygame.mouse.get_pos()
    screen.fill((25, 25, 25))
    pygame.draw.rect(screen, (255, 200, 100), box)
    pygame.draw.circle(screen, (255, 255, 255), (mouse_x, mouse_y), 8)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

pygame.mouse.get_pos() 返回当前鼠标坐标；collidepoint() 判断一个点是否在矩形内部。两者配合就能做「点中了没有」的判断。

第 4 小节

综合实战：点击生成圆点

把鼠标事件和绘图结合起来：每次点击鼠标，就在点击位置生成一个彩色圆点，所有圆点都会保留在画面上。

dots.py
import pygame
import random

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

dots = []       # 保存所有圆点的位置和颜色

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            color = (random.randint(100, 255),
                     random.randint(100, 255),
                     random.randint(100, 255))
            dots.append({"pos": event.pos, "color": color})

    screen.fill((20, 20, 20))
    for d in dots:
        pygame.draw.circle(screen, d["color"], d["pos"], 15)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

练习：给圆点加入半径信息，每次点击生成大小不一的圆点；或者按 R 键清空所有圆点。
