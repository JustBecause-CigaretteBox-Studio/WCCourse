第 1 小节

为什么需要 try / except

写程序最怕的不是报错，而是一报错就全盘崩溃。想象一下：用户正填着一份长表单，因为一次手滑输入了字母，程序直接闪退，所有内容都丢了。

try / except 就是给程序穿的"防弹衣"：让可能发生危险操作的代码先"试试"，真出事了就按我们的方案处理，而不是让 Python 直接撂挑子。

num = int(input("请输入你的年龄："))
print("十年后你", num + 10, "岁")

如果用户输入 "abc"，上面代码会立刻抛出 ValueError。下面学习如何接住它。

第 2 小节

try / except 基本写法

语法就像说中文一样直白：

try:
    num = int(input("请输入你的年龄："))
    print("十年后你", num + 10, "岁")
except ValueError:
    print("输入的不是数字，我无法计算。")

规则很简单：把可能出错的代码放进 try 块；如果抛出 ValueError，就跳到对应的 except 块执行。程序不会崩溃，用户只会看到一句友好提示。

第 3 小节

捕获特定异常 vs 捕获所有异常

你可以针对不同的异常写不同的 except，就像医院分科室挂号。不要图省事写个"包治百病"的空 except，那会隐藏真正的 bug。

try:
    a = int(input("分子："))
    b = int(input("分母："))
    print("结果：", a / b)
except ValueError:
    print("请输入数字。")
except ZeroDivisionError:
    print("分母不能为 0。")
except Exception as e:
    print("其他错误：", e)

最后一行的 Exception 是所有异常的"老祖宗"，用来兜住前面没专门处理的意外情况。先用具体的异常类型，再用通用的，是最佳实践。

第 4 小节

综合实战：安全除法计算器

做一个"安全除法计算器"，要求无论用户怎么乱输入，程序都不崩溃，并给出对应的提示。

def divide_calculator():
    try:
        a = float(input("请输入分子："))
        b = float(input("请输入分母："))
        result = a / b
    except ValueError:
        print("只能输入数字哦。")
    except ZeroDivisionError:
        print("分母不能为 0。")
    else:
        print(f"结果：{result:.2f}")

divide_calculator()

这里还偷偷用到了 else：只有没出错时，才打印结果。下一模块会详细讲它。
