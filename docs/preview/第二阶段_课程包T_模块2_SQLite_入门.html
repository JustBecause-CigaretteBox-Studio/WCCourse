第 1 小节

认识 SQLite

SQLite 是世界上最常用的嵌入式数据库之一。它最大的特点是零配置：不需要单独安装服务器，数据库本身就是一个文件。

Python 标准库自带 sqlite3 模块，所以只要装了 Python，就能立刻创建和使用 SQLite 数据库。

SQLite 的特点
# 1. 单文件存储：整个数据库就是一个 .db 文件
# 2. 零配置：无需启动数据库服务
# 3. Python 内置：import sqlite3 即可使用
# 4. 适合学习、单机程序、小型项目
第 2 小节

创建第一个数据库

用 Python 创建 SQLite 数据库只需要两步：连接数据库文件、创建游标。

create_first_db.py
import sqlite3

# 连接数据库文件（不存在会自动创建）
conn = sqlite3.connect("my_first.db")

# 创建游标：用来执行 SQL 语句
cursor = conn.cursor()

# 关闭连接
conn.close()
print("数据库已创建：my_first.db")

运行后，你会在当前目录看到一个 my_first.db 文件。这就是你的第一个数据库。

第 3 小节

表、行、列的概念

数据库里用表（Table）来组织数据。一个表就像一张 Excel 工作表：

  • 每一列（Column）代表一种属性，例如姓名、年龄。
  • 每一行（Row）代表一条记录，例如一个学生的信息。
  • 每个单元格里只能放一种类型的数据，例如整数、文本。
create_table.py
import sqlite3

conn = sqlite3.connect("my_first.db")
cursor = conn.cursor()

cursor.execute('''
CREATE TABLE IF NOT EXISTS students (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL,
    age   INTEGER
)
''')

conn.commit()  # 提交修改
conn.close()

注意 conn.commit()：对数据库的修改需要先提交，才会真正保存到文件里。查询则不需要 commit。

第 4 小节

综合实战：设计一个待办事项表

零配置也能建表

来做一个简单的待办事项（TODO）数据库。每条待办需要：标题、是否完成、创建时间。

todo_table.py
import sqlite3

conn = sqlite3.connect("todo.db")
cursor = conn.cursor()

cursor.execute('''
CREATE TABLE IF NOT EXISTS todos (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    title       TEXT NOT NULL,
    is_done     INTEGER DEFAULT 0,
    created_at  TEXT
)
''')

conn.commit()
conn.close()
print("todo 表创建完成")

动手任务：用 DB Browser for SQLite 或任何 SQLite 可视化工具打开 todo.db，看看表结构长什么样。
