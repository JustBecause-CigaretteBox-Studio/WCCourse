第 1 小节

文件就像仓库里的货物

用 os 模块查看、遍历文件

想象你的电脑桌面是一个大仓库，每个文件都是一箱货物。Python 的 os 模块就像仓库管理员：它能告诉你仓库里有多少箱子、箱子放在哪条过道、叫什么名字。

最常见的两个动作是：先看仓库清单，再拼接出箱子的完整地址。

list_files.py
import os

# 查看当前仓库里有什么
folder = "下载"
files = os.listdir(folder)
print(files)

# 拼出每个文件的完整地址
for name in files:
    full_path = os.path.join(folder, name)
    print(full_path)

os.listdir() 相当于「点名」，os.path.join() 相当于「把货架号和箱子名拼成完整地址」。这样做的好处是：不管在 Windows 还是 Mac 上，斜杠都能自动变对。

第 2 小节

批量重命名

用 os.rename 给文件换名字

手机里拍了一百张照片，名字都是 IMG_0001.jpg、IMG_0002.jpg……想统一改成 旅行_01.jpg、旅行_02.jpg，手动改太麻烦。用 Python 可以一次搞定。

核心函数是 os.rename(旧名, 新名)。它就像给箱子贴新标签：标签换了，但箱子还在原来的位置。

batch_rename.py
import os

folder = "照片"
files = os.listdir(folder)

for i, name in enumerate(files, start=1):
    # 取出扩展名，比如 .jpg
    ext = os.path.splitext(name)[1]
    new_name = f"旅行_{i:02d}{ext}"

    old_path = os.path.join(folder, name)
    new_path = os.path.join(folder, new_name)

    os.rename(old_path, new_path)
    print(f"{name} → {new_name}")

这里 os.path.splitext() 把文件名切成「名字」和「扩展名」两部分；f"旅行_{i:02d}" 让数字前面补零，变成 01、02，看起来更整齐。

第 3 小节

搬家、复制与分类

shutil 让文件自动归位

仓库整理到后面，经常需要把货物搬到不同区域：图片放到相册区，文档放到资料区，音乐放到音频区。shutil 模块就是搬家公司。

organize.py
import os
import shutil

# 按扩展名自动分类
rules = {
    ".jpg": "图片",
    ".png": "图片",
    ".docx": "文档",
    ".pdf": "文档",
    ".mp3": "音乐",
}

source = "下载"
for name in os.listdir(source):
    ext = os.path.splitext(name)[1].lower()
    target = rules.get(ext)
    if target:
        os.makedirs(target, exist_ok=True)
        shutil.move(os.path.join(source, name), os.path.join(target, name))

注意两个细节：

1. os.makedirs(target, exist_ok=True) 会先建好目标文件夹，如果已经有了也不会报错。

2. shutil.move() 是「搬家」；如果你想保留原文件再复制一份，用 shutil.copy()。

第 4 小节

综合实战：下载文件夹整理助手

自动分类、重命名、清理

每次下载完文件，「下载」文件夹都乱成一团。我们来写一个下载文件夹整理助手：它会按日期把文件放进不同子文件夹，并自动把同类文件归类。

download_cleaner.py
import os
import shutil
from datetime import datetime

def clean_downloads(path="下载"):
    for name in os.listdir(path):
        full = os.path.join(path, name)
        if os.path.isfile(full):
            # 按修改日期建文件夹
            mtime = datetime.fromtimestamp(os.path.getmtime(full))
            date_folder = mtime.strftime("%Y-%m")
            target_dir = os.path.join(path, date_folder)
            os.makedirs(target_dir, exist_ok=True)
            shutil.move(full, os.path.join(target_dir, name))
            print(f"已整理：{name} → {date_folder}/")

clean_downloads()

这个脚本先读取每个文件的修改时间，再用 strftime("%Y-%m") 格式化成「年-月」的文件夹名，最后把文件搬进去。运行一次，下载文件夹就整整齐齐了。
