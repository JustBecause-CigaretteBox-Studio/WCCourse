用任务管理器看懂进程与内存占用

第 1 小节

打开任务管理器，看进程

任务管理器（Windows）或活动监视器（macOS）是观察操作系统的“透视镜”。打开它，切换到“进程”选项卡，你能看到当前运行的所有程序，以及它们占用的 CPU、内存、磁盘、网络等资源。

在 Windows 上，你可以按 Ctrl + Shift + Esc 快速打开任务管理器。每一行通常对应一个进程，你可以右键结束任务。

命令行也提供了类似功能：

tasklist.sh
# Windows：列出进程
tasklist

# Linux/macOS：列出进程
ps aux
第 2 小节

看懂性能指标

任务管理器的“性能”选项卡展示了整台电脑的资源使用情况。重点关注以下几项：

  • CPU：使用率越高，处理器越忙。长期接近 100% 可能意味着有程序在拼命计算。
  • 内存：显示已用内存和剩余内存。内存用满后，系统会使用硬盘作为“虚拟内存”，速度会明显下降。
  • 磁盘：硬盘读写活动。磁盘 100% 常是电脑卡顿的元凶。
  • 网络：当前的上传、下载速度。
第 3 小节

命令行里的“任务管理器”

除了图形界面，命令行工具也能查看系统状态，而且往往更轻量、更适合远程服务器。

system_monitor.sh
# Linux/macOS
top           # 实时进程和资源
free -h       # 查看内存使用情况
df -h         # 查看磁盘空间

# Windows
wmic cpu get loadpercentage
wmic memorychip get capacity

这些命令本身也是向操作系统请求系统调用，把内核统计的数据展示给你。

第 4 小节

综合实战：用 Python 查看自己的进程

把本模块内容用起来

最后，我们写一个 Python 小脚本，查看当前进程的 PID 和内存占用（本教程也提供了C++实现）。如果你能安装 psutil 库，可以得到更详细的信息；否则用标准库也能看个大概。

self_inspect.py
import os
import sys

print("当前进程 PID：", os.getpid())
print("Python 版本：", sys.version.split()[0])

# 如果安装了 psutil，可以查看更详细的内存信息
try:
    import psutil
    p = psutil.Process(os.getpid())
    info = p.memory_info()
    print(f"当前进程占用内存：{info.rss / 1024 / 1024:.2f} MB")
except ImportError:
    print("提示：安装 psutil 后可查看更详细的内存占用")
self_inspect.cpp
#include <iostream>
#ifdef _WIN32
#include <windows.h>
#else
#include <unistd.h>
#endif

int main() {
#ifdef _WIN32
    std::cout << "当前进程 PID： " << GetCurrentProcessId() << std::endl;
#else
    std::cout << "当前进程 PID： " << getpid() << std::endl;
#endif
    std::cout << "提示：使用平台相关 API 可查看更详细的内存占用" << std::endl;
    return 0;
}

运行后，打开任务管理器找到对应的 PID，对比一下显示的内存数值。这就是“程序看到的自己”和“操作系统看到的程序”之间的联系。
