第 1 小节

字典为什么这么快

平均 O(1) 的秘密

Python 里的 dict、C++ 里的 unordered_map，底层都是哈希表。它们查找、插入、删除的平均时间复杂度接近 O(1)，几乎和里面存了多少东西无关。

想象储物柜：每个人通过某种规则拿到一个柜号，东西直接放进对应柜子。要取东西时，再用同样的规则找到柜子，打开就能拿到，不用逐个柜子翻。

例子里面的“某种规则”就叫哈希函数，而由柜子和里面内容组成的整体就是哈希表。

在某些书籍，例如《The Bible》(《算法导论》)中，“哈希”会变为“散列”，“哈希”源自音译Hash，意思是“切碎、剁碎”，“散列”是意译，表示“分散排列”的存储方式 

scores = {
    "Alice": 90,
    "Bob": 85,
    "Cara": 92
}

print(scores["Bob"])   # 85，查找极快
#include <unordered_map>
#include <string>
#include <iostream>
using namespace std;

unordered_map<string, int> scores;
scores["Alice"] = 90;
scores["Bob"] = 85;
scores["Cara"] = 92;

cout << scores["Bob"];   // 85
第 2 小节

哈希函数与冲突

不同钥匙打开同一个柜子怎么办

哈希函数并不完美：两个不同的关键字可能算出同一个柜子编号，这种情况叫冲突（Collision）。好的哈希表会处理冲突，常见方法有链地址法（柜子里挂一条小链表）和开放寻址法（附近找空位）。

只要哈希函数分布均匀，每个柜子里的东西都不多，查找仍然很快。Python 和 C++ 标准库已经帮我们把这些细节做好了，日常开发直接调用即可。

如果你确实对“哈希函数到底是什么”非常感兴趣，可以查阅《The Bible》，然而里面的内容会很难

# 用 Python 模拟最简单的哈希：对某个数取模
def simple_hash(key, size):
    return hash(key) % size

# 不同的 key 可能得到相同的哈希值
print(simple_hash("apple", 8))
print(simple_hash("grape", 8))
# 如果相同，就发生了冲突，需要用链表等办法解决
hash_conflict.cpp
#include <string>
#include <iostream>
using namespace std;

int simple_hash(const string& key, int size) {
    int h = 0;
    for (char ch : key) h = h * 31 + ch;
    return (h & 0x7fffffff) % size;
}

int main() {
    cout << simple_hash("apple", 8) << "\n";
    cout << simple_hash("grape", 8) << "\n";
    // 如果相同，就发生了冲突，需要用链表等办法解决
    return 0;
}
第 3 小节

常用操作

增删改查都很快

哈希表最常用的操作就是「根据 key 找到 value」。除此之外，还能判断 key 是否存在、删除 key、遍历所有键值对等。

但要注意：哈希表不保证键值对的顺序（除非使用 Python 3.7+ 的字典，它按插入顺序保存）。如果顺序很重要，可以考虑有序映射或用列表辅助。

phone = {"Alice": "123", "Bob": "456"}

phone["Cara"] = "789"      # 新增
phone["Bob"] = "999"       # 修改
print("Alice" in phone)    # True，判断是否存在
del phone["Bob"]           # 删除

for name, num in phone.items():
    print(name, num)
#include <unordered_map>
#include <string>
#include <iostream>
using namespace std;

unordered_map<string, string> phone;
phone["Alice"] = "123";
phone["Bob"] = "456";
phone["Cara"] = "789";
phone["Bob"] = "999";

if (phone.count("Alice")) cout << "存在\n";
phone.erase("Bob");

for (auto& [name, num] : phone) {
    cout << name << " " << num << "\n";
}
第 4 小节

综合实战：统计单词出现次数

用哈希表做词频统计

统计一篇文章中每个单词出现的次数，是哈希表最经典的用途之一。我们只需要遍历文本，把每个单词当作 key，出现次数当作 value，遇到一次就加 1。

text = "apple banana apple cherry banana apple"
words = text.split()

count = {}
for word in words:
    count[word] = count.get(word, 0) + 1

for word, times in count.items():
    print(word, times)
# apple 3
# banana 2
# cherry 1
#include <unordered_map>
#include <sstream>
#include <string>
#include <iostream>
using namespace std;

string text = "apple banana apple cherry banana apple";
unordered_map<string, int> count;
stringstream ss(text);
string word;
while (ss >> word) {
    count[word]++;
}

for (auto& [w, c] : count) {
    cout << w << " " << c << "\n";
}

练习：读入一段用户输入的文本，输出出现次数最多的前 3 个单词。
