创建你的第一个类

属性、方法、selfthis 的含义

开始模块 2 第 1 小节 → 模块 2 · 4 个小节 · 进度自动保存
第 1 小节

属性：类里的变量

类是盛放数据和函数的容器。放在类里的变量有一个专门的名字：属性（attribute）。如果把类比作一个表格的模板，那么属性就是表格里的每一栏。

cat_attr.py
class Cat:
    def __init__(self, name, age, color):
        self.name = name      # 属性：名字
        self.age = age        # 属性：年龄
        self.color = color    # 属性：颜色

mimi = Cat("咪咪", 2, "白色")
print(mimi.name)   # 咪咪
cat_attr.cpp
#include <iostream>
using namespace std;

class Cat {
public:
    string name;
    int age;
    string color;
};

int main() {
    Cat mimi = {"咪咪", 2, "白色"};
    cout << mimi.name << endl;
    return 0;
}

在上面的例子里，name、age、color 都是 Cat 类的属性。每个由类创建出来的对象（比如 mimi）都会拥有一份自己的属性值。

第 2 小节

方法：类里的函数

放在类里的函数叫做方法（method）。方法的作用通常是操作这个类的属性，或者完成和对象相关的任务。定义方法和定义普通函数很像，区别只是它写在 class 内部。

cat_method.py
class Cat:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def say(self):                 # 方法
        print(self.name, "说：喵")

    def birthday(self):            # 方法
        self.age += 1
        print(self.name, "今年", self.age, "岁了")

mimi = Cat("咪咪", 2)
mimi.say()
mimi.birthday()
cat_method.cpp
#include <iostream>
using namespace std;

class Cat {
public:
    string name;
    int age;

    void say() {
        cout << name << " 说：喵" << endl;
    }

    void birthday() {
        age++;
        cout << name << " 今年 " << age << " 岁了" << endl;
    }
};

int main() {
    Cat mimi = {"咪咪", 2};
    mimi.say();
    mimi.birthday();
    return 0;
}

调用方法时，我们写 mimi.say()，看起来就像是在命令 mimi 做一件事。方法让我们把「对象能干什么」和「对象是什么」放在同一个地方描述。

第 3 小节

self 与 this：对象指向自己

在 Python 的方法里，第一个参数通常叫 self。在 C++ 里，可以用 this 关键字。它们的作用都是：让方法知道「我现在在操作哪个对象」。

self_demo.py
class Cat:
    def __init__(self, name):
        self.name = name

    def rename(self, new_name):
        self.name = new_name   # self 代表调用 rename 的那只猫

mimi = Cat("咪咪")
mimi.rename("大咪")
print(mimi.name)   # 大咪
this_demo.cpp
#include <iostream>
using namespace std;

class Cat {
public:
    string name;

    void rename(string newName) {
        this->name = newName;   // this 指向当前对象，你要重命名的是这只猫而不是其他的猫
    }
};

int main() {
    Cat mimi = {"咪咪"};
    mimi.rename("大咪");
    cout << mimi.name << endl;
    return 0;
}

当 mimi.rename("大咪") 执行时，方法里的 self 就代表了 mimi方法里的 this 就代表了 mimi。注意：调用方法时，Python 会自动把对象传给 self，不需要你手动写。注意：调用方法时，C++ 会自动把当前对象绑定到 this，通常连 this-> 都可以省略。

综合实战：设计一只小猫

把本模块内容用起来

请你独立设计一个 Dog 类，包含以下要求：

  • 属性：name、age
  • 方法：bark()，打印「汪汪」；grow()，让 age 增加 1

参考答案：

dog_class.py
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(self.name, "说：汪汪")

    def grow(self):
        self.age += 1
        print(self.name, "长大了，今年", self.age, "岁")

wangcai = Dog("旺财", 1)
wangcai.bark()
wangcai.grow()
dog_class.cpp
#include <iostream>
using namespace std;

class Dog {
public:
    string name;
    int age;

    void bark() {
        cout << name << " 说：汪汪" << endl;
    }

    void grow() {
        age++;
        cout << name << " 长大了，今年 " << age << " 岁" << endl;
    }
};

int main() {
    Dog wangcai = {"旺财", 1};
    wangcai.bark();
    wangcai.grow();
    return 0;
}
