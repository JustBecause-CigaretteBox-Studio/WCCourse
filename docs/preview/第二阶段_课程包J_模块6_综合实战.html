第 1 小节

没有最好的语言，只有合适的语言

学完前面的模块，你会发现一个事实：编程语言不是“谁比谁强”，而是“谁更适合做什么”。C 控制内存，Python 快速拼装，JavaScript 驱动网页，Java 支撑企业系统，Go 跑云原生服务，Rust 追求安全与性能。

同一个任务，用不同语言写出来，代码长度、运行速度、维护难度都会不同。优秀的程序员不是只会一门语言，而是能根据场景选择最合适的工具。

这个模块的任务是：判断一个整数是不是素数。我们会用 C、Python、JavaScript 各写一份实现，直观比较它们的特点。

第 2 小节

算法思路：素数判断

素数是指只能被 1 和它本身整除的大于 1 的整数。判断一个数 n 是否为素数，最朴素的方法是：

  • 如果 n 小于等于 1，不是素数。
  • 从 2 开始，检查到 √n 之间的所有整数是否能整除 n。
  • 只要有一个能整除，就不是素数；否则就是素数。

这个逻辑和语言无关。接下来三小节只是把同一逻辑翻译成三种不同的语法。

第 3 小节

动手试一试：三份代码并排看

C 语言版：需要声明类型、手动控制循环，逻辑紧凑但代码较长。

C
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

bool is_prime(int n) {
    if (n <= 1) return false;
    for (int i = 2; i <= (int)sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    int n = 29;
    if (is_prime(n)) {
        printf("%d 是素数\n", n);
    } else {
        printf("%d 不是素数\n", n);
    }
    return 0;
}

Python 版：不需要声明类型，语法更贴近数学表达。

Python
import math

def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

n = 29
print(f"{n} 是素数" if is_prime(n) else f"{n} 不是素数")

JavaScript 版：和 Python 同样简洁，用 const 声明，用模板字符串输出。

JavaScript
function isPrime(n) {
    if (n <= 1) return false;
    for (let i = 2; i <= Math.sqrt(n); i++) {
        if (n % i === 0) return false;
    }
    return true;
}

const n = 29;
console.log(`${n} ${isPrime(n) ? "是素数" : "不是素数"}`);

三份代码的核心算法一模一样，但表达习惯不同：C 强调类型和显式转换，Python 强调可读性，JavaScript 强调灵活。

第 4 小节

综合实战：把它们串起来

判断素数 + 批量打印前 20 个素数

接下来我们不再只判断一个数，而是打印前 20 个素数。这能体现不同语言在循环、数组/列表使用上的差异。

C 语言版：用固定大小数组存放结果。

C
#include <stdio.h>
#include <stdbool.h>
#include <math.h>

bool is_prime(int n) {
    if (n <= 1) return false;
    for (int i = 2; i <= (int)sqrt(n); i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    int found = 0, num = 2;
    while (found < 20) {
        if (is_prime(num)) {
            printf("%d ", num);
            found++;
        }
        num++;
    }
    printf("\n");
    return 0;
}

Python 版：用列表收集，代码更短。

Python
import math

def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(math.sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

primes = []
n = 2
while len(primes) < 20:
    if is_prime(n):
        primes.append(n)
    n += 1

print(primes)

JavaScript 版：和 Python 结构相似，但用数组的 push 方法。

JavaScript
function isPrime(n) {
    if (n <= 1) return false;
    for (let i = 2; i <= Math.sqrt(n); i++) {
        if (n % i === 0) return false;
    }
    return true;
}

const primes = [];
let n = 2;
while (primes.length < 20) {
    if (isPrime(n)) primes.push(n);
    n++;
}

console.log(primes);

比较之后可以发现：C 最接近机器，控制最细；Python 最接近想法，代码最少；JavaScript 介于两者之间，灵活且无处不在。当你再遇到新语言时，先找它在这把尺子上的位置，就能快速判断它适合做什么。
