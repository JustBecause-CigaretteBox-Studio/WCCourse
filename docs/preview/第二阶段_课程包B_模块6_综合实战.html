第 1 小节

需求分析：一个不怕乱输入的程序

现在综合前面所有知识，做一个"用户输入处理机"。它能：

  • 提示用户输入一个 1~100 的整数
  • 如果输入不是数字，提示"请输入整数"
  • 如果数字超出范围，提示"范围不对"
  • 输入合法时，给出"优秀/及格/不及格"评级

这个需求几乎用到了异常处理全家桶：try/except、自定义异常、else、finally。

第 2 小节

设计：先写校验函数

先把"输入是否合法"的逻辑拆成独立函数，再用自定义异常表达不同的错误。这样主逻辑会非常干净。

class NotIntegerError(Exception):
    pass

class OutOfRangeError(Exception):
    pass

def validate_score(text):
    try:
        score = int(text)
    except ValueError:
        raise NotIntegerError("请输入整数")
    if score < 0 or score > 100:
        raise OutOfRangeError("分数必须在 0~100 之间")
    return score

函数只负责判断，不负责打印。这样它既能被命令行程序调用，也能被网页/游戏复用。

第 3 小节

整合：多层异常处理

主程序负责捕获这些自定义异常，并给出友好的中文提示。再用 finally 做流程收尾。

def grade(score):
    if score >= 90:
        return "优秀"
    elif score >= 60:
        return "及格"
    else:
        return "不及格"

try:
    text = input("请输入 0~100 的分数：")
    score = validate_score(text)
except NotIntegerError as e:
    print("输入错误：", e)
except OutOfRangeError as e:
    print("范围错误：", e)
else:
    print(f"你的评级是：{grade(score)}")
finally:
    print("评分流程结束。")

注意 grade 只在 else 里调用，因为只有在输入合法时才有评级可言。

第 4 小节

综合实战：智能评分机

把前面的代码拼装成一个完整程序，并加入"循环询问直到输入正确"的功能。下面是完整实现：

class NotIntegerError(Exception):
    pass

class OutOfRangeError(Exception):
    pass

def validate_score(text):
    try:
        score = int(text)
    except ValueError:
        raise NotIntegerError("请输入整数")
    if score < 0 or score > 100:
        raise OutOfRangeError("分数必须在 0~100 之间")
    return score

def grade(score):
    if score >= 90:
        return "优秀"
    elif score >= 60:
        return "及格"
    else:
        return "不及格"

def main():
    while True:
        text = input("请输入 0~100 的分数（输入 q 退出）：")
        if text.lower() == "q":
            break
        try:
            score = validate_score(text)
        except NotIntegerError as e:
            print("错误：", e)
            continue
        except OutOfRangeError as e:
            print("错误：", e)
            continue
        print(f"评级：{grade(score)}")
    print("程序已退出。")

main()

运行后，尝试输入 "abc"、"101"、"-5"、"88"，看程序是否能稳定处理每一种情况。
