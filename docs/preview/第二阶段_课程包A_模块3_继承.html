第 1 小节

什么是继承

继承是一种「父子关系」：子类自动拥有父类中已经写好的属性和方法，不需要再重复写一遍。生活中也有很多类似的例子：小汽车、卡车、公交车都是「车」，它们共享「能跑、有轮子」这些特点，但又有各自不同的功能。

inherit_basic.py
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(self.name, "在吃东西")

class Dog(Animal):     # Dog 继承自 Animal
    pass               # 暂时不添加新内容

d = Dog("旺财")
d.eat()                # 旺财 在吃东西
inherit_basic.cpp
#include <iostream>
using namespace std;

class Animal {
public:
    string name;
    Animal(string n) : name(n) {}
    void eat() {
        cout << name << " 在吃东西" << endl;
    }
};

class Dog : public Animal {   // Dog 继承 Animal
public:
    Dog(string n) : Animal(n) {}
};

int main() {
    Dog d("旺财");
    d.eat();
    return 0;
}

上面的 Dog 类几乎没有写新代码，却已经能调用 eat()。这就是继承最直接的用处：避免重复写相同的代码。

第 2 小节

复用与扩展：子类的新本领

继承不只是「照搬」父类，子类还可以添加自己特有的属性和方法，甚至重写父类的方法，让同样的命令产生不同的行为。

override.py
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(self.name, "发出声音")

class Dog(Animal):
    def speak(self):           # 重写父类方法
        print(self.name, "说：汪汪")

class Cat(Animal):
    def speak(self):           # 重写父类方法
        print(self.name, "说：喵")

Dog("旺财").speak()
Cat("咪咪").speak()
override.cpp
#include <iostream>
using namespace std;

class Animal {
public:
    string name;
    Animal(string n) : name(n) {}
    virtual void speak() {
        cout << name << " 发出声音" << endl;
    }
};

class Dog : public Animal {
public:
    Dog(string n) : Animal(n) {}
    void speak() override {
        cout << name << " 说：汪汪" << endl;
    }
};

class Cat : public Animal {
public:
    Cat(string n) : Animal(n) {}
    void speak() override {
        cout << name << " 说：喵" << endl;
    }
};

int main() {
    Dog d("旺财"); d.speak();
    Cat c("咪咪"); c.speak();
    return 0;
}

在 C++ 例子里，virtual 和 override 是告诉编译器：这个方法可能会被重写。对新手来说，先记住它们和「重写」相关即可，不需要深入细节。在 Python 里，如果你在子类里写了一个和父类同名的方法，就会自动覆盖父类的方法，不需要额外关键字。

第 3 小节

调用父类：super 与父类构造

有时候子类想「在父类已经做完的事情之上，再加点东西」。这时就需要显式调用父类的方法。Python 用 super()。C++ 用初始化列表调用父类构造函数。

super_demo.py
class Animal:
    def __init__(self, name):
        self.name = name
        print("Animal 初始化完成")

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)   # 先调用父类构造
        self.breed = breed       # 再添加自己的属性
        print("Dog 初始化完成")

Dog("旺财", "金毛")
super_demo.cpp
#include <iostream>
using namespace std;

class Animal {
public:
    string name;
    Animal(string n) : name(n) {
        cout << "Animal 初始化完成" << endl;
    }
};

class Dog : public Animal {
public:
    string breed;
    Dog(string n, string b) : Animal(n), breed(b) {
        cout << "Dog 初始化完成" << endl;
    }
};

int main() {
    Dog d("旺财", "金毛");
    return 0;
}

super() 的含义就是「我的父类」。通过它，子类既能复用父类已经写好的初始化逻辑，又能补充自己的独特属性。这样代码既有层次，又不容易重复。C++ 的初始化列表中先写父类构造 Animal(n)，再写成员变量 breed(b)。这样父类先完成初始化，子类再补充自己的成员。

第 4 小节

综合实战：动物家族

把本模块内容用起来

请你设计一个 Bird 类，继承自 Animal，并添加一个 fly() 方法。然后创建一只鸟，让它先吃东西，再飞翔。

bird_solution.py
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(self.name, "在吃东西")

class Bird(Animal):
    def fly(self):
        print(self.name, "在天上飞")

b = Bird("小白")
b.eat()
b.fly()
bird_solution.cpp
#include <iostream>
using namespace std;

class Animal {
public:
    string name;
    Animal(string n) : name(n) {}
    void eat() {
        cout << name << " 在吃东西" << endl;
    }
};

class Bird : public Animal {
public:
    Bird(string n) : Animal(n) {}
    void fly() {
        cout << name << " 在天上飞" << endl;
    }
};

int main() {
    Bird b("小白");
    b.eat();
    b.fly();
    return 0;
}

尝试扩展这个例子：给 Bird 加一个 speak() 方法，让它发出「叽叽」的声音。这样你就同时用到了继承、扩展和重写。
