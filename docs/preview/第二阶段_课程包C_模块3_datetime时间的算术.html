第 1 小节

日期

datetime.date 与 datetime.datetime

程序经常需要知道「现在几点」「今天星期几」「距离某个日子还有几天」。Python 把这类需求统一交给 datetime 模块处理。

datetime.date 表示「某年某月某日」，就像日历上的一天；datetime.datetime 则更精确，包含时、分、秒。

from datetime import date, datetime

# 今天
print(date.today())

# 现在（包含时分秒）
print(datetime.now())

# 指定一个日期
mid_autumn = date(2026, 9, 25)
print(mid_autumn.year, mid_autumn.month, mid_autumn.day)

如果你只想取出年、月、日，可以直接访问 .year、.month、.day 属性。这种写法比手动切割字符串要可靠得多。

第 2 小节

时间戳

数字化的时刻

时间戳（timestamp）是电脑记录时间的一种方式：从某个固定起点（1970 年 1 月 1 日 0 时 0 分 0 秒）到现在一共经过了多少秒。它就像一个「时刻的身份证」，方便比较和存储。

from datetime import datetime

now = datetime.now()
print("当前时间：", now)

# 转成时间戳
stamp = now.timestamp()
print("时间戳：", stamp)

# 把时间戳转回 datetime
back = datetime.fromtimestamp(stamp)
print("还原后：", back)

时间戳的优点是「就一个数字」，比较大小、做减法特别方便。缺点是不好读，所以通常只在程序内部使用，显示给用户时再转回「年月日」格式。

第 3 小节

timedelta 计算

时间的加减法

直接对日期做「加 3 天」「减 7 天」是不行的，因为日期不是普通数字。Python 提供了 timedelta，表示一段「时间差」，专门用来做这类运算。

from datetime import date, timedelta

today = date.today()
print("今天：", today)

# 3 天后
future = today + timedelta(days=3)
print("3 天后：", future)

# 7 天前
past = today - timedelta(days=7)
print("7 天前：", past)

# 两个日期相差多少天
deadline = date(2026, 12, 31)
print("距离年底还有：", (deadline - today).days, "天")

timedelta 还可以表示小时、分钟、秒。注意它只能和 datetime 或 date 类型的对象做加减，不能直接加在字符串上。

第 4 小节

综合实战

倒数日小工具

做一个简单的「倒数日」程序：输入一个重要日期，程序告诉你还有几天，并自动判断是「还没到来」「就是今天」还是「已经过去」。

from datetime import date

def countdown(target_str):
    # 把 "2026-09-01" 这种字符串转成 date
    y, m, d = map(int, target_str.split("-"))
    target = date(y, m, d)

    today = date.today()
    diff = (target - today).days

    if diff > 0:
        return f"距离 {target_str} 还有 {diff} 天"
    elif diff == 0:
        return f"今天就是 {target_str}！"
    else:
        return f"{target_str} 已经过去了 {-diff} 天"

print(countdown("2026-12-31"))
print(countdown("2026-01-01"))
print(countdown(str(date.today())))

你可以把它改成「生日提醒」「考试倒计时」或者「项目截止日期提醒」。核心就是「目标日期 - 今天 = 相差天数」。
