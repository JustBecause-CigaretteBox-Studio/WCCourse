第 1 小节

项目规划

每日简报需要哪些信息

学完前面的模块，你已经能请求网页、解析内容、保存数据、遵守规矩。现在把这些能力串起来，做一个小项目：每日简报生成器。

简报的内容可以包括：

  • 一句话天气（从允许抓取的公开天气站点获取）。
  • 几条新闻标题（从允许抓取的新闻聚合页或 RSS 获取）。
  • 一句喜欢的歌词或名言（可选，用来练习字符串处理）。

第 2 小节

抓取与解析

用 requests + BeautifulSoup 摘取片段

下面这段代码演示如何从一个本地或公开页面中提取新闻标题。为了离线也能运行，我们先用一段本地 HTML 字符串练习：

parse_news.py
from bs4 import BeautifulSoup

html_doc = """
<div class="news-list">
  <article><h3><a href="/news/1">Python 发布新版本</a></h3></article>
  <article><h3><a href="/news/2">人工智能最新进展</a></h3></article>
  <article><h3><a href="/news/3">开源社区周刊</a></h3></article>
</div>
"""

soup = BeautifulSoup(html_doc, "html.parser")
news = []
for article in soup.select(".news-list article"):
    a = article.find("a")
    news.append({
        "title": a.get_text(strip=True),
        "link": a.get("href"),
    })

for item in news:
    print(item["title"], "->", item["link"])

实际项目中，把 html_doc 换成 requests.get(url).text 即可。注意：soup.select(".news-list article") 是 CSS 选择器写法，可以一次性定位到复合结构的节点。

💡 小技巧

CSS 选择器是 BeautifulSoup 的强力补充。例如 .post h2 a 表示「class 为 post 的元素下面的 h2 下面的 a」。

第 3 小节

生成每日简报

把数据格式化成可读文本

抓取到的数据如果只是躺在 CSV 里，还不够「简报」。我们可以用 Python 把它们格式化成一段文本，保存为 Markdown 或纯文本文件：

generate_brief.py
from datetime import date

# 假设已经从网页中解析到这些数据
weather = "晴，22℃~30℃"
news = [
    "Python 发布新版本",
    "人工智能最新进展",
    "开源社区周刊",
]
quote = "代码是写给人看的，顺便让机器运行。"

today = date.today().isoformat()
lines = [
    f"# 每日简报 {today}",
    "",
    "## 天气",
    weather,
    "",
    "## 新闻",
]
for i, title in enumerate(news, 1):
    lines.append(f"{i}. {title}")

lines.extend(["", "## 今日一句", quote])

brief = "\n".join(lines)
with open(f"brief_{today}.md", "w", encoding="utf-8") as f:
    f.write(brief)

print(brief)

运行后会生成一个 Markdown 文件，里面包含天气、新闻列表和一句话。你可以每天早上运行一次脚本，得到当天的简报。
