第 1 小节

安装与基本用法

把 HTML 变成可以搜索的汤

上一模块我们用 requests 拿到了 HTML 字符串，但它只是一大段文本。要从里面精准找到标题、链接、表格，需要一位「解剖师」——BeautifulSoup。

BeautifulSoup 会把 HTML 字符串解析成一棵结构化的树，然后让我们按标签名、CSS 类、属性来查找节点。先安装它：

终端命令
pip install beautifulsoup4

最简单的用法只有四步：请求、解析、查找、输出。

bs_basic.py
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
resp = requests.get(url)

soup = BeautifulSoup(resp.text, "html.parser")
print(soup.title.string)            # 提取 title 标签里的文本

BeautifulSoup(网页内容, "html.parser") 会创建一个 soup 对象。然后就可以用 soup.title、soup.h1、soup.find("tag") 等方法查找节点。

🔑 本小节小结

BeautifulSoup 负责解析 HTML；requests 负责下载 HTML。两者配合是 Python 爬虫最常见的组合。

第 2 小节

提取标题与所有链接

find、find_all 与 get 方法

网页里的链接都在 <a href="..."> 标签里。BeautifulSoup 的 find_all 可以一次性找出所有 <a> 标签，然后读取它们的 href 属性。

extract_links.py
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
resp = requests.get(url)
soup = BeautifulSoup(resp.text, "html.parser")

# 提取标题
title = soup.title.string if soup.title else "无标题"
print("标题：", title)

# 提取所有链接
links = []
for a in soup.find_all("a"):
    href = a.get("href")
    text = a.get_text(strip=True)
    if href:
        links.append((text, href))

for text, href in links[:10]:       # 只打印前 10 条
    print(f"{text} -> {href}")

这里用了几个常用方法：

  • soup.find_all("a")：找出所有 <a> 标签。
  • a.get("href")：读取 href 属性，不存在时返回 None。
  • a.get_text(strip=True)：读取标签内的文字，并去掉首尾空白。
💡 小技巧

很多链接是相对路径，例如 /about。如果要访问完整地址，需要拼上域名："https://example.com" + href。

第 3 小节

提取表格数据

把网页表格变成 Python 列表

网页表格通常用 <table>、<tr>（行）、<td>（单元格）组成。BeautifulSoup 可以一层层把它们拆出来。

extract_table.py
import requests
from bs4 import BeautifulSoup

html_doc = """
<table>
  <tr><th>姓名</th><th>年龄</th></tr>
  <tr><td>小明</td><td>18</td></tr>
  <tr><td>小红</td><td>19</td></tr>
</table>
"""

soup = BeautifulSoup(html_doc, "html.parser")
table = soup.find("table")
rows = []

for tr in table.find_all("tr"):
    cells = [td.get_text(strip=True) for td in tr.find_all(["td", "th"])]
    rows.append(cells)

for row in rows:
    print(row)

输出结果：

运行结果
['姓名', '年龄']
['小明', '18']
['小红', '19']

拿到这个二维列表后，就可以存进 CSV、Excel 或数据库，下一模块会详细介绍。

第 4 小节

综合实战

抓取文章列表页并提取标题链接

假设某博客的文章列表 HTML 结构如下（实际练习时，请使用允许抓取的公开站点，或把下面 HTML 保存为本地文件解析）：

blog.html（示例片段）
<article class="post">
  <h2><a href="/post/python-101">Python 入门指南</a></h2>
  <span class="date">2026-08-01</span>
</article>
<article class="post">
  <h2><a href="/post/web-crawl">爬虫基础</a></h2>
  <span class="date">2026-08-05</span>
</article>

提取所有文章标题、链接和日期的代码：

blog_spider.py
from bs4 import BeautifulSoup

html_doc = """...上面那段 HTML..."""
soup = BeautifulSoup(html_doc, "html.parser")

for article in soup.find_all("article", class_="post"):
    a = article.find("h2").find("a")
    title = a.get_text(strip=True)
    link = a.get("href")
    date = article.find("span", class_="date").get_text(strip=True)
    print(f"{date} | {title} | {link}")

练习任务：找一个允许抓取的博客或新闻列表页，用浏览器开发者工具（F12）观察每篇文章的 HTML 结构，然后修改上面的代码，把标题和链接提取出来。
