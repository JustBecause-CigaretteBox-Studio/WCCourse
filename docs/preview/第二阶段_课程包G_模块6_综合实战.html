第 1 小节

红石就是电路：从拉杆到「会思考的电线」

在《我的世界》里，红石粉铺在地上就是「电线」，能传信号；拉杆一扳，线路就有电（记作 1），扳回去就没电（记作 0）。这和我们前几章讲的一样——两种状态「通电」和「断电」，就是计算机最底层的 0 和 1。

真正的魔法是一个叫红石火把的东西：它插在方块侧面时正常亮着（输出 1）；但如果从下面接到电，它就被「压灭」（输出 0）。这正好是一个非门（NOT）：输入有电反而输出没电，输入没电反而输出有电。

💡 关键一步

一个普通的开关，只能「原样」传信号；而红石火把能「翻转」信号。就靠这个「翻转」，无数个小元件按规则组合，从最朴素的开关，变成了能算数的芯片——这正是模块 1《从灯泡到芯片》里那颗 CPU 的真相。

接下来只要学会怎么把几个这样的元件拼起来，你就能做出「会做判断题」的电路，再进一步做出「会算加法」的电路。

第 2 小节

三种基本逻辑门：AND / OR / NOT

只有「翻转」还不够。计算机靠三种基本逻辑门组合出一切运算：

  • NOT 非门：红石火把。输入 1 → 输出 0，输入 0 → 输出 1（把信号反过来）。
  • AND 与门：两个输入都有电，输出才有电。红石里用两个火把接力实现。
  • OR 或门：任意一个输入有电，输出就有电。把两根线并在一起即可。

这些门，就是你在编程语言里天天写的 &&、||、!。下面把这三个门写成函数——你在《我的世界》里用红石搭的东西，在代码里就是几个返回 0/1 的小函数：

Python 实现三个逻辑门
def not_gate(a):        return 1 - a                     # 翻转
def and_gate(a, b):     return 1 if (a == 1 and b == 1) else 0
def or_gate(a, b):      return 1 if (a == 1 or b == 1) else 0
def xor_gate(a, b):     return 1 if (a != b) else 0      # 异或：不同为 1

print(and_gate(1, 1))   # 1
print(xor_gate(1, 1))   # 0  → 1+1 的本位是 0
gates.cpp
int not_gate(int a)        { return a ? 0 : 1; }
int and_gate(int a, int b) { return (a == 1 && b == 1) ? 1 : 0; }
int or_gate(int a, int b)  { return (a == 1 || b == 1) ? 1 : 0; }
int xor_gate(int a, int b) { return (a != b) ? 1 : 0; }   // 异或：不同为 1

#include <iostream>
int main() {
    std::cout << and_gate(1, 1) << "\n";   // 1
    std::cout << xor_gate(1, 1) << "\n";   // 0  → 1+1 的本位是 0
    return 0;
}

注意 xor_gate（异或）：两个输入「不同」时才是 1。它看起来简单，却是后面「算加法」的关键零件。

第 3 小节

拼出「半加器」：先会算 1 + 1

二进制里，1 + 1 = 10（进位 1，本位 0）。拆开看其实是两件事：本位（Sum）和进位（Carry）。我们把四种输入列出来：

AB本位 Sum进位 Carry
0000
0110
1010
1101

盯着表看：本位 = A 异或 B（不同才为 1），进位 = A 与 B（同时为 1 才进位）。也就是说，一个半加器 = 一个 XOR 门 + 一个 AND 门。而 XOR 门本身又能用第 2 小节的门拼出来：XOR = (A OR B) AND NOT(A AND B)。

在《我的世界》用红石实现：两根拉杆进去，一盏灯亮表示「本位」、另一盏灯亮表示「进位」。模块 2《CPU 电脑的大脑》里说，CPU 做加法的那个部件叫算术逻辑单元（ALU）——它最基础的零件，就是这个半加器。

第 4 小节

串成完整计算器：从全加器到 ALU

把前面所有零件用上，做出一台能算加减法的机器

半加器只能算一位、还不管「低位有没有进位」。要算多位数，需要全加器：它比半加器多一个输入——来自低位的进位 Cin，输出本位 Sum 和向高位的进位 Cout。拆开看，全加器 = 两个半加器 + 一个或门。

把 n 个全加器像糖葫芦一样串起来——低位的 Cout 接高位的 Cin——就是一条「进位链」，能算 n 位加法。这就是 CPU 里加法器的骨架。再给它加上减法（用补码把减法变成加法）和显示（把二进制结果译码成七段数码管），一台计算器就成型了。

下面用代码模拟这个「进位链」：每个全加器还是那几个逻辑门，区别只是把上一个的进位喂给下一个。

Python 模拟进位链（4 位加法器）
def half_adder(a, b):
    s = 1 if (a != b) else 0                # 本位 = 异或
    c = 1 if (a == 1 and b == 1) else 0     # 进位 = 与
    return s, c

def full_adder(a, b, cin):
    s1, c1 = half_adder(a, b)
    s2, c2 = half_adder(s1, cin)
    return s2, 1 if (c1 == 1 or c2 == 1) else 0

# 把两个 4 位二进制数相加（列表低位在前）
def add4(x, y):
    cin = 0
    out = []
    for i in range(4):
        s, cin = full_adder(x[i], y[i], cin)
        out.append(s)
    return out, cin   # out 是结果，cin 是最高位进位（溢出）

print(add4([1, 1, 0, 0], [1, 0, 0, 0]))   # 4 + 1 = 5 → [0,1,0,1], 进位 0
adder.cpp
// 半加器：s = 本位，c = 进位
void half_adder(int a, int b, int& s, int& c) {
    s = (a != b) ? 1 : 0;
    c = (a == 1 && b == 1) ? 1 : 0;
}

// 全加器：多一个低位进位 cin
void full_adder(int a, int b, int cin, int& s, int& cout) {
    int s1, c1, s2, c2;
    half_adder(a, b, s1, c1);
    half_adder(s1, cin, s2, c2);
    s = s2;
    cout = (c1 == 1 || c2 == 1) ? 1 : 0;
}

#include <iostream>
int main() {
    int s, c;
    full_adder(1, 1, 0, s, c);     // 1 + 1 + 0
    std::cout << "本位=" << s << " 进位=" << c << "\n";
    return 0;
}
