第 1 小节

IP：电脑的门牌号

要在互联网上找到一台设备，光靠名字可不行，得有一个数字地址，这就是 IP 地址（Internet Protocol Address）。你可以把它想象成现实生活中的门牌号：快递能送到你家，是因为有省、市、街道、门牌号这套分层地址。

最常见的 IPv4 地址由 4 段数字组成，每段 0-255，比如 192.168.1.1。但因为互联网上的设备越来越多，IPv4 地址不够用了，于是出现了 IPv6，格式像 fe80::1ff:fe23:4567:890a，地址空间大到可以给地球上每一粒沙子都分一个。

IPv4
4 组 0-255 数字，用点分隔。例如 223.5.5.5，约 43 亿个地址。
IPv6
8 组 16 进制数，用冒号分隔。地址数量是 2^128，几乎用不完。

IP 地址还分公网 IP和私网 IP。你家里所有设备（手机、电脑、平板）的局域网地址通常是 192.168.x.x，这是私网地址，只在你的路由器内部有效。而路由器连到运营商那边拿到的才是公网 IP，全世界唯一。

check_ip.py
import socket

# 获取本机主机名，再解析成本机 IP
hostname = socket.gethostname()
print("主机名：", hostname)
print("本机 IP：", socket.gethostbyname(hostname))

# 获取某个域名的 IP（后面会详细讲）
print("example.com 的 IP：", socket.gethostbyname("example.com"))
第 2 小节

DNS：互联网的电话簿

人脑记名字容易，记数字难。让你天天背 104.18.24.46 才能上某个网站，谁受得了？所以互联网引入了 DNS（Domain Name System，域名系统），它就像一本巨大的电话簿：你把域名（比如 www.example.com）交给 DNS，它帮你查到对应的 IP。

DNS 查询不是一步到位的。它会先去问「根域名服务器」：「.com 在哪？」；根服务器告诉它「.com 的顶级域名服务器地址」；再问顶级服务器：「example.com 在哪？」；最后问到负责 example.com 的权威域名服务器，拿到最终 IP。整个过程通常只需要几十毫秒。

💡 类比

域名 = 联系人姓名；IP 地址 = 电话号码；DNS = 电话簿/通讯录。

Python 的 socket 模块封装了 DNS 查询。你可以用 gethostbyname 查 IPv4，也可以用 getaddrinfo 查更详细的信息（包括 IPv6、端口类型等）。

dns_lookup.py
import socket

# 基础查询：域名 → IPv4
domain = "www.example.com"
ip = socket.gethostbyname(domain)
print(f"{domain} 的 IPv4 是 {ip}")

# 更详细的查询：协议族、套接字类型、IP 等
info = socket.getaddrinfo("www.example.com", None)
print("\n更详细的信息：")
for item in info[:3]:  # 只看前 3 条
    family, socktype, proto, canonname, sockaddr = item
    print(f"  协议族: {family}, 类型: {socktype}, 地址: {sockaddr}")

运行后你会发现，一个域名可能对应多个 IP。这是网站的负载均衡策略：DNS 会把用户分散到不同的服务器，避免一台机器被挤爆。

第 3 小节

动手：批量查询域名 IP

在真实开发中，经常需要检查一批域名是否解析正常、IP 是否变化。与其一个个去命令行敲 nslookup，不如写个 Python 小脚本批量查。

batch_dns.py
import socket

domains = [
    "www.example.com",
    "www.python.org",
    "www.github.com",
    "this-domain-does-not-exist-12345.xyz"
]

for domain in domains:
    try:
        ip = socket.gethostbyname(domain)
        print(f"✅ {domain:45s} -> {ip}")
    except socket.gaierror:
        print(f"❌ {domain:45s} -> 无法解析（域名不存在或没联网）")

这个脚本展示了网络编程中非常常见的模式：尝试执行 → 捕获异常 → 给出友好提示。域名解析可能因为网络断开、域名拼写错误、DNS 服务器故障而失败，所以代码里用 try/except 包住查询。

⚠️ 注意

查询外部域名需要联网。如果你当前没有网络，所有外部域名都会解析失败，这是正常的，不是代码 bug。

第 4 小节

综合实战：做一个域名 IP 查询器

输入域名，输出它的 IP 和解析结果

把前几节的内容串起来：读取用户输入的域名，用 socket.gethostbyname 查询 IPv4，再用 getaddrinfo 列出所有解析结果。如果解析失败，告诉用户可能的原因。

domain_lookup_tool.py
import socket

def lookup(domain):
    print(f"\n🔍 正在查询：{domain}")
    try:
        ipv4 = socket.gethostbyname(domain)
        print(f"  IPv4: {ipv4}")
    except socket.gaierror as e:
        print(f"  解析失败：{e}")
        return

    try:
        info = socket.getaddrinfo(domain, None)
        print(f"  共解析到 {len(info)} 个结果")
        for i, item in enumerate(info[:5], 1):
            print(f"    {i}. {item[4]}")
    except Exception as e:
        print(f"  详细查询失败：{e}")

if __name__ == "__main__":
    # 也可以改成 input("请输入域名：") 做成交互式
    for domain in ["baidu.com", "python.org", "localhost"]:
        lookup(domain)

这是一个真正能用的小工具。你可以把它改成交互式：让用户在控制台输入域名，回车就显示结果。也可以把结果保存到文本文件里，做成一个「域名巡检脚本」。
