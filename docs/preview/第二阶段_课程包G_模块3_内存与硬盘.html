第 1 小节

书桌与书柜：RAM 与 ROM 的区别

计算机存储设备可以分成两大类：一类是「正在用」的，一类是「长期存」的。我们用书桌和书柜来比喻：

书桌（RAM）书柜（硬盘/SSD）
放正在看的书放暂时不看的书
拿取极快拿取较慢
断电后清空断电后仍在
容量较小容量较大
价格较贵价格便宜

内存（RAM，随机存取存储器）就是 CPU 的「书桌」。程序运行时，操作系统会把当前需要的数据和代码从硬盘搬到内存里，CPU 再从内存读写。内存速度非常快，但断电后数据会全部消失。

硬盘/SSD则是「书柜」，容量大、断电不丢，但读写速度慢得多。我们平时保存文件、安装软件，都是往硬盘里写。ROM（只读存储器）是另一种特殊的非易失存储，电脑主板上的 BIOS/UEFI 就存在 ROM 里，用来在开机时引导系统。

第 2 小节

内存地址：每个字节都有门牌号

内存就像一栋巨大的宿舍楼，每个房间住 1 个字节（8 位），每个房间都有唯一的门牌号，这个门牌号就是 内存地址。CPU 想读写数据时，会先给出地址，再从对应房间取数据。

地址 0x000001001001
地址 0x000111100011
地址 0x000200000000
⋯
地址 0xFFFF10101010

你写程序时定义的变量名，编译后都会变成具体的内存地址。比如 int x = 42，编译器可能会把 42 存到地址 0x7ffd_1234 开始的 4 个字节里。之后你读取 x，CPU 就去这个地址拿。

用列表模拟内存
# 模拟一段 16 字节的内存，初始都是 0
memory = [0] * 16

# CPU 写入：把地址 3 的房间改成 42
address = 3
memory[address] = 42

# CPU 读取：从地址 3 取出数据
print(memory[address])  # 42
memory_demo.cpp
#include <iostream>
using namespace std;

int main() {
    // 模拟一段 16 字节的内存，初始都是 0
    int memory[16] = {0};

    // CPU 写入：把地址 3 的房间改成 42
    int address = 3;
    memory[address] = 42;

    // CPU 读取：从地址 3 取出数据
    cout << memory[address] << endl;  // 42
    return 0;
}

真实的内存地址非常大。32 位系统最多能识别约 4 GB 内存，64 位系统则能识别天文数字般的内存空间（虽然实际在2026年主板插不了那么多）。

第 3 小节

硬盘与持久化：为什么文件不会随关机消失

内存虽然快，但有一个致命缺点：断电即失。如果你正在写文档，突然停电，内存里的内容还没来得及保存，就会全部消失。所以程序会周期性地把数据写回硬盘，硬盘用磁性（机械硬盘）或闪存（SSD）来长期保存电荷状态，断电后数据依然在。

机械硬盘（HDD）靠高速旋转的盘片和磁头读写，容量大、便宜，但速度慢、怕震动。固态硬盘（SSD）没有机械部件，用闪存芯片存储，速度快、抗震，但单位容量价格更高，且有写入寿命限制。

💡 小知识

「保存文件」的本质就是把内存里的数据复制到硬盘。很多软件都有自动保存功能，就是为了防止断电或崩溃导致内存数据丢失。

第 4 小节

综合实战：用 Python 查看内存和磁盘

把书桌与书柜的概念变成可观测的数据

Python 的 psutil 库可以读取系统信息。psutil 是一个第三方库——别人写好并公开的工具包，先用 pip install 装一次（方法在代码下方），之后就能 import 使用。下面的代码能查看当前内存和磁盘的使用情况，让你直观看到「书桌」和「书柜」各用了多少。

查看内存与磁盘使用
import psutil   # psutil 是第三方库，专门用来读取系统信息

# 内存信息（书桌）
mem = psutil.virtual_memory()
print("总内存:", round(mem.total / 1000000000, 2), "GB")   # round(x, 2) 表示保留两位小数
print("已使用:", round(mem.used / 1000000000, 2), "GB")
print("可用:  ", round(mem.available / 1000000000, 2), "GB")
print("使用率:", mem.percent, "%")

# 磁盘信息（书柜）
disk = psutil.disk_usage("/")   # Mac/Linux 写 "/"；Windows 也可以写成 "C:/"
print("磁盘总容量:", round(disk.total / 1000000000, 2), "GB")
print("已使用:    ", round(disk.used / 1000000000, 2), "GB")
print("剩余:      ", round(disk.free / 1000000000, 2), "GB")
print("使用率:    ", disk.percent, "%")
inspect_memory_disk.cpp
#include <iostream>
#include <windows.h>
using namespace std;

// ⚠️ 选读：C++ 没有现成的库函数可查内存，
// 必须调用 Windows 系统提供的 API（应用程序接口）。
// 这段代码比 Python 版本复杂不少，看懂大意即可，不要求掌握。
int main() {
    MEMORYSTATUSEX mem;          // 一张用来装内存信息的「表格」
    mem.dwLength = sizeof(mem);
    GlobalMemoryStatusEx(&mem);  // 请 Windows 把数据填进表格

    cout << "总内存: " << mem.ullTotalPhys / 1000000000.0 << " GB" << endl;
    cout << "可用:   " << mem.ullAvailPhys / 1000000000.0 << " GB" << endl;
    cout << "使用率: " << mem.dwMemoryLoad << "%" << endl;
    return 0;
}
📌 为什么 C++ 版本和 Python 版本差这么多？

查看系统信息需要调用操作系统提供的 API。Python 有现成的 psutil 库把这些调用打包好了，所以代码很短；C++ 要直接和 Windows API 打交道，代码又长又绕。这也是为什么「快速做个小工具」时大家更爱用 Python。C++ 版本看看就好，不需要记住。

如果你的电脑没装 psutil，可以先在终端运行：

安装 psutil
