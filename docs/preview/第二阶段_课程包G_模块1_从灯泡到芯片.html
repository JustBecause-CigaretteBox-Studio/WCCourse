第 1 小节

二进制：只有 0 和 1 的世界

计算机内部并不认识「A」「中」「3.14」这些符号，它只认识两种状态：通电 和 断电。我们把通电记作 1，断电记作 0。这就是二进制——整个世界只有 0 和 1。

你可以把一根电线想象成一个灯泡开关：

开关二进制灯泡
OFF0灭
ON1亮

一个 0 或 1 叫做 1 个 比特（bit）。8 个比特组成 1 个 字节（byte），可以表示 0～255 之间的数字。

用 Python 观察二进制
# 把十进制转成二进制
print(bin(5))     # 0b101，问问AI,bin()有什么作用，输出前面为什么有个0b
print(bin(13))    # 0b1101

# 把二进制转回十进制
print(int("0b1010", 2))  # 10

# 1 字节是 8 个比特，能表示的最大值 = 8 个 2 相乘再减 1
print(2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 - 1)  # 255
binary_demo.cpp
#include <iostream>
using namespace std;

// 把一个十进制数转成二进制并打印出来
void print_binary(int n) {
    int bits[8];              // 最多看 8 位
    int count = 0;
    while (n > 0) {
        bits[count] = n % 2;  // 除以 2 的余数就是当前这一位
        n = n / 2;
        count = count + 1;
    }
    // 倒着输出，才是正确的二进制顺序
    for (int i = count - 1; i >= 0; i--) {
        cout << bits[i];
    }
    cout << endl;
}

int main() {
    // 把十进制转成二进制
    print_binary(5);    // 101
    print_binary(13);   // 1101

    // 1 字节能表示的最大值：8 个 2 相乘再减 1
    cout << 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 - 1 << endl;  // 255
    return 0;
}

二进制的位数越多，能表示的信息就越多。32 位可以表示约 42 亿个数，64 位则能表示一个天文数字。CPU、内存、硬盘里的所有数据，最终都是一长串 0 和 1。

不难想到，计算机显然需要巨量的0和1。要让物理世界承载这两个数字，最自然的办法就是用电的两种状态：通电代表 1，断电代表 0。

CPU 里塞进了上百亿个晶体管（可以想成开关）。每个开关都在以每秒几十亿次的频率翻转：通、断、通、断……对应着 1、0、1、0……目前只有半导体能在纳米尺度上实现这种极速、可控、可逆的通断，同时还不至于把电脑烧成电磁炉。

第 2 小节

逻辑门：芯片里的开关电路

如果只有一根电线，我们只能表示「有电/没电」。但把几根电线连起来，就可以做判断。芯片里最基本的判断单元叫做逻辑门，它根据输入的 0/1 决定输出什么。

最常见的三个逻辑门：

  • 与门 AND：两个输入都为 1，输出才为 1。
  • 或门 OR：只要有一个输入为 1，输出就为 1。
  • 非门 NOT：输入是 1 就输出 0，输入是 0 就输出 1。

这些门电路本质上是用晶体管搭出来的。晶体管就像一个电控开关：给控制端加电，开关就闭合；不加电，开关就断开。现代 CPU 里有几十亿到上百亿个晶体管，它们组合成更复杂的门，再组合成加法器、寄存器、控制器。

用 Python 模拟逻辑门
def AND(a, b):
    return 1 if a == 1 and b == 1 else 0

def OR(a, b):
    return 1 if a == 1 or b == 1 else 0

def NOT(a):
    return 0 if a == 1 else 1

# 测试
print("AND(1, 0) =", AND(1, 0))  # 0
print("OR(1, 0)  =", OR(1, 0))   # 1
print("NOT(1)    =", NOT(1))     # 0
logic_gates.cpp
#include <iostream>
using namespace std;

int AND(int a, int b) {
    return (a == 1 && b == 1) ? 1 : 0;
}

int OR(int a, int b) {
    return (a == 1 || b == 1) ? 1 : 0;
}

int NOT(int a) {
    return (a == 1) ? 0 : 1;
}

int main() {
    cout << "AND(1, 0) = " << AND(1, 0) << endl;  // 0
    cout << "OR(1, 0)  = " << OR(1, 0) << endl;   // 1
    cout << "NOT(1)    = " << NOT(1) << endl;     // 0
    return 0;
}
第 3 小节

加法器：用门电路做加减法

计算机不会做我们熟悉的「1+1=2」这种十进制加法，它只做二进制加法。而二进制加法规则非常简单：

算式结果说明
0 + 00根本不用说明
0 + 11根本不用说明
1 + 01根本不用说明
1 + 110写 0，向高位进 1

只做两个 1 位二进制数相加的电路叫半加器。它有两个输出：一个叫「和（sum）」，一个叫「进位（carry）」。例如 1+1，sum=0，carry=1。

如果还要考虑来自低位的进位，就需要全加器。把很多个全加器串起来，就能做 8 位、16 位、32 位甚至 64 位的加法。这就是 CPU 里 ALU（算术逻辑单元） 的雏形。

用 Python 模拟半加器
# 上一小节的逻辑门函数，直接拿来用
def AND(a, b):
    return 1 if a == 1 and b == 1 else 0

def OR(a, b):
    return 1 if a == 1 or b == 1 else 0

def XOR(a, b):
    # 异或：两个输入「不一样」时输出 1
    return 1 if a != b else 0

def half_adder(a, b):
    sum_bit = XOR(a, b)   # 和：只有一位是 1 时为 1
    carry = AND(a, b)     # 进位：两位都是 1 时为 1
    print(a, "+", b, "= 和", sum_bit, ", 进位", carry)

for a in [0, 1]:
    for b in [0, 1]:
        half_adder(a, b)
half_adder.cpp
#include <iostream>
using namespace std;

// 上一小节的逻辑门函数，直接拿来用
int AND(int a, int b) {
    return (a == 1 && b == 1) ? 1 : 0;
}

int XOR(int a, int b) {
    // 异或：两个输入「不一样」时输出 1
    return (a != b) ? 1 : 0;
}

void half_adder(int a, int b) {
    int sum_bit = XOR(a, b);   // 和：只有一位是 1 时为 1
    int carry = AND(a, b);     // 进位：两位都是 1 时为 1
    cout << a << " + " << b << " = 和 " << sum_bit << ", 进位 " << carry << endl;
}

int main() {
    int inputs[2] = {0, 1};
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            half_adder(inputs[i], inputs[j]);
        }
    }
    return 0;
}

现代 CPU 里的 ALU 不仅能做加法，还能做减法（补码）、比较大小、位运算等。所有这些复杂操作，拆开看都是由 AND、OR、NOT 这样的简单门一层层组合出来的。

第 4 小节

综合实战：做一个 1 位全加器模拟器

用代码把二进制、逻辑门、加法器串起来

前面我们分别学了二进制、逻辑门和半加器。现在把它们合起来，写一个真正的 1 位全加器：输入三个比特（a、b 和来自低位的进位 c_in），输出两个比特（和 s、向高位的进位 c_out）。

全加器的逻辑可以这样拆：

  • 先用一个半加器算 a + b，得到中间和 s1 和中间进位 c1。
  • 再用一个半加器算 s1 + c_in，得到最终和 s 和进位 c2。
  • 最终向高位的进位 c_out = c1 OR c2。
1 位全加器 Python 实现
# 前面小节的逻辑门函数
def AND(a, b):
    return 1 if a == 1 and b == 1 else 0

def OR(a, b):
    return 1 if a == 1 or b == 1 else 0

def XOR(a, b):
    return 1 if a != b else 0

# 半加器拆成「和」与「进位」两个小函数
def half_sum(a, b):
    return XOR(a, b)

def half_carry(a, b):
    return AND(a, b)

def full_sum(a, b, c_in):
    # 先算 a + b 的中间和，再和低位进位相加
    return half_sum(half_sum(a, b), c_in)

def full_carry(a, b, c_in):
    c1 = half_carry(a, b)                  # 第一步产生的进位
    c2 = half_carry(half_sum(a, b), c_in)  # 第二步产生的进位
    return OR(c1, c2)                      # 任意一步有进位，就向高位进位

# 验证所有 8 种输入组合
print("a b c_in | sum carry")
for a in [0, 1]:
    for b in [0, 1]:
        for c_in in [0, 1]:
            print(a, b, " ", c_in, " |  ", full_sum(a, b, c_in), "    ", full_carry(a, b, c_in))
full_adder.cpp
#include <iostream>
using namespace std;

// 前面小节的逻辑门函数
int AND(int a, int b) {
    return (a == 1 && b == 1) ? 1 : 0;
}

int OR(int a, int b) {
    return (a == 1 || b == 1) ? 1 : 0;
}

int XOR(int a, int b) {
    return (a != b) ? 1 : 0;
}

// 半加器拆成「和」与「进位」两个小函数
int half_sum(int a, int b) {
    return XOR(a, b);
}

int half_carry(int a, int b) {
    return AND(a, b);
}

int full_sum(int a, int b, int c_in) {
    // 先算 a + b 的中间和，再和低位进位相加
    return half_sum(half_sum(a, b), c_in);
}

int full_carry(int a, int b, int c_in) {
    int c1 = half_carry(a, b);                  // 第一步产生的进位
    int c2 = half_carry(half_sum(a, b), c_in);  // 第二步产生的进位
    return OR(c1, c2);                          // 任意一步有进位，就向高位进位
}

int main() {
    cout << "a b c_in | sum carry" << endl;
    int inputs[2] = {0, 1};
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            for (int k = 0; k < 2; k++) {
                int a = inputs[i];
                int b = inputs[j];
                int c_in = inputs[k];
                cout << a << " " << b << "   " << c_in
                     << "   |  " << full_sum(a, b, c_in)
                     << "     " << full_carry(a, b, c_in) << endl;
            }
        }
    }
    return 0;
}
