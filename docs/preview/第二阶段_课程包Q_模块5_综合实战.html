第 1 小节

从真实数据开始

消费记录或步数都可以

第 2 小节

三步快速分析

分类汇总、趋势统计、异常检查

拿到账单后，通常会问三个问题：钱主要花在哪些类别上？每天花了多少钱？有没有哪天特别离谱？这三个问题正好对应 Pandas 的三种操作：分组聚合、按日期统计、异常值识别。

spending_analysis.py
import pandas as pd

df = pd.read_csv("bills.csv")

# 1. 按类别汇总
print("=== 各类别总支出 ===")
print(df.groupby("类别")["金额"].sum().sort_values(ascending=False))

# 2. 按日期汇总
df["日期"] = pd.to_datetime(df["日期"])    # 把日期列转成日期类型
daily = df.groupby("日期")["金额"].sum()
print("\n=== 每日支出 ===")
print(daily)

# 3. 异常检查：找出单日支出超过平均值两倍的天
mean_daily = daily.mean()
print("\n=== 异常高消费日期 ===")
print(daily[daily > mean_daily * 2])

注意 pd.to_datetime() 这一步很重要。如果不转换，日期只是一串文字，无法按时间顺序分组或排序。转换成日期类型后，Pandas 就能识别「前后」「同一天」这些关系。

第 3 小节

动手：我的消费画像

清洗、统计、输出文字结论

现在把分析结果整理成一份「消费画像」：总支出、最花钱的类别、最花钱的一天、平均每天花多少。这些数字可以直接复制到日记、报告或朋友圈里。

my_profile.py
import pandas as pd

df = pd.read_csv("bills.csv")

total = df["金额"].sum()
category_max = df.groupby("类别")["金额"].sum().idxmax()
daily_mean = df.groupby("日期")["金额"].sum().mean()
max_day = df.groupby("日期")["金额"].sum().idxmax()

print(f"这段时期总支出：{total} 元")
print(f"最花钱的类别：{category_max}")
print(f"平均每天支出：{daily_mean:.2f} 元")
print(f"花钱最多的一天：{max_day}")

这段代码里没有新函数，只是把学过的 groupby()、sum()、mean()、idxmax() 组合起来。idxmax() 的作用是「返回最大值所在的索引」，在这里就是「最花钱的类别/日期叫什么名字」。

如果你用的是步数数据，思路完全一样：把「金额」换成「步数」，把「类别」换成「日期/星期」，就能分析自己哪一天最活跃、哪段时间最懒。

第 4 小节

综合实战：生成一份完整的消费报告

读 CSV、做统计、画图、写结论

最后一节，把前面所有技能打包成一个完整项目：读取账单 CSV，清洗并统计，画出类别饼图和每日支出折线图，最后把关键结论输出到控制台。这就是一份最小可用的数据分析报告。

full_report.py
import pandas as pd
import matplotlib.pyplot as plt

# 1. 读取数据
df = pd.read_csv("bills.csv")

# 2. 转换日期类型
df["日期"] = pd.to_datetime(df["日期"])

# 3. 统计
category_total = df.groupby("类别")["金额"].sum()
daily_total = df.groupby("日期")["金额"].sum()

# 4. 画饼图：各类别支出占比
plt.figure(figsize=(6, 6))
plt.pie(category_total, labels=category_total.index, autopct="%1.1f%%")
plt.title("支出类别占比")
plt.savefig("spending_pie.png")

# 5. 画折线图：每日支出趋势
plt.figure(figsize=(8, 4))
plt.plot(daily_total.index, daily_total.values, marker="o")
plt.title("每日支出趋势")
plt.xlabel("日期")
plt.ylabel("金额（元）")
plt.xticks(rotation=30)
plt.tight_layout()
plt.savefig("spending_trend.png")

# 6. 输出文字结论
print("=== 消费报告 ===")
print(f"总支出：{df['金额'].sum()} 元")
print(f"最花钱类别：{category_total.idxmax()}")
print(f"单日最高支出：{daily_total.max()} 元（{daily_total.idxmax().date()}）")
print("图表已保存：spending_pie.png, spending_trend.png")

运行这个项目后，你会得到两张图片和一段文字结论。试着把自己的真实账单导出成 CSV，把文件名替换进去，再跑一遍——恭喜你，这就是你的第一份 Python 数据分析报告。
