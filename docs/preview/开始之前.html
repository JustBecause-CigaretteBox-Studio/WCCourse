有 AI 还学编程干嘛

在这个 AI 普及的时代，作者整出了“成人编程”。
于是很多人问：“都有 AI 写代码了为什么还学编程？”

答案很简单：学编程是为了更好地用 AI，不只是用来写代码。

本教程适合这些人

  • 会用 AI 的
  • 不会用 AI 的
  • 大学 C++ / Python 课听不懂的
  • 总觉得 AI 不好用，听不懂话、老是说假话的
  • 想让 AI 帮自己干活，却不知道具体做法的
  • 养龙虾不会装软件的
  • 认为编程很重要，但不知道哪里重要的
  • 学过少儿编程，想重拾儿时回忆的
  • 想利用电教系统展示自己的
  • 单纯觉得编程好玩的
  • 网上找的教程听不懂的
  • 没找到自己是以上哪些人的

本教程会怎么教

本教程并不会一味地教你手搓代码浪费时间，也不会用名校封面加包浆清朝老 PPT 忽悠你。

而是会教你入门、读懂代码后，迅速学会与 AI 工作的方式，让你真正爽用 AI，把 AI 变成你最牛的牛马。

只要会识字，就能会编程！

学编程的好处

本教程带来的好处是多方面的。作者举一个简单的例子：你在学会编程的过程中，会自然学会各种专业工具的用法。

你可以：

  • ✅ 在《我的世界》手搓电脑
  • ✅ 骇入学校电教柜
  • ✅ 在 Excel 里玩俄罗斯方块
  • ✅ 用 Python 自动秒杀 / 抢课
  • ✅ 人工智能学院 GPA 4.0

如何下载 C++（Windows 手把手版）

C++ 有两条路：Dev-C++ 更像一个普通「APP」，装完打开就能写代码，几乎不用配环境； VSCode 更专业，但配置更复杂。新手建议先用方案一跑起来，以后想深入再回来装方案二。

方案一：Dev-C++（推荐给新手 ⭐）

它就像你手机上的 APP：下载 → 安装 → 打开 → 写代码 → 一键运行，全程不用配环境。竞赛常用，体积也小。

  1. 点击下方按钮进入下载页，找到绿色「Download」按钮，点击后稍等几秒会开始下载。
  2. 双击下载好的安装包，安装界面可以先选 English（装完能改成中文），然后一路「I Agree / Next」。
  3. 装完打开 Dev-C++，第一次启动会让你选语言，选择「简体中文 / Chinese」。
  4. 按 Ctrl + N 新建文件，随便写两行代码，按 F11 编译运行——能看到黑窗口里输出内容，环境就搭好了。
下载 Dev-C++

方案二：VSCode（更专业，配置较复杂）

先说清楚一个概念：VSCode 只是一个「编辑器」，本身不会编译 C++。 就像 Word 只是打字的，不代表你学会了外语。所以除了 VSCode，还要单独装一个「编译器」（这里用 MinGW-w64）。

  1. 点击下方按钮下载 VSCode 并安装。安装时「添加到 PATH」默认是勾上的，保持勾选；建议额外勾选「创建桌面快捷方式」，其余一路下一步。
  2. 下载 MinGW-w64 编译器：进入下载页后，找名字里带 Win64、UCRT 的 ZIP 压缩包（不需要安装程序的那种），下载后解压到一个路径简单的位置，例如直接解压成 C:\mingw64。
  3. 把编译器的位置告诉 Windows：在任务栏搜索框搜「编辑系统环境变量」→ 点「环境变量」→ 在下方的「系统变量」里找到 Path → 点「编辑」→「新建」→ 填入 C:\mingw64\bin（注意末尾有个 \bin）→ 一路点「确定」。
  4. 验证编译器：按 Win + R，输入 cmd 回车打开黑窗口，输入 g++ --version 回车。看到一串版本号就成功了；如果显示「不是内部或外部命令」，说明上一步的路径没填对，回去检查。
  5. 打开 VSCode，点左边的「扩展」图标（像四块积木），搜索并安装 C/C++（Microsoft 出品，通常排第一）和 Code Runner 两个插件。
  6. 在桌面新建一个文件夹（比如叫 code），用 VSCode 的「文件 → 打开文件夹」打开它，在里面新建 hello.cpp 写上代码，点右上角 ▶ 按钮运行。看到下方输出，环境就搭好了。
下载 VSCode 下载 MinGW-w64（winlibs）

如何下载 Python（Windows 手把手版）

Python 的推荐组合是「Python 本体 + VSCode」：前者是真正干活的解释器，后者是你写代码的编辑器。 跟着下面三步走，大约 10 分钟就能跑通第一段代码。

第 1 步：安装 Python 本体

  1. 点击下方按钮打开 Python 官网，点首页黄色「Download Python 3.x.x」按钮，下载安装包。
  2. 双击安装包。最关键的一步：先勾选窗口最下方的「Add python.exe to PATH」（有的版本写作 Add Python to PATH），再点「Install Now」。忘记勾选的话，电脑以后会「找不到 Python」。
  3. 验证：按 Win + R，输入 cmd 回车打开黑窗口，输入 python --version 回车。看到 Python 3.x.x 的字样就成功了。
下载 Python

第 2 步：安装 VSCode 和 Python 扩展

  1. 点击下方按钮下载 VSCode 并安装。「添加到 PATH」默认是勾上的，保持勾选；建议额外勾选「创建桌面快捷方式」，其余一路下一步。
  2. 打开 VSCode，点左边的「扩展」图标（像四块积木），搜索 Python，安装 Microsoft 出品、通常排第一的那个插件。
下载 VSCode

第 3 步：跑通第一段代码

  1. 在桌面新建一个文件夹（比如叫 code），用 VSCode 的「文件 → 打开文件夹」打开它。
  2. 在里面新建一个文件，命名为 hello.py，写上 print("你好，世界！") 并保存。
  3. 点右上角 ▶ 按钮运行。第一次运行 VSCode 可能会让你选择解释器，选带有「推荐 / Recommended」标记的那个。看到下方输出「你好，世界！」，环境就搭好了。
