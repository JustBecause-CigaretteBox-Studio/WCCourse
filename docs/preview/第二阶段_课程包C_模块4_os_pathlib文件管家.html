第 1 小节

遍历文件夹

看看里面有什么

程序处理文件时，第一步往往是「先看看某个文件夹里有什么」。Python 有两套常用工具：os 模块和 pathlib 模块。os 出现得更早，写法偏字符串；pathlib 更现代，把路径当成对象操作。

import os

# 列出当前文件夹里的所有文件和子文件夹
for name in os.listdir("."):
    print(name)

如果只想看某种类型的文件，可以加上简单的判断：

import os

for name in os.listdir("."):
    if name.endswith(".py"):
        print("Python 文件：", name)

用 pathlib 的写法更面向对象：

from pathlib import Path

folder = Path(".")
for item in folder.iterdir():
    print(item.name)
第 2 小节

批量移动与重命名

os.rename 与 Path.rename

整理文件时，经常需要把一批文件改名或移到别的位置。手动操作很枯燥，程序可以几秒钟完成。

import os

# 把 old.txt 改名为 new.txt
os.rename("old.txt", "new.txt")

# 把 file.txt 移动到 backup 文件夹里
os.rename("file.txt", "backup/file.txt")

pathlib 的版本读起来更像自然语言：

from pathlib import Path

old = Path("old.txt")
new = Path("new.txt")
old.rename(new)

批量改名通常配合循环使用，比如给所有 .txt 文件加上前缀。记住：改名和移动本质上是同一个操作，只是目标路径不同。

第 3 小节

路径操作

拼接、判断、取后缀

路径拼接最忌手动写 "\\" 或 "/"，因为 Windows 和 Mac/Linux 用的符号不一样。用 os.path.join 或 Path 的 / 运算符，程序会自动处理差异。

import os
from pathlib import Path

# os 风格
full = os.path.join("data", "2026", "report.txt")
print(full)

# pathlib 风格
p = Path("data") / "2026" / "report.txt"
print(p)

# pathlib 还能方便地取信息
print("文件名：", p.name)
print("后缀：", p.suffix)
print("所在文件夹：", p.parent)
print("是否存在：", p.exists())

Path 对象把路径的「零件」都拆好了：名字、后缀、父目录都能直接取。写文件整理工具时，这些功能非常顺手。

第 4 小节

综合实战

批量整理图片文件

假设你的桌面上有一堆截图，文件名乱七八糟。我们来写一个脚本，把所有 .png 图片统一重命名为 img_001.png、img_002.png 这样的格式。

from pathlib import Path

def rename_images(folder):
    path = Path(folder)
    png_files = sorted(path.glob("*.png"))

    for i, old_path in enumerate(png_files, start=1):
        new_name = f"img_{i:03d}.png"
        new_path = old_path.parent / new_name
        old_path.rename(new_path)
        print(f"{old_path.name} -> {new_name}")

# 在当前文件夹运行
rename_images(".")

path.glob("*.png") 会找出当前文件夹里所有匹配的文件；:03d 让数字变成 3 位，比如 1 变成 001。这个思路可以扩展到整理任何类型的文件。
