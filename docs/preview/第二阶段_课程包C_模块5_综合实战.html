第 1 小节

项目思路

为什么要自动整理下载文件夹

浏览器的下载文件夹往往堆满了各种文件：图片、文档、压缩包、安装包。手动整理很费时，但程序可以自动完成：按文件的「修改日期」把它们分进不同的年月文件夹里。

这个项目会用到的本领：

  • os / pathlib：遍历下载文件夹、创建新文件夹、移动文件。
  • datetime：把文件修改时间转成「2026-08」这样的年月字符串。
  • json：把整理记录存成日志，方便以后查看。

整理前，先在下载文件夹里建几个测试文件，运行脚本后观察它们被分类到了哪些新文件夹中。

第 2 小节

分步骤实现

先排序，再移动

核心逻辑可以拆成三步：找出文件 → 按日期分组 → 移动到对应文件夹。

from datetime import datetime
from pathlib import Path

def organize_by_month(folder_path):
    folder = Path(folder_path)

    # 遍历文件夹里的文件
    for file_path in folder.iterdir():
        if not file_path.is_file():
            continue

        # 取文件最后修改时间
        mtime = file_path.stat().st_mtime
        dt = datetime.fromtimestamp(mtime)

        # 按年月分组
        month_dir = folder / f"{dt.year}-{dt.month:02d}"
        month_dir.mkdir(exist_ok=True)

        # 移动文件
        new_path = month_dir / file_path.name
        file_path.rename(new_path)
        print(f"已移动：{file_path.name} -> {month_dir.name}/")

# 在下载文件夹运行（请把路径改成你自己的）
# organize_by_month("C:/Users/你的用户名/Downloads")

这里 file_path.stat().st_mtime 返回文件的最后修改时间戳；month_dir.mkdir(exist_ok=True) 会在文件夹不存在时自动创建，已经存在也不会报错。

第 3 小节

运行与改进

加上日志和排错

在真实电脑上运行前，建议先把脚本指向一个测试文件夹，确认效果后再处理真正的下载目录。我们还可以用 JSON 记录每次整理的结果。

import json
from datetime import datetime
from pathlib import Path

LOG_FILE = "organize_log.json"

def log_action(moved_files):
    record = {
        "time": datetime.now().isoformat(),
        "moved": moved_files
    }
    with open(LOG_FILE, "a", encoding="utf-8") as f:
        f.write(json.dumps(record, ensure_ascii=False) + "\n")

def organize_with_log(folder_path):
    folder = Path(folder_path)
    moved = []

    for file_path in folder.iterdir():
        if not file_path.is_file():
            continue

        mtime = file_path.stat().st_mtime
        dt = datetime.fromtimestamp(mtime)
        month_dir = folder / f"{dt.year}-{dt.month:02d}"
        month_dir.mkdir(exist_ok=True)

        new_path = month_dir / file_path.name
        file_path.rename(new_path)
        moved.append(str(new_path))

    log_action(moved)
    print(f"整理完成，共移动 {len(moved)} 个文件。")

# organize_with_log("./test_downloads")

日志文件 organize_log.json 每一行记录一次整理操作。如果哪天发现文件找不到了，翻开日志就能知道它最后被移到了哪里。

第 4 小节

综合实战

完整版个人文件整理助手

把前面的片段拼成一个更完整的版本：自动检测下载文件夹、跳过已分类的文件夹、记录日志。请在本地创建测试文件后再运行。

import json
import os
from datetime import datetime
from pathlib import Path

LOG_FILE = "organize_log.json"

def ensure_test_files(folder):
    # 如果测试文件夹为空，自动生成几个空文件
    path = Path(folder)
    if any(path.iterdir()):
        return
    path.mkdir(exist_ok=True)
    for i in range(3):
        (path / f"test{i}.txt").write_text("hello")
    print("已创建测试文件。")

def organize_downloads(folder_path):
    folder = Path(folder_path)
    folder.mkdir(exist_ok=True)
    ensure_test_files(folder)

    moved = []
    for item in folder.iterdir():
        if not item.is_file():
            continue

        mtime = item.stat().st_mtime
        dt = datetime.fromtimestamp(mtime)
        month_dir = folder / f"{dt.year}-{dt.month:02d}"
        month_dir.mkdir(exist_ok=True)

        dest = month_dir / item.name
        item.rename(dest)
        moved.append({"file": item.name, "to": str(month_dir)})

    # 写入日志
    with open(LOG_FILE, "a", encoding="utf-8") as f:
        f.write(json.dumps({
            "time": datetime.now().isoformat(),
            "moved": moved
        }, ensure_ascii=False) + "\n")

    print(f"整理完成，移动了 {len(moved)} 个文件。")

# 使用示例：先在一个测试文件夹运行
organize_downloads("./我的下载测试")

运行后，你会看到 ./我的下载测试 里出现了类似 2026-08 的文件夹，测试文件已经被分类进去。把它改成真正的下载路径，就能每天一键整理。
