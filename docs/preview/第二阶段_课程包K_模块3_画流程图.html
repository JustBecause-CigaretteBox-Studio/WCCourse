第 1 小节

程序的视觉草稿

写代码之前，先画流程图，就像盖房子之前先画图纸。流程图是程序的视觉草稿，它把「先做什么、后做什么、遇到分支怎么办」一目了然地画出来。

对新手来说，流程图最大的好处是：在写代码之前就发现逻辑漏洞。改一张图比改一堆代码容易得多。

  • 流程图负责让你想清楚结构；
  • 伪代码负责让你想清楚步骤；
  • 真实代码负责让电脑执行。

这三个阶段不要混在一起。先想清楚，再写代码，出错率会低很多。

第 2 小节

常用流程图符号

流程图有一套通用符号。记住这四种就够写大部分程序：

流程图符号
椭圆：开始 / 结束
矩形：执行一个动作
菱形：判断（是 / 否 分支）
箭头：流程方向

菱形只放一个问题，出去两条箭头，分别标注「是 / 否」或「真 / 假」。不要把整个动作都塞进菱形里。

第 3 小节

画一个登录流程

假设做一个简单的登录功能：用户输入密码，程序判断对不对。对就进入主页，错就提示重新输入。

登录流程图
[开始]
  ↓
[输入用户名和密码]
  ↓
<密码正确？>
  ├─ 是 → [进入主页] → [结束]
  └─ 否 → [提示错误] → [重新输入]

注意菱形的用法：里面只有一个判断问题。真正的动作「输入密码」「提示错误」都放矩形里。
