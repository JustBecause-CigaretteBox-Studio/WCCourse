第 1 小节

程序里的便签格式

什么是 JSON

上一章我们学会了把纯文字写进文件。但程序里的数据往往更复杂：一个玩家可能有名字、等级、金币；一个配置可能包含开关、数字、列表。如果直接写成一大段字符串，读起来会很麻烦。

JSON 就是一种「程序里的便签格式」。它长得像 Python 的字典和列表，几乎所有编程语言都能读懂。你可以把它理解为一种通用翻译本：Python 把字典写成 JSON，别的程序（或者下一次运行的 Python）再读回字典。

import json

player = {
    "name": "小鸡",
    "level": 5,
    "coins": 120,
    "items": ["药水", "火把"]
}

# 把字典变成 JSON 字符串
text = json.dumps(player, ensure_ascii=False)
print(text)

上面代码中，json.dumps() 里的 s 是 string 的意思，表示「转成字符串」。ensure_ascii=False 让中文保持原样，不要变成 \u 编码。

反过来，如果有一段 JSON 文本，也能用 json.loads() 变回字典：

import json

text = '{"name": "小鸡", "level": 5}'
player = json.loads(text)
print(player["name"])   # 小鸡
第 2 小节

把字典和列表存进文件

json.dump 与 json.load

dumps 和 loads 操作的是字符串。如果想直接写到文件里，Python 提供了更省事的版本：json.dump() 和 json.load()。注意没有末尾的 s，它们直接对接文件。

import json

player = {"name": "小鸡", "level": 5, "coins": 120}

with open("player.json", "w", encoding="utf-8") as f:
    json.dump(player, f, ensure_ascii=False, indent=2)

运行后，当前文件夹会出现一个 player.json，内容一目了然：

{
  "name": "小鸡",
  "level": 5,
  "coins": 120
}

读回来也很对称：

import json

with open("player.json", "r", encoding="utf-8") as f:
    player = json.load(f)

print(player["name"], "当前等级", player["level"])

一个小提醒：JSON 的文件通常用 .json 当后缀；用 encoding="utf-8" 打开，中文才不容易乱码。

第 3 小节

读写配置文件

让程序记住用户的偏好

很多程序都需要「设置」：音量大小、主题颜色、默认下载路径。这些设置用 JSON 文件保存再合适不过。程序启动时读一次，用户修改后再写回去。

import json
import os

SETTINGS_FILE = "settings.json"

# 1. 如果配置文件不存在，先给一个默认值
if not os.path.exists(SETTINGS_FILE):
    default = {"theme": "light", "volume": 80, "auto_save": True}
    with open(SETTINGS_FILE, "w", encoding="utf-8") as f:
        json.dump(default, f, ensure_ascii=False, indent=2)

# 2. 读取配置
with open(SETTINGS_FILE, "r", encoding="utf-8") as f:
    settings = json.load(f)

print("当前主题：", settings["theme"])

# 3. 修改并保存
settings["volume"] = 60
with open(SETTINGS_FILE, "w", encoding="utf-8") as f:
    json.dump(settings, f, ensure_ascii=False, indent=2)

这里用到了 os.path.exists() 判断文件是否存在。如果用户第一次打开程序，还没有配置文件，就自动创建一个默认的；之后每次启动都能读回上次的设置。

第 4 小节

综合实战

做一个可存档的小游戏角色

把前三节的内容串起来：做一个可以「存档」和「读档」的角色系统。运行程序时自动读取之前的角色；如果还没有存档，就创建一个新角色并保存。

import json
import os

SAVE_FILE = "hero.json"

def new_hero():
    return {
        "name": "冒险家",
        "hp": 100,
        "atk": 10,
        "level": 1
    }

def load_hero():
    if os.path.exists(SAVE_FILE):
        with open(SAVE_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    return None

def save_hero(hero):
    with open(SAVE_FILE, "w", encoding="utf-8") as f:
        json.dump(hero, f, ensure_ascii=False, indent=2)

# 主流程
hero = load_hero()
if hero is None:
    print("没有找到存档，创建新角色。")
    hero = new_hero()
else:
    print(f"欢迎回来，{hero['name']}！")

# 模拟打怪升级
hero["level"] += 1
hero["atk"] += 2
save_hero(hero)
print(f"已存档：等级 {hero['level']}，攻击力 {hero['atk']}")

你可以把这段代码复制到本地运行。每次运行，等级都会 +1，并且下次运行能接着上次的等级继续——这就是 JSON 作为「存档格式」的核心作用。
