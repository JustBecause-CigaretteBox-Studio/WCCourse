第 1 小节

SELECT：把数据读出来

SQL 是与数据库对话的语言。SELECT 用于从表中查询数据，是最常用的 SQL 语句。

SELECT 示例
-- 查询所有学生的所有信息
SELECT * FROM students;

-- 只查询姓名和年龄
SELECT name, age FROM students;

-- 查询年龄大于 18 岁的学生
SELECT * FROM students WHERE age > 18;

* 表示「所有列」，WHERE 用来加条件。把条件写清楚，就能快速找到想要的数据。

第 2 小节

INSERT / UPDATE / DELETE

增删改是另外三类基础操作：

  • INSERT：插入新行。
  • UPDATE：修改已有行。
  • DELETE：删除行。
增删改示例
-- 增：插入一条学生记录
INSERT INTO students (name, age) VALUES ('张三', 17);

-- 改：把张三的年龄改成 18
UPDATE students SET age = 18 WHERE name = '张三';

-- 删：删除张三这条记录
DELETE FROM students WHERE name = '张三';

特别注意：UPDATE 和 DELETE 一定要记得加 WHERE，否则会把整张表都改掉或删掉。

第 3 小节

WHERE、排序与限制结果

查询时经常需要排序、限制返回数量。SQL 用 ORDER BY 排序，用 LIMIT 限制条数。

排序与限制
-- 按年龄从小到大排
SELECT * FROM students ORDER BY age ASC;

-- 按年龄从大到小排，只取前 3 条
SELECT * FROM students ORDER BY age DESC LIMIT 3;

-- 统计学生总数
SELECT COUNT(*) FROM students;

ASC 是升序，DESC 是降序。COUNT(*) 可以帮你统计一共有多少条记录。

第 4 小节

综合实战：管理一份书单

用 SQL 完成增删改查

假设你有一张 books 表，字段有 id、title、author、rating。请完成以下 SQL：

书单练习
-- 1. 添加一本书
INSERT INTO books (title, author, rating) VALUES
    ('三体', '刘慈欣', 9);

-- 2. 查询所有书，按评分从高到低排
SELECT * FROM books ORDER BY rating DESC;

-- 3. 把《三体》的评分改成 10
UPDATE books SET rating = 10 WHERE title = '三体';

-- 4. 删除评分低于 5 的书
DELETE FROM books WHERE rating < 5;
