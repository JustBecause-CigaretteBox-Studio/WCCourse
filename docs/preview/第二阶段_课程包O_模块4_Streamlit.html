第 1 小节

认识 Streamlit

前面我们用 HTML、CSS、JS 做网页，需要同时处理三样东西。如果你更熟悉 Python，又想做数据展示、小工具或简单网页，Streamlit 是一条捷径。

Streamlit 的理念很简单：用纯 Python 写脚本，它会自动帮你生成网页界面。你不需要写 HTML、CSS 或 JavaScript。

安装 Streamlit 只需要一行命令：

终端
pip install streamlit

然后创建一个 app.py，写下你的第一个 Streamlit 应用：

app.py
import streamlit as st

st.title("我的第一个 Streamlit 网页")
st.write("Hello, World!")

在终端运行：

终端
streamlit run app.py

浏览器会自动弹出一个本地网页。这就像用 Python 写了一个脚本，但 Streamlit 替你把它包装成了可交互的网站。

第 2 小节

常用组件

Streamlit 最强大的地方是「一行代码一个组件」。下面是几个最常用的：

常用组件
import streamlit as st

# 文本输入
name = st.text_input("请输入你的名字")

# 滑动条
age = st.slider("选择你的年龄", 0, 120, 20)

# 按钮
clicked = st.button("点我")

# 下拉选择
fruit = st.selectbox("喜欢的水果", ["苹果", "香蕉", "橙子"])

# 显示结果
st.write(f"你好，{name}！你今年 {age} 岁，喜欢 {fruit}。")

每个组件都会返回一个值：输入框返回字符串，滑动条返回数字，按钮返回 True 或 False。你可以像用普通 Python 变量一样使用这些返回值。

比如下面这个「摄氏度转华氏度」小工具，只需要 5 行核心代码：

温度转换器
import streamlit as st

c = st.number_input("摄氏度", value=0.0)
f = c * 9 / 5 + 32
st.write(f"华氏度：{f}°F")

不需要写 HTML 表单，也不需要写 JS 事件监听，Streamlit 会自动处理界面刷新。

第 3 小节

交互与状态

Streamlit 默认每次用户操作都会重新运行整个脚本。这意味着普通变量会被重置，想要「记住」一些东西，就要用 session_state。

比如做一个计数器，点一次按钮加 1：

用 session_state 做计数器
import streamlit as st

# 初始化计数器
if "count" not in st.session_state:
    st.session_state.count = 0

# 点击按钮时增加计数
if st.button("+1"):
    st.session_state.count += 1

st.write(f"当前计数：{st.session_state.count}")

st.session_state 是一个特殊的字典，页面刷新后里面的值仍然保留。它适合保存登录状态、购物车、表单草稿等需要「记忆」的数据。

再举一个例子：控制一组复选框，只有在用户勾选「同意协议」后才显示提交按钮：

条件显示
import streamlit as st

agree = st.checkbox("我已阅读并同意用户协议")

if agree:
    st.success("可以继续操作")
    st.button("提交")
else:
    st.warning("请先勾选同意协议")
第 4 小节

综合实战

做一个 BMI 计算器

BMI（身体质量指数）是体重（kg）除以身高（m）的平方。我们用 Streamlit 做一个输入身高体重、自动计算并显示结果的网页。

bmi.py
import streamlit as st

st.title("BMI 计算器")

height = st.number_input("身高（米）", min_value=0.5, max_value=2.5, value=1.70)
weight = st.number_input("体重（千克）", min_value=20.0, max_value=200.0, value=60.0)

if st.button("计算 BMI"):
    bmi = weight / (height ** 2)
    st.write(f"你的 BMI 是：**{bmi:.2f}**")

    if bmi < 18.5:
        st.info("偏瘦")
    elif bmi < 24:
        st.success("正常")
    elif bmi < 28:
        st.warning("超重")
    else:
        st.error("肥胖")

实战任务：

  1. 把上面的代码保存为 bmi.py。
  2. 在终端运行 streamlit run bmi.py。
  3. 修改代码，用 st.sidebar 把输入项放到侧边栏。
  4. 挑战：给计算结果添加一个历史记录，用 st.session_state 保存最近 5 次记录。
