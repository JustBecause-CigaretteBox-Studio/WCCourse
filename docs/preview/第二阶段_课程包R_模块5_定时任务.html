第 1 小节

脚本也需要闹钟

为什么要让程序定时执行

前面的脚本都是手动双击或命令行运行的。但很多事情应该自动发生：每天凌晨备份文件、每周一早上生成周报、每月一号发送账单提醒。

定时任务就像给脚本设一个闹钟：到了指定时间，系统自己把脚本叫醒执行，不用你守着电脑。

不同系统有不同的闹钟：

  • Windows：任务计划程序
  • Linux / macOS：cron

无论用哪种，核心思路都一样：先写好一个 Python 脚本，再告诉系统「什么时候执行它」。

第 2 小节

Windows 任务计划程序

图形界面里设闹钟

Windows 自带的「任务计划程序」非常适合新手。只要打开它，创建一个基本任务，指定触发器和操作即可。

操作步骤：

  1. 按 Win + R，输入 taskschd.msc，回车。
  2. 右侧点击「创建基本任务」。
  3. 输入名称，比如「每日备份脚本」。
  4. 触发器选择「每天」或「每周」。
  5. 操作选择「启动程序」，然后浏览选择你的 Python 解释器路径。
  6. 在「添加参数」里填入你的脚本路径，例如 C:\\Users\\你\\backup.py。
  7. 完成并启用任务。

一个最简单的可定时执行脚本是：

hello_schedule.py
from datetime import datetime

now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
with open("运行日志.txt", "a") as f:
    f.write(f"脚本在 {now} 运行了一次\n")

print(f"已记录运行时间：{now}")

运行一次后，检查 运行日志.txt 有没有新增一行，就能验证定时任务是否生效。

第 3 小节

Linux / macOS 的 cron

命令行里的时间表

cron 是 Linux 和 macOS 上最常用的定时任务工具。它用一张「时间表」决定什么时候执行什么命令。

打开终端，输入 crontab -e 编辑时间表。每一行的格式是：

cron 格式
分 时 日 月 周  命令
0  8  *  *  *  python3 /home/你/backup.py

上面这行表示：每天早上 8 点 0 分，执行一次备份脚本。五个时间字段分别代表「分、时、日、月、周几」，星号表示「任意」。

常用例子：

常用 cron 例子
# 每小时执行一次
0 * * * * python3 /home/你/script.py

# 每周一早上 9 点执行
0 9 * * 1 python3 /home/你/weekly_report.py

# 每月 1 号凌晨 2 点执行
0 2 1 * * python3 /home/你/monthly_bill.py
第 4 小节

综合实战：每日备份脚本

自动把重要文件复制一份

我们每天手动备份文件太麻烦。下面这个脚本会自动把「工作文档」文件夹复制到「备份」文件夹，并给备份目录加上日期名字。

daily_backup.py
import shutil
import os
from datetime import datetime

source = "工作文档"
backup_dir = "备份"

# 按日期生成备份文件夹名
today = datetime.now().strftime("%Y-%m-%d")
target = os.path.join(backup_dir, f"备份_{today}")

# 复制整个文件夹
shutil.copytree(source, target, dirs_exist_ok=True)

print(f"已完成备份：{source} → {target}")

把这个脚本加入 Windows 任务计划程序或 cron，设定每天运行一次，你就拥有了一个自动备份系统。

进阶提示：可以在脚本里加上错误处理，比如源文件夹不存在时记录日志，而不是直接报错退出。
