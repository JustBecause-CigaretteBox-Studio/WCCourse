第 1 小节

像素：屏幕上的最小色块

无论你看到的是文字、照片还是游戏画面，显示器上呈现的一切最终都是由许许多多很小的彩色小方块组成的，这些小方块叫 像素（pixel）。分辨率，比如 1920×1080，意思就是屏幕横向有 1920 个像素、纵向有 1080 个像素。

每个像素的颜色通常用三个数字表示：红（R）、绿（G）、蓝（B），每个通道 0～255。例如 (255, 0, 0) 是纯红，(0, 255, 0) 是纯绿，(255, 255, 255) 是白色。三个通道组合起来，可以表示约 1670 万种颜色。

RGB 颜色
# 白色 = 红+绿+蓝 都拉满
white = (255, 255, 255)

# 黄色 = 红 + 绿
yellow = (255, 255, 0)

# 灰色 = 三个通道相等
gray = (128, 128, 128)

# 计算颜色通道占用的总位数
bits_per_pixel = 8 * 3
print("一个像素需要", bits_per_pixel, "位，约", bits_per_pixel / 8, "字节")
pixel_color.cpp
#include <iostream>
using namespace std;

int main() {
    // 白色 = 红+绿+蓝 都拉满
    int white[3] = {255, 255, 255};

    // 黄色 = 红 + 绿
    int yellow[3] = {255, 255, 0};

    // 灰色 = 三个通道相等
    int gray[3] = {128, 128, 128};

    int bits_per_pixel = 8 * 3;
    cout << "一个像素需要 " << bits_per_pixel
         << " 位，约 " << bits_per_pixel / 8 << " 字节" << endl;
    return 0;
}
第 2 小节

帧率：画面有多流畅

屏幕并不是真的在「动」，它只是在快速播放一张张静止的图片。每一张静止图片叫一 帧（frame）。每秒钟播放的帧数就是 帧率（FPS，Frames Per Second）。

  • 24 FPS：（一些）电影常用的帧率，人眼已经能感觉到连续。
  • 60 FPS：普通显示器和游戏主流帧率，很流畅。
  • 120/144 FPS：电竞显示器常见，动作更顺滑。

显示器的 刷新率（Hz） 表示屏幕每秒能更新多少次。如果显卡输出 120 FPS，但显示器只有 60 Hz，那你实际上每秒只能看到 60 帧，多出来的帧会被浪费或造成画面撕裂。所以「帧率」和「刷新率」要搭配看。

💡 小知识

一帧 1920×1080、24 位色的画面，大约需要 1920 × 1080 × 3 ≈ 6.2 MB 的显存（显卡的内存）。60 FPS 的话，显卡每秒要处理和输出约 372 MB 的图像数据。如果是 4K 分辨率或更高的刷新率，数据量会成倍增。

第 3 小节

GPU：为什么需要独立的显卡

CPU 很擅长做复杂的串行计算，比如判断、分支、逻辑。但屏幕上有几百万甚至上千万个像素，每个像素都要计算颜色，这种「大量重复但简单」的计算并不适合 CPU 来做。

于是诞生了 GPU（Graphics Processing Unit，图形处理器）。GPU 有成千上万个小型计算核心，擅长并行处理大量相似任务。渲染一帧画面时，GPU 可以同时计算成千上万个像素的颜色，效率远高于 CPU。

除了游戏画面，现在的 AI 训练（比如大模型）、视频编码、科学计算也大量依赖 GPU。它已经把「图形处理」扩展成了「通用并行计算」。

第 4 小节

综合实战：用 Python 生成一张像素图用 C++ 生成一张像素图

亲手体验像素与 RGB

下面我们安装 Pillow 库，用 Python 画一张简单的像素图。下面我们用 C++ 直接写 PPM 文本格式（无需额外库），生成一张像素图。你会看到：图像本质上就是一个二维像素数组，每个像素存着 RGB 颜色。

生成一张 256×256 的渐变图
from PIL import Image   # Pillow 是第三方库，专门用来处理图片

# 创建一个 256×256 的黑色画布
img = Image.new("RGB", (256, 256), (0, 0, 0))
pixels = img.load()   # 拿到所有像素，准备逐个改颜色

# 把每个像素设置成不同的颜色
for y in range(256):
    for x in range(256):
        # (x, y, 128) 是一个 RGB 颜色：红=x，绿=y，蓝=128
        pixels[x, y] = (x, y, 128)

img.save("gradient.png")
print("已保存 gradient.png")
print("图片总像素数:", 256 * 256)
print("原始 RGB 数据大小:", round(256 * 256 * 3 / 1024, 1), "KB")   # round(x, 1) 保留一位小数
draw_pixels.cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    const int W = 256, H = 256;

    // ofstream：写文件用的「文件版 cout」，课程包 C 会细讲文件读写
    // 这里用简单的 PPM 文本格式保存图片，无需额外库
    ofstream f("gradient.ppm");
    f << "P3
" << W << " " << H << "
255
";

    for (int y = 0; y < H; y++) {
        for (int x = 0; x < W; x++) {
            // 红色随 x 增加，绿色随 y 增加
            f << x << " " << y << " 128 ";
        }
        f << "
";
    }
    f.close();

    cout << "已保存 gradient.ppm" << endl;
    cout << "图片总像素数: " << W * H << endl;
    cout << "原始 RGB 数据大小: " << (W * H * 3 / 1024.0) << " KB" << endl;
    return 0;
}
