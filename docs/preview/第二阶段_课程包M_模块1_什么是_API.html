什么是 API

程序之间的「服务员」，请求与响应

第 1 小节

API 就像餐厅服务员

想象你走进一家餐厅。你不需要亲自去厨房做菜，只需要看菜单、点菜，服务员会把你的需求传给厨房，再把做好的菜端回来。

API（Application Programming Interface，应用程序编程接口）就是程序世界里的「服务员」。它规定了一个程序可以怎样向另一个程序「点菜」，以及另一个程序会怎么「上菜」。

例如，手机上的天气 App 并不会自己计算天气，而是向气象局的天气服务发请求；气象局的服务把天气数据作为响应返回，App 再把数据美化（加个广告）显示出来。

在这个过程里，App 和气象局服务之间传递信息的「菜单」和「规矩」，就是 API。

  • 请求（Request）：客户端说「我要什么」。
  • 响应（Response）：服务端把结果送回来。
api_analogy.py
# 用函数来比喻 API：
# 调用方不需要知道厨房怎么炒菜，
# 只要知道「菜名」和「返回什么」就够了。

def 点菜(菜名):
    # 厨房里的复杂操作被隐藏起来了
    return f"{菜名} 做好了"

print(点菜("番茄炒蛋"))  # 输出：番茄炒蛋 做好了
第 2 小节

端点、URL 与 JSON

在 Web API 中，「菜单上的每一道菜」通常对应一个 URL，也叫做 端点（Endpoint）。 比如 https://github.com/JustBecause-CigaretteBox-Studio/Tutorials 就是一个端点。

程序访问这个 URL，就像服务员把单子递给厨房。厨房处理完后，会把结果打包发回。最常见的打包格式叫做 JSON，看起来像 Python 的字典，易读也易解析。

sample_json.py
# 这是一段典型的 API 响应（JSON 格式）
# Python 里用 json 模块可以把它转成字典

import json

raw = '''
{
    "city": "北京",
    "temperature": 24,
    "unit": "C",
    "condition": "晴"
}
'''

data = json.loads(raw)
print(data["city"], data["temperature"], data["unit"])  # 北京 24 C

现实世界里的 API 返回值通常更复杂，会嵌套列表和字典。学会从 JSON 里提取自己需要的字段，是调用 API 的基本功。

第 3 小节

用 Python 发送第一个 API 请求

Python 里最常用的 HTTP 请求库是 requests。 它让「向服务器点菜」变得像调用函数一样简单。

下面这个例子访问一个公开接口，获取一条随机名言。如果电脑联网，运行它就能看到返回的内容。

first_request.py
import requests

url = "https://api.quotable.io/random"
response = requests.get(url)

# 状态码 200 表示请求成功
print("状态码:", response.status_code)

# 把 JSON 响应转成字典
quote = response.json()
print(quote["content"])
print("——", quote["author"])

代码中的 requests.get(url) 就是「发请求」， response.json() 就是「把响应解析成 JSON」。 如果服务器返回的不是 JSON，就不能调用 .json()，否则会报错。

第 4 小节

综合实战：随机狗狗图片查看器

把 API 请求与 JSON 解析串起来

现在我们用 requests 访问一个免费的狗狗图片接口， 从响应里取出图片 URL 并打印出来。如果复制到浏览器打开，还能看到一只随机小狗。

dog_viewer.py
import requests

url = "https://dog.ceo/api/breeds/image/random"
response = requests.get(url)

# 检查请求是否成功
if response.status_code == 200:
    data = response.json()
    print("狗狗图片 URL：", data["message"])
else:
    print("请求失败，状态码：", response.status_code)

这个程序的核心流程就是调用 API 的「标准三步走」：

  • 找到 API 端点（URL）。
  • 用 requests.get 发送请求。
  • 解析 JSON，取出需要的数据。

你可以试着把 URL 换成 https://api.thecatapi.com/v1/images/search， 不过它的返回是一个列表，图片地址在 data[0]["url"]，动手改改看吧。
