第 1 小节

内存：程序的“工作台”

程序运行时，所有变量、数据和临时结果都存放在内存（RAM）里。内存比硬盘快得多，但断电后内容会丢失，所以也叫“易失性存储”。

操作系统会给每个进程分配一块内存区域。其中：

  • 栈（Stack）：存放函数参数、局部变量，自动分配和回收。
  • 堆（Heap）：存放动态申请的数据，需要程序主动释放（或由垃圾回收器处理）。
memory_demo.py
import sys

x = 42
s = "hello"

# id() 返回变量在内存中的“地址”
print("x 的内存地址：", id(x))
print("s 的内存地址：", id(s))

# getsizeof 返回对象占用的字节数
print("x 占用字节：", sys.getsizeof(x))
print("s 占用字节：", sys.getsizeof(s))
memory_demo.cpp
#include <iostream>
#include <string>

int main() {
    int x = 42;
    std::string s = "hello";

    std::cout << "x 的内存地址： " << &x << std::endl;
    std::cout << "s 的内存地址： " << &s << std::endl;

    std::cout << "x 占用字节： " << sizeof(x) << std::endl;
    std::cout << "s 占用字节： " << sizeof(s) << std::endl;
    return 0;
}
第 2 小节

虚拟内存：每个程序都有自己的“地图”

真实内存是有限的，但操作系统能让多个程序都觉得自己独占一大片内存。这需要用到虚拟内存。

每个进程看到的都是自己的“虚拟地址空间”，操作系统和 CPU 中的内存管理单元（MMU）负责把虚拟地址翻译成物理地址。

用电影院来理解

想象一家电影院有很多影厅：

  • 1 号厅的座位从第 1 排第 1 座开始编号：1 排 1 座、1 排 2 座、1 排 3 座……
  • 2 号厅的座位也从第 1 排第 1 座开始编号：1 排 1 座、1 排 2 座、1 排 3 座……

每个影厅的座位编号规则完全一样，都是“从 1 开始连续编号”。

现在问题来了：

  • 小明拿着“5 排 6 座”电影票进场。
  • 小红拿着“5 排 6 座”电影票进场。
  • 他们俩的票面上都写着“5 排 6 座”，但进场后，坐在了完全不同的两个物理座位上，这是因为他们被带往了不同的影厅。

这就是虚拟内存的核心逻辑：

  • 微信运行在“1 号厅”，它的“5 排 6 座”对应内存的 A 区域。
  • 浏览器运行在“2 号厅”，它的“5 排 6 座”对应内存的 B 区域。
  • 操作系统就像影院售票系统，在背后做“翻译”——看到你是“1 号厅的 5 排 6 座”，就指引你去 A 区域；看到他是“2 号厅的 5 排 6 座”，就指引他去 B 区域。
  • 每个程序被分到自己的影厅，然后再根据座位号找自己的位置。

这样做有三个好处：

1. 互不干扰，更安全

即使 1 号厅有人大声喧哗（程序崩溃），也影响不到 2 号厅的观众。程序 A 出了 bug，不会把程序 B 搞坏。

2. 看起来空间很大

影厅一共只有20个，但是影院可以发100张“5排6座”的票，因为不一定所有人（程序）都会同时来看电影。真坐满了？那就灵活调度安排排队，程序是不会像观众一样投诉的。

3. 不常用的东西先“存到仓库”

如果某场电影暂时没人看，影院可以把这场次的座位安排给其他热门电影。等原场次观众来了，再重新安排座位。

操作系统也是这样：把某个程序暂时不用的数据搬到硬盘上（交换分区 / 页面文件），等需要了再调回内存。

第 3 小节

分页：把大地图切成小方块

操作系统不会一次性把整个程序塞进内存，而是把虚拟地址空间和物理内存都切成大小相同的小块，叫做页（Page）。程序用到哪一页，再把哪一页加载到物理内存里。

如果程序访问的页不在内存中，会触发缺页中断（Page Fault）。操作系统会把需要的页从硬盘调入内存；如果内存满了，还会把不常用的页换出去，这叫页面置换。

这种“按需加载”的方式，让小内存电脑也能运行大程序。

paging_sim.py
# 模拟分页：把大列表切成一页一页处理
big_data = list(range(100))      # 假装这是 100 个数据项
page_size = 10                    # 每页 10 项

for i in range(0, len(big_data), page_size):
    page = big_data[i:i + page_size]
    print(f"处理第 {i//page_size + 1} 页：{page[:3]}...{page[-3:]}")
paging_sim.cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> big_data(100);
    for (int i = 0; i < 100; ++i) {
        big_data[i] = i;
    }

    int page_size = 10;
    int page_count = big_data.size() / page_size;

    for (int i = 0; i < page_count; ++i) {
        std::cout << "处理第 " << (i + 1) << " 页：";
        for (int j = 0; j < 3; ++j) {
            std::cout << big_data[i * page_size + j] << " ";
        }
        std::cout << "... ";
        for (int j = page_size - 3; j < page_size; ++j) {
            std::cout << big_data[i * page_size + j] << " ";
        }
        std::cout << std::endl;
    }
    return 0;
}
第 4 小节

综合实战：模拟内存分配器

把本模块内容用起来

现在写一个简单的“内存分配器”。它维护一块内存池，支持“申请”和“释放”，并打印当前已用和剩余空间。这个例子能帮你理解操作系统管理内存时的基本动作。

memory_allocator.py
class TinyAllocator:
    def __init__(self, total):
        self.total = total
        self.used = 0
        self.blocks = {}

    def alloc(self, name, size):
        if self.used + size > self.total:
            print(f"错误：{name} 申请 {size} 失败，剩余空间不足")
            return False
        self.blocks[name] = size
        self.used += size
        print(f"分配 {size} 给 {name}，已用 {self.used}/{self.total}")
        return True

    def free(self, name):
        size = self.blocks.pop(name, 0)
        self.used -= size
        print(f"释放 {name} 的 {size}，已用 {self.used}/{self.total}")

mem = TinyAllocator(total=100)
mem.alloc("浏览器", 40)
mem.alloc("音乐", 30)
mem.alloc("游戏", 50)   # 空间不够
mem.free("音乐")
mem.alloc("游戏", 50)   # 现在可以了
memory_allocator.cpp
#include <iostream>
#include <string>
#include <map>

class TinyAllocator {
public:
    TinyAllocator(int total) : total(total), used(0) {}

    bool alloc(const std::string &name, int size) {
        if (used + size > total) {
            std::cout << "错误：" << name << " 申请 " << size
                      << " 失败，剩余空间不足" << std::endl;
            return false;
        }
        blocks[name] = size;
        used += size;
        std::cout << "分配 " << size << " 给 " << name
                  << "，已用 " << used << "/" << total << std::endl;
        return true;
    }

    void free(const std::string &name) {
        auto it = blocks.find(name);
        if (it == blocks.end()) return;
        int size = it->second;
        blocks.erase(it);
        used -= size;
        std::cout << "释放 " << name << " 的 " << size
                  << "，已用 " << used << "/" << total << std::endl;
    }

private:
    int total;
    int used;
    std::map<std::string, int> blocks;
};

int main() {
    TinyAllocator mem(100);
    mem.alloc("浏览器", 40);
    mem.alloc("音乐", 30);
    mem.alloc("游戏", 50);   // 空间不够
    mem.free("音乐");
    mem.alloc("游戏", 50);   // 现在可以了
    return 0;
}
