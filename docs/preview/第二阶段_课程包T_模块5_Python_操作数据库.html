第 1 小节

用 sqlite3 连接与执行 SQL

Python 的 sqlite3 模块让我们可以用代码来创建表、插入和查询数据。基本流程是：连接 → 创建游标 → 执行 SQL → 提交 → 关闭。

python_sqlite.py
import sqlite3

conn = sqlite3.connect("demo.db")
cursor = conn.cursor()

cursor.execute('''
CREATE TABLE IF NOT EXISTS users (
    id   INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    age  INTEGER
)
''')

cursor.execute("INSERT INTO users (name, age) VALUES ('李四', 20)")
conn.commit()

conn.close()

推荐使用 with 语句或确保调用 conn.close()，否则数据库文件可能被占用。

第 2 小节

参数化查询防注入

如果直接把用户输入拼进 SQL 字符串，恶意用户可能通过特殊字符破坏查询，甚至删除数据。这种攻击叫 SQL 注入。

安全的参数化查询
import sqlite3

conn = sqlite3.connect("demo.db")
cursor = conn.cursor()

name = input("请输入用户名：")

# 用 ? 占位，数据库会自动处理转义
cursor.execute("SELECT * FROM users WHERE name = ?", (name,))

rows = cursor.fetchall()
for row in rows:
    print(row)

conn.close()

参数化查询把「代码」和「数据」分开，数据库只把 ? 里的内容当数据，不会当成 SQL 指令执行。

第 3 小节

读取查询结果

执行 SELECT 后，可以用 fetchone() 取一条，fetchall() 取全部，也可以用 for 循环直接遍历游标。

读取结果
import sqlite3

conn = sqlite3.connect("demo.db")
cursor = conn.cursor()

cursor.execute("SELECT * FROM users")

# 方式 1：一次取所有
rows = cursor.fetchall()
print(rows)

# 方式 2：一条一条取
cursor.execute("SELECT * FROM users WHERE age > 18")
while True:
    row = cursor.fetchone()
    if row is None:
        break
    print(row)

conn.close()

如果希望结果像字典一样用列名访问，可以设置 conn.row_factory = sqlite3.Row。

第 4 小节

综合实战：安全的用户登录检查

用参数化查询保护账号

假设你有一个用户表，想通过用户名和密码验证登录。千万不要用字符串拼接，必须用参数化查询。

safe_login.py
import sqlite3

def check_login(username, password):
    conn = sqlite3.connect("demo.db")
    cursor = conn.cursor()

    cursor.execute(
        "SELECT * FROM users WHERE name = ? AND password = ?",
        (username, password)
    )
    user = cursor.fetchone()
    conn.close()

    return user is not None

# 测试
ok = check_login("李四", "123456")
print("登录成功" if ok else "登录失败")

动手任务：尝试把 cursor.execute 里的参数化写法改成字符串拼接，看看输入特殊字符时会出现什么问题（只在自己的测试数据库里试）。
