第 1 小节

设计游戏与搭建场景

我们要做一个经典的打砖块游戏：底部有一个挡板，一个球在窗口里反弹，球碰到砖块就消除砖块并得分。

先把元素拆成数据：挡板是 Rect，球是位置和半径，砖块是一组 Rect。这一步先只把场景画出来。

breakout_setup.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

paddle = pygame.Rect(350, 550, 100, 15)
ball = {"x": 400, "y": 300, "r": 10, "vx": 4, "vy": -4}
bricks = []
for row in range(5):
    for col in range(8):
        bricks.append(pygame.Rect(20 + col * 95, 50 + row * 30, 80, 20))

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((20, 20, 30))
    pygame.draw.rect(screen, (200, 200, 200), paddle)
    pygame.draw.circle(screen, (255, 220, 100), (int(ball["x"]), int(ball["y"])), ball["r"])
    for b in bricks:
        pygame.draw.rect(screen, (100, 200, 255), b)

    pygame.display.flip()
    clock.tick(60)

pygame.quit()

现在场景已经搭好：有挡板、球和 5 行 8 列的砖块。下一步让球动起来。

第 2 小节

球拍、球与移动

让球按照速度移动，并让它在窗口四边反弹。同时用鼠标或方向键控制挡板左右移动。

keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT]:  paddle.x -= 7
if keys[pygame.K_RIGHT]: paddle.x += 7
paddle.clamp_ip(screen.get_rect())

ball["x"] += ball["vx"]
ball["y"] += ball["vy"]

if ball["x"] - ball["r"] < 0 or ball["x"] + ball["r"] > 800:
    ball["vx"] = -ball["vx"]
if ball["y"] - ball["r"] < 0:
    ball["vy"] = -ball["vy"]

if ball["y"] + ball["r"] > 600:
    ball["x"], ball["y"] = 400, 300     # 掉到底部后重置球

把这段代码放进游戏循环里。现在球会来回反弹，挡板可以左右移动，球掉到底部会重置。

提示：paddle.clamp_ip(screen.get_rect()) 可以限制挡板不跑出窗口。

第 3 小节

砖块与碰撞

接下来处理碰撞：球碰到挡板要反弹，碰到砖块要消除砖块并加分。我们用矩形碰撞判断砖块，用简单的位置关系判断挡板。

breakout_hit.py
import pygame

# ... 前面的初始化代码保持不变 ...

font = pygame.font.SysFont("simhei", 32)
score = 0

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  paddle.x -= 7
    if keys[pygame.K_RIGHT]: paddle.x += 7
    paddle.clamp_ip(screen.get_rect())

    ball["x"] += ball["vx"]
    ball["y"] += ball["vy"]

    # 窗口边界反弹
    if ball["x"] - ball["r"] < 0 or ball["x"] + ball["r"] > 800:
        ball["vx"] = -ball["vx"]
    if ball["y"] - ball["r"] < 0:
        ball["vy"] = -ball["vy"]

    # 挡板碰撞
    ball_rect = pygame.Rect(ball["x"] - ball["r"], ball["y"] - ball["r"],
                            ball["r"] * 2, ball["r"] * 2)
    if ball_rect.colliderect(paddle) and ball["vy"] > 0:
        ball["vy"] = -ball["vy"]

    # 砖块碰撞
    new_bricks = []
    for b in bricks:
        if ball_rect.colliderect(b):
            ball["vy"] = -ball["vy"]
            score += 10
        else:
            new_bricks.append(b)
    bricks = new_bricks

    if ball["y"] + ball["r"] > 600:
        ball = {"x": 400, "y": 300, "r": 10, "vx": 4, "vy": -4}

    screen.fill((20, 20, 30))
    pygame.draw.rect(screen, (200, 200, 200), paddle)
    pygame.draw.circle(screen, (255, 220, 100), (int(ball["x"]), int(ball["y"])), ball["r"])
    for b in bricks:
        pygame.draw.rect(screen, (100, 200, 255), b)

    text = font.render("分数: " + str(score), True, (255, 255, 255))
    screen.blit(text, (20, 20))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

现在游戏的核心玩法已经完整：移动挡板、弹球、消砖块、计分。下一步是增加完善和扩展。

第 4 小节

完善与扩展

一个完整的游戏还需要开始/结束界面、胜利判断、音效和更丰富的视觉反馈。下面是几个可以逐步添加的扩展：

  • 胜利判断：当 bricks 列表为空时显示「你赢了！」。 if not bricks: print("你赢了！")
  • 生命系统：给玩家 3 条命，球掉底 3 次才结束。
  • 音效：用 pygame.mixer.Sound 给碰撞和消砖块加声音。
  • 难度递增：每消掉一行砖块，球速稍微加快。
breakout_extra.py
# 胜利判断示例
if not bricks:
    win_text = font.render("你赢了！", True, (100, 255, 150))
    screen.blit(win_text, (320, 280))
    pygame.display.flip()
    pygame.time.wait(2000)
    running = False

# 增加生命
lives = 3
# 球掉底时：
if ball["y"] + ball["r"] > 600:
    lives -= 1
    if lives <= 0:
        running = False
    else:
        ball = {"x": 400, "y": 300, "r": 10, "vx": 4, "vy": -4}

挑战：试着把砖块改成不同颜色，每行一个颜色；或者让球击中挡板不同位置时反弹角度不同，这样游戏会更有趣。
