第 1 小节

项目目标与表设计

最后一战：用 Python + SQLite 做一个简易通讯录。功能包括：添加联系人、查看全部、按名字搜索、修改电话、删除联系人。

先设计表结构。一个联系人包含：姓名、电话、备注。

contact_schema.py
import sqlite3

def init_db():
    conn = sqlite3.connect("contacts.db")
    cursor = conn.cursor()
    cursor.execute('''
    CREATE TABLE IF NOT EXISTS contacts (
        id      INTEGER PRIMARY KEY AUTOINCREMENT,
        name    TEXT NOT NULL,
        phone   TEXT,
        note    TEXT
    )
    ''')
    conn.commit()
    conn.close()

第 3 小节

修改、删除与搜索

通讯录少不了修改电话、删除联系人、按名字搜索。搜索时用 LIKE 配合通配符 %。

修改、删除、搜索
import sqlite3

def update_phone(contact_id, new_phone):
    conn = sqlite3.connect("contacts.db")
    cursor = conn.cursor()
    cursor.execute(
        "UPDATE contacts SET phone = ? WHERE id = ?",
        (new_phone, contact_id)
    )
    conn.commit()
    conn.close()

def delete_contact(contact_id):
    conn = sqlite3.connect("contacts.db")
    cursor = conn.cursor()
    cursor.execute("DELETE FROM contacts WHERE id = ?", (contact_id,))
    conn.commit()
    conn.close()

def search_contacts(keyword):
    conn = sqlite3.connect("contacts.db")
    cursor = conn.cursor()
    cursor.execute(
        "SELECT * FROM contacts WHERE name LIKE ?",
        (f"%{keyword}%",)
    )
    return cursor.fetchall()
第 4 小节

综合实战：完整通讯录程序

把功能串成一个命令行小工具

把前面的函数组合起来，加上一个简单的命令行菜单，就是一个能用的通讯录小工具。

contact_book.py
import sqlite3

def init_db():
    conn = sqlite3.connect("contacts.db")
    c = conn.cursor()
    c.execute('''
    CREATE TABLE IF NOT EXISTS contacts (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        phone TEXT,
        note TEXT
    )''')
    conn.commit()
    conn.close()

def add_contact(name, phone, note=""):
    with sqlite3.connect("contacts.db") as conn:
        c = conn.cursor()
        c.execute("INSERT INTO contacts (name, phone, note) VALUES (?, ?, ?)",
                  (name, phone, note))
        conn.commit()

def list_contacts():
    with sqlite3.connect("contacts.db") as conn:
        c = conn.cursor()
        c.execute("SELECT * FROM contacts ORDER BY name")
        for row in c.fetchall():
            print(row)

def search(keyword):
    with sqlite3.connect("contacts.db") as conn:
        c = conn.cursor()
        c.execute("SELECT * FROM contacts WHERE name LIKE ?", (f"%{keyword}%",))
        return c.fetchall()

init_db()
add_contact("Alice", "13800138000", "同学")
add_contact("Bob", "13900139000", "同事")
list_contacts()
print(search("Ali"))
