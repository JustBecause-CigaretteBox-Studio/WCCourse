第 1 小节

发票整理助手的整体思路

从混乱的 PDF 到整齐的表格

月底报销时，桌面上往往堆满了各种发票：餐饮、交通、办公用品……我们要做一个发票整理助手，它能：

  1. 把一堆混乱的发票文件按类型分类；
  2. 给它们重命名为「日期_金额_类型」的格式；
  3. 把信息汇总到一张 Excel 表格里。

这个项目会用到课程包 R 前面几个模块的技能：文件操作、Excel 处理、字符串处理。你可以把它当成一个「小毕业典礼」。

为了简化，我们先假设文件名里已经包含了日期和金额信息，比如 2025-08-20_120_餐饮.pdf。真实场景中可以用 OCR 或 PDF 解析库读取发票内容，这里先聚焦核心流程。

第 2 小节

自动分类与重命名

按发票类型整理文件

我们可以根据文件名里的关键字判断发票类型，然后把文件搬到对应文件夹，并统一命名格式。

organize_invoices.py
import os
import shutil
from datetime import datetime

source = "发票原始"
categories = {
    "餐饮": ["餐", "饭", "咖啡"],
    "交通": ["打车", "地铁", "公交"],
    "办公": ["文具", "打印", "办公"],
}

def guess_category(name):
    for category, keywords in categories.items():
        for kw in keywords:
            if kw in name:
                return category
    return "其他"

for filename in os.listdir(source):
    if not filename.endswith(".pdf"):
        continue

    # 从文件名提取日期、金额、类型
    parts = filename.replace(".pdf", "").split("_")
    date = parts[0] if len(parts) > 0 else datetime.now().strftime("%Y-%m-%d")
    amount = parts[1] if len(parts) > 1 else "0"
    category = guess_category(filename)

    # 创建分类文件夹并移动
    os.makedirs(category, exist_ok=True)
    new_name = f"{date}_{amount}_{category}.pdf"
    shutil.move(os.path.join(source, filename), os.path.join(category, new_name))
    print(f"{filename} → {category}/{new_name}")

这个脚本展示了「读取 → 解析 → 判断 → 移动 → 重命名」的完整流程。关键字表可以随时扩展，比如加上「住宿」「差旅」等类别。

第 3 小节

汇总到 Excel

生成报销统计表

分类完成后，再用 openpyxl 把每个类别的金额汇总起来，生成一张报销统计表。

invoice_summary.py
import os
from openpyxl import Workbook

wb = Workbook()
ws = wb.active
ws.title = "报销汇总"
ws.append(["日期", "金额", "类别", "文件名"])

totals = {}

for category in ["餐饮", "交通", "办公", "其他"]:
    if not os.path.exists(category):
        continue
    for name in os.listdir(category):
        if not name.endswith(".pdf"):
            continue
        parts = name.replace(".pdf", "").split("_")
        date = parts[0]
        amount = float(parts[1])
        totals[category] = totals.get(category, 0) + amount
        ws.append([date, amount, category, name])

# 加一行汇总
ws.append([])
ws.append(["类别", "合计"])
for category, total in totals.items():
    ws.append([category, total])

wb.save("报销汇总表.xlsx")
print("报销汇总表已生成")
print(totals)

这里用 Workbook() 新建一个 Excel 文件，再用 ws.append() 一行行填入数据。最后按类别汇总，方便财务核对。

第 4 小节

完整项目与扩展思考

把助手变成真正的生产力工具

把前面的代码拼起来，就形成了一个完整的「发票整理助手」：

invoice_helper.py
import os
import shutil
from openpyxl import Workbook

def organize_invoices(source="发票原始"):
    categories = {"餐饮": ["餐", "饭"], "交通": ["打车", "地铁"], "办公": ["文具", "打印"]}

    def guess_category(name):
        for c, kws in categories.items():
            if any(kw in name for kw in kws):
                return c
        return "其他"

    for name in os.listdir(source):
        if not name.endswith(".pdf"):
            continue
        parts = name.replace(".pdf", "").split("_")
        date, amount = parts[0], parts[1] if len(parts) > 1 else "0"
        c = guess_category(name)
        os.makedirs(c, exist_ok=True)
        new_name = f"{date}_{amount}_{c}.pdf"
        shutil.move(os.path.join(source, name), os.path.join(c, new_name))

def create_summary():
    wb = Workbook()
    ws = wb.active
    ws.title = "报销汇总"
    ws.append(["日期", "金额", "类别", "文件名"])
    totals = {}
    for c in ["餐饮", "交通", "办公", "其他"]:
        if not os.path.exists(c):
            continue
        for name in os.listdir(c):
            parts = name.replace(".pdf", "").split("_")
            ws.append([parts[0], float(parts[1]), parts[2], name])
            totals[c] = totals.get(c, 0) + float(parts[1])
    ws.append(["类别", "合计"])
    for c, t in totals.items():
        ws.append([c, t])
    wb.save("报销汇总表.xlsx")

if __name__ == "__main__":
    organize_invoices()
    create_summary()
    print("发票整理完成！")

你可以继续扩展这个助手：

  • 用 pdfplumber 或 PyMuPDF 自动读取 PDF 里的金额；
  • 加入定时任务，每月一号自动整理上月发票；
  • 把汇总表自动邮件发给财务。
