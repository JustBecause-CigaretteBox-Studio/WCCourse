取指令、执行、寄存器、时钟

第 1 小节

取指令：CPU 在做什么

CPU 并不会「理解」你的 Python 代码。Python 程序最终被解释或编译成一条条非常简单的机器指令，比如「把内存地址 100 的数字加到寄存器 A 上」。CPU 的工作就是不断重复三个动作：

CPU 里有一个特殊的寄存器叫 程序计数器（PC），它永远记着「下一条指令在哪里」。每次取完指令，PC 就自动加 1（或跳到别的地方），指向下一条。循环、函数调用、条件判断，本质上都是通过修改 PC 的值来实现的。

模拟取指令循环
program = [
    "LOAD  A, 10",   # 把 10 放进寄存器 A
    "LOAD  B, 3",    # 把 3 放进寄存器 B
    "ADD   A, B",    # A = A + B
    "PRINT A",       # 输出 A
]

pc = 0
while pc < len(program):
    instruction = program[pc]
    print("PC=", pc, ", 取指令:", instruction)
    pc = pc + 1
fetch_cycle.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string program[4] = {
        "LOAD  A, 10",   // 把 10 放进寄存器 A
        "LOAD  B, 3",    // 把 3 放进寄存器 B
        "ADD   A, B",    // A = A + B
        "PRINT A",       // 输出 A
    };

    int pc = 0;
    while (pc < 4) {
        string instruction = program[pc];
        cout << "PC=" << pc << ", 取指令: " << instruction << endl;
        pc = pc + 1;
    }
    return 0;
}

真实的 CPU 每秒钟会执行几十亿次这样的取指令循环，所以一个看起来很复杂的程序，在 CPU 眼里就是无数条简单指令的排列组合。

第 2 小节

执行：译码与算术逻辑单元

取到指令后，CPU 要把它「翻译」成具体的电路动作，这个过程叫 译码（Decode）。例如「ADD A, B」这条指令会告诉 ALU：把寄存器 A 和 B 的值相加，结果写回 A。

真正做运算的部件叫 ALU（Arithmetic Logic Unit，算术逻辑单元）。它就像 CPU 里的计算器，能做整数加减、位运算、比较大小等操作。模块 1 里学的加法器，就是 ALU 的核心组成部分。

现代 CPU 通常有多个 ALU，可以同时执行多条独立指令，这种技术叫流水线和超标量。但初学者只需要记住：CPU 的核心工作就是取指令、译码、执行，循环往复。

⚠️ 注意

CPU 能直接执行的指令集叫「机器码」或「汇编指令」。我们平时写的 Python、C++ 代码需要被翻译成机器码才能运行。这个翻译工作由解释器、编译器完成。

第 3 小节

寄存器与时钟：CPU 的速度

CPU 内部有一小片极快的存储空间，叫做 寄存器（Register）。寄存器数量很少（通常几十个），但读写速度比内存快几十倍甚至上百倍。CPU 做运算时，数据先要被搬进寄存器，算完再搬出去。

你可以这样理解：

  • 寄存器：CPU 手边的工作台，放正在用的东西。
  • 内存（RAM）：书桌，离得比较近，常用资料放这里。
  • 硬盘：书柜，离得远，但容量大、能长期保存。

CPU 的所有操作都由一个时钟来统一节拍。时钟每「滴答」一次，CPU 就完成一步操作（比如取一条指令）。常见的 3 GHz CPU，意味着每秒能滴答 30 亿次。时钟频率越高，CPU 在同样时间内能做的步骤就越多，但发热和耗电也会上升。

频率转换
ghz = 3.0
hz = ghz * 1000000000      # 1 GHz = 10 亿 Hz
cycles_per_ms = hz / 1000  # 1 秒 = 1000 毫秒
print(ghz, "GHz 的 CPU 每毫秒大约滴答", cycles_per_ms, "次")
# 输出：3.0 GHz 的 CPU 每毫秒大约滴答 3000000.0 次
clock_demo.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double ghz = 3.0;
    double hz = ghz * 1000000000;   // 1 GHz = 10 亿 Hz
    double cycles_per_ms = hz / 1000;

    // fixed + setprecision(0)：让小数点后面不显示（格式控制，记住这个写法即可）
    cout << fixed << setprecision(0);
    cout << ghz << " GHz 的 CPU 每毫秒大约滴答 "
         << cycles_per_ms << " 次" << endl;
    return 0;
}
第 4 小节

综合实战：写一个极简 CPU 模拟器

把取指令、译码、执行串起来

下面我们实现一个玩具 CPU，支持四条指令：LOAD、ADD、SUB、PRINT。它将展示 CPU 最核心的「取-译-执行」循环。

极简 CPU 模拟器
# 内存里存储的程序：每条指令是一个小列表 [操作, 参数1, 参数2]
program = [
    ["LOAD", "A", "10"],
    ["LOAD", "B", "4"],
    ["ADD",  "A", "B"],
    ["SUB",  "A", "B"],
    ["PRINT", "A", ""],
]

registers = {"A": 0, "B": 0}   # 用字典当寄存器（第一阶段第 2 章学过）
pc = 0

while pc < len(program):
    op = program[pc][0]     # 指令名
    arg1 = program[pc][1]   # 第一个参数
    arg2 = program[pc][2]   # 第二个参数
    print("PC=", pc, ", 执行", op, arg1, arg2)

    if op == "LOAD":
        registers[arg1] = int(arg2)   # int() 把文字转成数字
    elif op == "ADD":
        registers[arg1] = registers[arg1] + registers[arg2]
    elif op == "SUB":
        registers[arg1] = registers[arg1] - registers[arg2]
    elif op == "PRINT":
        print("  -> 输出: 寄存器", arg1, "=", registers[arg1])

    pc = pc + 1

print("最终寄存器状态:", registers)
tiny_cpu.cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 内存里存储的程序：三个数组分别存指令名、参数1、参数2
    string ops[5]  = {"LOAD", "LOAD", "ADD", "SUB", "PRINT"};
    string arg1[5] = {"A", "B", "A", "A", "A"};
    string arg2[5] = {"10", "4", "B", "B", ""};

    // 两个寄存器
    int regA = 0;
    int regB = 0;
    int pc = 0;

    while (pc < 5) {
        cout << "PC=" << pc << ", 执行 " << ops[pc]
             << " " << arg1[pc] << " " << arg2[pc] << endl;

        if (ops[pc] == "LOAD") {
            int value = stoi(arg2[pc]);   // stoi 把文字转成整数
            if (arg1[pc] == "A") regA = value;
            if (arg1[pc] == "B") regB = value;
        } else if (ops[pc] == "ADD") {
            if (arg1[pc] == "A") regA = regA + regB;
            if (arg1[pc] == "B") regB = regB + regA;
        } else if (ops[pc] == "SUB") {
            if (arg1[pc] == "A") regA = regA - regB;
            if (arg1[pc] == "B") regB = regB - regA;
        } else if (ops[pc] == "PRINT") {
            if (arg1[pc] == "A") cout << "  -> 输出: 寄存器 A = " << regA << endl;
            if (arg1[pc] == "B") cout << "  -> 输出: 寄存器 B = " << regB << endl;
        }
        pc = pc + 1;
    }

    cout << "最终寄存器状态: A=" << regA << " B=" << regB << endl;
    return 0;
}
