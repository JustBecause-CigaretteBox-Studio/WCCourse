第 1 小节

冒泡排序：像气泡往上冒

冒泡排序是最直观的排序方法之一。想象水里的小气泡，轻的总是往上浮。排序时，我们反复比较相邻的两个数，如果顺序不对就交换它们，一轮下来，最大的数就会“浮”到最右边。

重复多轮后，整个列表就像气泡一样，从右到左依次排好。每一轮至少能确定一个数的最终位置。

Python 冒泡排序
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

nums = [5, 2, 8, 1, 9]
print(bubble_sort(nums))  # [1, 2, 5, 8, 9]
C++ 冒泡排序
#include <iostream>
#include <vector>
using namespace std;

void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
            }
        }
    }
}

int main() {
    vector<int> nums = {5, 2, 8, 1, 9};
    bubbleSort(nums);
    for (int x : nums) cout << x << " ";
    return 0;
}
第 2 小节

选择排序：每次挑最小的

选择排序的思路像排队时反复找最矮的人站到最前面。每一轮从剩下的元素里找出最小的一个，把它放到已排序区域的末尾。

和冒泡排序一样，选择排序也要用两层循环，但交换次数通常更少：每一轮最多只交换一次。

Python 选择排序
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

nums = [5, 2, 8, 1, 9]
print(selection_sort(nums))  # [1, 2, 5, 8, 9]
C++ 选择排序
#include <iostream>
#include <vector>
using namespace std;

void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        swap(arr[i], arr[minIdx]);
    }
}

int main() {
    vector<int> nums = {5, 2, 8, 1, 9};
    selectionSort(nums);
    for (int x : nums) cout << x << " ";
    return 0;
}
第 3 小节

插入排序：像整理扑克牌

插入排序就像你抓扑克牌时整理手牌：左手已经排好序，右手抽到一张新牌，就插入到左手正确的位置。

它从第二个元素开始，把当前元素一个一个插到前面已经有序的区间中。对少量数据或接近有序的列表，插入排序非常快。

Python 插入排序
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

nums = [5, 2, 8, 1, 9]
print(insertion_sort(nums))  # [1, 2, 5, 8, 9]
C++ 插入排序
#include <iostream>
#include <vector>
using namespace std;

void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

int main() {
    vector<int> nums = {5, 2, 8, 1, 9};
    insertionSort(nums);
    for (int x : nums) cout << x << " ";
    return 0;
}

综合实战：给考试成绩排个名

把三种排序方法串起来用

现在用排序解决一个实际问题：班里 5 位同学的考试成绩是 [88, 72, 95, 60, 81]，请你把分数从低到高排好，并输出前三名。

你可以任选上面三种排序方法中的一种来实现。这里以选择排序为例，因为它写起来短、交换次数也少。

成绩排名小工具
def selection_sort(arr):

sorted_scores = selection_sort(scores)
print("从低到高：", sorted_scores)
print("前三名：", sorted_scores[-3:])
exam_rank.cpp
#include <iostream>
#include <vector>
using namespace std;

void selection_sort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[min_idx]) min_idx = j;
        }
        swap(arr[i], arr[min_idx]);
    }
}

int main() {
    vector<int> scores = {88, 72, 95, 60, 81};
    selection_sort(scores);
    cout << "从低到高：";
    for (int x : scores) cout << x << " ";
    cout << endl;
    cout << "前三名：";
    for (int i = scores.size() - 3; i < scores.size(); i++)
        cout << scores[i] << " ";
    cout << endl;
    return 0;
}

运行后你会得到 [60, 72, 81, 88, 95]，前三名是 [81, 88, 95]。如果你愿意，可以把三种排序都试一遍，看看结果是否一致。实际开发中，Python 有内置的 sorted() 可用，但理解底层排序能帮助你写出更高效的代码。
