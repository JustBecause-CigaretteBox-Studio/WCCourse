第 1 小节

输入输出：程序怎么和外界说话

程序不能闭门造车，它需要读取键盘、鼠标、文件、网络，也需要把结果显示到屏幕、写入文件、发送到网络。这些统称为输入 / 输出（I/O）。

操作系统为每种设备配备了设备驱动程序。驱动是硬件和操作系统之间的翻译官：键盘按下时，驱动把电信号转换成操作系统能理解的“按键事件”；显卡驱动则把操作系统指令转换成显示器上的像素。

普通程序不需要知道硬件细节，只要调用操作系统提供的 I/O 接口就行。

io_demo.py
# 标准输入：从键盘读取
name = input("请输入你的名字：")

# 标准输出：显示到屏幕
print("你好，", name)
io_demo.cpp
#include <iostream>
#include <string>

int main() {
    std::cout << "请输入你的名字：";
    std::string name;
    std::cin >> name;
    std::cout << "你好，" << name << std::endl;
    return 0;
}
第 2 小节

中断：提升效率

最早的 I/O 方式是轮询（Polling）：CPU 不停地问设备“好了没？好了没？”这非常浪费 CPU 时间。

后来发明了中断（Interrupt）：CPU 先去干别的，等设备完成后再“按门铃”通知 CPU。这就像点外卖后你去工作，外卖到了门铃响，你再去开门。

中断让 CPU 能高效地同时处理多个设备。键盘、鼠标、网卡、硬盘都会触发中断。

第 3 小节

缓冲区：先攒一攒再送

很多 I/O 设备速度很慢。如果每产生一个字节就送一次，CPU 会疲于奔命。缓冲区（Buffer）就是一块临时内存：先把数据攒够，再一次性发送。

生活中也有类似例子：快递不会每收到一个包裹就发车，而是装满一车再出发。

在 Python 中，print 默认会把输出先放进缓冲区。如果你希望立即显示，可以加 flush=True。

buffer_demo.py
import time

# 默认缓冲：可能稍后才显示
for i in range(3):
    print(i, end=" ")
    time.sleep(0.5)

print()  # 换行并刷新

# 立即输出
for i in range(3):
    print(i, end=" ", flush=True)
    time.sleep(0.5)
buffer_demo.cpp
#include <iostream>
#include <thread>
#include <chrono>

int main() {
    // 默认缓冲：可能稍后才显示
    for (int i = 0; i < 3; ++i) {
        std::cout << i << " ";
        std::this_thread::sleep_for(std::chrono::milliseconds(500));
    }
    std::cout << std::endl;  // 换行并刷新

    // 立即输出
    for (int i = 0; i < 3; ++i) {
        std::cout << i << " " << std::flush;
        std::this_thread::sleep_for(std::chrono::milliseconds(500));
    }
    std::cout << std::endl;
    return 0;
}
第 4 小节

综合实战：重定向与管道小实验

把本模块内容用起来

在命令行里，我们可以用重定向和管道灵活地组合程序的输入输出，这正是操作系统 I/O 设计的威力所在。

io_experiment.sh
# 把命令输出保存到文件
echo "hello world" > hello.txt

# 把文件内容作为输入
sort < hello.txt

# 管道：把前一个命令的输出传给下一个命令
echo -e "banana\napple\ncherry" | sort

在 Windows PowerShell 中，重定向符号类似，例如 echo hello > hello.txt。这些命令的本质都是操作系统在帮你搬运数据。
