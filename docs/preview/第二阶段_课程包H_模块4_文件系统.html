第 1 小节

文件系统：硬盘上的“图书馆”

硬盘里的数据成千上万，如果没有组织方式，找文件就像在大海里捞针。文件系统就是硬盘上的图书馆：它规定了怎么存放文件、怎么命名、怎么分类。

文件系统最基本的元素是文件和目录（文件夹）。目录可以嵌套，形成一棵树。从根目录出发到某个文件的路径，就像图书馆的索书号。

list_files.py
import os

# 列出当前目录下的文件和文件夹
items = os.listdir(".")
for item in items:
    print(item)
list_files.cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    for (const auto &entry : fs::directory_iterator(".")) {
        std::cout << entry.path().filename().string() << std::endl;
    }
    return 0;
}
第 2 小节

inode：文件的“身份证”

在 Linux、macOS 等类 Unix 系统中，每个文件都有一个inode。inode 是文件的“身份证”，记录了文件大小、创建时间、修改时间、数据块位置等元信息，但不记录文件名。

文件名只是目录里的一条记录，指向 inode。同一个 inode 可以被多个文件名指向，这叫硬链接；而软链接（符号链接）则是新建一个文件，里面存着另一个路径。

inode_demo.sh
# 在 Linux/macOS 终端中查看 inode 号
ls -i file.txt

# 创建硬链接
ln file.txt hard_link.txt

# 创建软链接
ln -s file.txt soft_link.txt

Windows 的 NTFS 也有类似概念，但普通用户通常不会直接接触到“inode”这个词。

第 3 小节

绝对路径与相对路径

定位文件有两种常用方式。绝对路径从根目录开始写，像完整地址；相对路径从当前所在目录开始写，例如“这栋楼旁边那栋楼”。

例如，在 Windows 里：

  • 绝对路径：C:\Users\Alice\Documents\note.txt
  • 相对路径：.\Documents\note.txt（假设当前在 C:\Users\Alice）

在 Python 中，pathlib 模块能帮我们方便地处理路径。在 C++ 中，std::filesystem 能帮我们方便地处理路径。

path_demo.py
from pathlib import Path

# 当前文件所在目录
here = Path(".").resolve()
print("绝对路径：", here)

# 拼接子路径
note = here / "note.txt"
print("note.txt 路径：", note)
path_demo.cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    fs::path here = fs::absolute(".");
    std::cout << "绝对路径： " << here << std::endl;

    fs::path note = here / "note.txt";
    std::cout << "note.txt 路径： " << note << std::endl;
    return 0;
}
第 4 小节

综合实战：遍历目录树

把本模块内容用起来

写一个小工具，遍历当前目录下的所有文件和子目录，打印出一棵“目录树”。这能帮你理解文件系统是如何组织的。

tree.py
import os

def tree(path, prefix=""):
    items = sorted(os.listdir(path))
    for i, name in enumerate(items):
        full = os.path.join(path, name)
        is_last = (i == len(items) - 1)
        branch = "└── " if is_last else "├── "
        print(prefix + branch + name)
        if os.path.isdir(full):
            ext = "    " if is_last else "│   "
            tree(full, prefix + ext)

print("当前目录树：")
tree(".")
tree.cpp
#include <iostream>
#include <filesystem>
#include <vector>
#include <algorithm>
#include <string>

namespace fs = std::filesystem;

void tree(const fs::path &path, const std::string &prefix = "") {
    std::vector<fs::directory_entry> items;
    for (const auto &entry : fs::directory_iterator(path)) {
        items.push_back(entry);
    }
    std::sort(items.begin(), items.end(),
        [](const fs::directory_entry &a, const fs::directory_entry &b) {
            return a.path().filename().string() < b.path().filename().string();
        });

    for (size_t i = 0; i < items.size(); ++i) {
        const auto &entry = items[i];
        bool is_last = (i == items.size() - 1);
        std::string branch = is_last ? "└── " : "├── ";
        std::cout << prefix << branch << entry.path().filename().string() << std::endl;
        if (entry.is_directory()) {
            std::string ext = is_last ? "    " : "│   ";
            tree(entry.path(), prefix + ext);
        }
    }
}

int main() {
    std::cout << "当前目录树：" << std::endl;
    tree(".");
    return 0;
}
