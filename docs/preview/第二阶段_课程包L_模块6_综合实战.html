用图形化工具管理一个小项目的完整生命周期

第 1 小节

用图形化工具看 Git

命令行虽然强大，但对新手不够直观。很多图形化工具能把提交、分支、合并画成流程图，一目了然。常见工具有：

  • GitHub Desktop：简洁，适合初学者；
  • Sourcetree：功能全面，分支图清晰；
  • GitKraken：跨平台，可视化效果好；
  • VS Code 内置 Git：写代码时顺手管理版本。

图形化工具和命令行并不冲突。建议先用命令行理解原理，再用图形化工具提高效率。本模块的实战将模拟一个完整生命周期，无论你用哪种工具，背后的 Git 命令都是一样的。

第 2 小节

小项目完整生命周期概览

一个典型的小项目生命周期通常包括以下步骤：

# 1. 初始化本地仓库
git init

# 2. 写初始代码并提交
git add .
git commit -m "项目初始化"

# 3. 创建功能分支
git switch -c feature-login

# 4. 开发、测试、提交
git add .
git commit -m "实现登录功能"

# 5. 切回主线并合并
git switch main
git merge feature-login

# 6. 推送到远程
git remote add origin https://...git
git push -u origin main

这个流程覆盖了前面五个模块的核心知识点：仓库、提交、分支、合并、远程。

第 3 小节

图形化工具中的常见操作

以 GitHub Desktop 为例，常用操作对应命令行如下：

  • Commit 按钮 = git add + git commit；
  • Branch → New Branch = git switch -c；
  • Publish branch = git push；
  • Fetch origin / Pull origin = git fetch / git pull；
  • Merge into current branch = git merge。

图形化工具会高亮显示冲突文件，通常左边是「当前分支」，右边是「要合并的分支」，中间是合并结果。理解命令行后，这些界面会变得非常容易。

第 4 小节

综合实战

用 GUI 管理一个「待办清单」项目

本实战目标：从零开始管理一个 todo-list 项目，全程使用你选择的图形化工具，必要时对照下方命令。

任务清单：

  1. 新建文件夹 todo-list，用 git init 初始化。
  2. 创建 todo.txt，写入「- 买牛奶」，提交（Commit）。
  3. 在 GUI 中创建分支 feature-priority。
  4. 在分支上给待办项加上优先级，例如「[高] 买牛奶」，提交。
  5. 切回 main，在 GUI 中合并 feature-priority。
  6. （可选）在 GitHub/Gitee 创建远程仓库，把 main 推上去。
mkdir todo-list && cd todo-list
git init
echo "- 买牛奶" > todo.txt
git add todo.txt && git commit -m "初始待办"
git switch -c feature-priority
# 修改 todo.txt 为 "[高] 买牛奶"
git add todo.txt && git commit -m "添加优先级"
git switch main
git merge feature-priority
# 可选：git remote add origin ... && git push -u origin main

完成后，你就体验了项目从零到上线的完整 Git 生命周期。
