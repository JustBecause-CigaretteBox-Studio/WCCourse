第 1 小节

Excel 是带格子的仓库

openpyxl 的基本概念

Excel 文件就像一本带格子的账簿：工作簿是整本账，工作表是其中一页，单元格是页面上一个小格子。openpyxl 就是替你翻账簿、填数字的助手。

在使用之前，需要先安装它：

终端命令
pip install openpyxl

安装好后，就可以打开一个 Excel 文件，看看里面有什么：

open_excel.py
from openpyxl import load_workbook

# 打开一本账簿
wb = load_workbook("成绩表.xlsx")

# 看看有哪些页
print(wb.sheetnames)

# 翻到第一页
ws = wb.active
print(f"共有 {ws.max_row} 行，{ws.max_column} 列")

wb.active 表示「当前正在看的那一页」。如果你知道页名，也可以用 wb["Sheet1"] 直接翻到指定页。

第 2 小节

读取与填写数据

像坐标一样定位单元格

每个单元格都有地址，比如 A1、B2。用 openpyxl 访问单元格，就像在棋盘上用坐标找棋子。

read_write_excel.py
from openpyxl import load_workbook

wb = load_workbook("成绩表.xlsx")
ws = wb.active

# 读取 A1 单元格
name = ws["A1"].value
print("表头：", name)

# 给 B2 填一个新分数
ws["B2"] = 95

# 按行号、列号也可以：第 2 行第 3 列
ws.cell(row=2, column=3, value="优秀")

# 保存修改
wb.save("成绩表_已更新.xlsx")

注意：openpyxl 不会自动保存，修改完后一定要调用 wb.save()，否则改动只留在内存里，文件还是原样。

第 3 小节

格式美化与数据汇总

让表格好看又会算

表格不仅要填对，还要好看、好读。openpyxl 可以给单元格加粗、改颜色，还能遍历整列做汇总。

format_summary.py
from openpyxl import load_workbook
from openpyxl.styles import Font

wb = load_workbook("成绩表.xlsx")
ws = wb.active

# 把第一行表头加粗
for cell in ws[1]:
    cell.font = Font(bold=True)

# 汇总第 2 列的分数
total = 0
count = 0
for row in ws.iter_rows(min_row=2, max_row=ws.max_row, min_col=2, max_col=2):
    score = row[0].value
    if isinstance(score, (int, float)):
        total += score
        count += 1

ws["D1"] = "平均分"
ws["D2"] = round(total / count, 2) if count else 0

wb.save("成绩表_汇总.xlsx")

iter_rows() 会按行返回一个个单元格，我们可以指定从第 2 行开始、只看第 2 列，这样就能跳过表头，只统计分数。

第 4 小节

综合实战：自动生成成绩单

从原始分数到格式化报表

假设老师给了一张原始分数表，只有姓名和分数。我们要自动生成一张新表，加上等级（≥90 优秀，≥60 及格，否则不及格），并算平均分。

report_card.py
from openpyxl import load_workbook
from openpyxl.styles import Font, PatternFill

wb = load_workbook("原始成绩.xlsx")
ws = wb.active

# 添加新表头
ws["C1"] = "等级"
ws["C1"].font = Font(bold=True)

for row in range(2, ws.max_row + 1):
    score = ws.cell(row=row, column=2).value
    if score >= 90:
        level = "优秀"
        fill = PatternFill("solid", fgColor="C6EFCE")
    elif score >= 60:
        level = "及格"
        fill = PatternFill("solid", fgColor="FFEB9C")
    else:
        level = "不及格"
        fill = PatternFill("solid", fgColor="FFC7CE")

    ws.cell(row=row, column=3, value=level)
    ws.cell(row=row, column=3).fill = fill

wb.save("成绩单.xlsx")
print("成绩单已生成！")

这个脚本演示了「读取 → 判断 → 填写 → 美化 → 保存」的完整流程。你可以根据自己的需要，把等级规则改成任何标准。
