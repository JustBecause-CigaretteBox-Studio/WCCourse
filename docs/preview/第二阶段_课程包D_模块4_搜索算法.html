第 1 小节

线性搜索：逐页翻书

线性搜索也叫顺序搜索，思路最简单：从第一个元素开始，一个接一个地检查，直到找到目标或遍历完。

它的优点是不要求数据有序，缺点是如果目标在最后，或者根本不存在，就得检查所有元素。数据量越大，耗时越长，复杂度是 O(n)。

Python 线性搜索
def linear_search(arr, target):
    for i, value in enumerate(arr):
        if value == target:
            return i
    return -1

names = ["张三", "李四", "王五", "赵六"]
print(linear_search(names, "王五"))  # 2
print(linear_search(names, "孙七"))  # -1
C++ 线性搜索
#include <iostream>
#include <vector>
using namespace std;

int linearSearch(vector<string>& arr, string target) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

int main() {
    vector<string> names = {"张三", "李四", "王五", "赵六"};
    cout << linearSearch(names, "王五") << endl;  // 2
    cout << linearSearch(names, "孙七") << endl; // -1
    return 0;
}
第 2 小节

二分搜索：像查字典

二分搜索的思路像查英文字典：先看中间一页，如果目标词在中间之后，就翻后半本；如果在中间之前，就翻前半本。每次都能把范围砍掉一半。

前提是数据必须已经排好序。如果数据乱七八糟，二分搜索就会给出错误结果。它的复杂度是 O(log n)，意思是在 n 个元素里查找，最多只需要 log₂n 次。

Python 二分搜索
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

scores = [60, 72, 81, 88, 95]
print(binary_search(scores, 88))  # 3
print(binary_search(scores, 70))  # -1
C++ 二分搜索
#include <iostream>
#include <vector>
using namespace std;

int binarySearch(vector<int>& arr, int target) {
    int left = 0, right = arr.size() - 1;
    while (left <= right) {
        int mid = (left + right) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

int main() {
    vector<int> scores = {60, 72, 81, 88, 95};
    cout << binarySearch(scores, 88) << endl;  // 3
    cout << binarySearch(scores, 70) << endl; // -1
    return 0;
}
第 3 小节

线性 vs 二分：怎么选

两种搜索没有绝对的优劣，关键看数据是否已经排序，以及你要搜多少次。

对比项线性搜索二分搜索
数据要求不需要排序必须已排序
时间复杂度O(n)O(log n)
最坏查找次数n 次约 log₂n 次
适用场景数据少、未排序数据多、已排序

一个细节是：如果数据只搜一次，先排序再二分可能不划算，因为排序本身也要花时间。但如果要反复查找，先排序一次再二分就很赚了。

第 4 小节

综合实战：猜数字游戏

用二分搜索的思想猜一个 1 到 100 的数

来玩一个经典游戏：你心里想一个 1 到 100 之间的整数，程序用二分策略来猜，你每次只回答“大了”“小了”或“对了”。

因为每次把范围砍掉一半，最多只要 7 次就能猜中（2⁷ = 128 > 100）。这比从 1 开始逐个猜（最多 100 次）快得多。

二分猜数字
def guess_number():
    low, high = 1, 100
    print("请想一个 1 到 100 之间的整数。")
    while low <= high:
        mid = (low + high) // 2
        print("我猜是：", mid)
        ans = input("大了/小了/对了：")
        if ans == "对了":
            print("耶，猜中了！")
            return
        elif ans == "大了":
            high = mid - 1
        else:
            low = mid + 1

guess_number()
guess_number.cpp
#include <iostream>
#include <string>
using namespace std;

void guess_number() {
    int low = 1, high = 100;
    cout << "请想一个 1 到 100 之间的整数。" << endl;
    while (low <= high) {
        int mid = (low + high) / 2;
        cout << "我猜是：" << mid << endl;
        string ans;
        cout << "大了/小了/对了：";
        cin >> ans;
        if (ans == "对了") {
            cout << "耶，猜中了！" << endl;
            return;
        } else if (ans == "大了") {
            high = mid - 1;
        } else {
            low = mid + 1;
        }
    }
}

int main() {
    guess_number();
    return 0;
}

动手运行一下，故意把数字藏得偏一点，看看程序最多用几步能猜中。理解了这种“每次砍一半”的策略，你就掌握了二分搜索的核心。
