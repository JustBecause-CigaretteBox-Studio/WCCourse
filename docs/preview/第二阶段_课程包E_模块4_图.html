第 1 小节

图是什么

节点和边组成的关系网

图由顶点（Vertex）和边（Edge）组成。顶点就像城市，边就像城市之间的路。如果边有方向，就叫有向图；如果边有权重（比如路程公里数），就叫带权图。

社交网络、地图导航、计算机网络路由，背后都是图。图能表达非常灵活的关系，不像树那样必须有一个根和明确的父子关系。

在程序中表示图，最常用的两种方法是邻接矩阵和邻接表。

图：4 个顶点、4 条边的无向图（顶点是城市，边是城市之间的路）
第 2 小节

邻接矩阵

用二维表格记录谁和谁相连

邻接矩阵是一个 n × n 的表格，matrix[i][j] 表示顶点 i 到顶点 j 是否有边。对于无权图，常用 0 和 1 表示；带权图则存权重，这里暂时不讨论。

邻接矩阵查询「i 和 j 是否相邻」非常快，只需要 O(1)。但如果图很稀疏（边很少），会浪费大量空间。

图：上面那张图的邻接矩阵（行 i、列 j 交叉处为 1 表示有边，0 表示无边；无向图关于对角线对称）
# 4 个节点 0,1,2,3 的邻接矩阵（无向图）
# 0-1, 1-2, 2-3, 0-3 之间有边
n = 4
matrix = [[0] * n for _ in range(n)]
edges = [(0, 1), (1, 2), (2, 3), (0, 3)]
for u, v in edges:
    matrix[u][v] = 1
    matrix[v][u] = 1      # 无向图要对称

print(matrix[0][1])     # 1，表示 0 和 1 相邻
print(matrix[0][2])     # 0，表示 0 和 2 不相邻
const int N = 4;
int matrix[N][N] = {0};

void addEdge(int u, int v) {
    matrix[u][v] = 1;
    matrix[v][u] = 1;     // 无向图要对称
}

addEdge(0, 1);
addEdge(1, 2);
addEdge(2, 3);
addEdge(0, 3);

cout << matrix[0][1];    // 1
第 3 小节

邻接表

只记录每个节点的邻居

邻接表只存储每个顶点直接相连的顶点列表。对于稀疏图，邻接表更省空间；想遍历某个顶点的所有邻居，也非常自然。

图：同一张图的邻接表（每个节点只记录自己的邻居：0→[1,3]，1→[0,2]，2→[1,3]，3→[0,2]）
from collections import defaultdict

graph = defaultdict(list)
edges = [(0, 1), (1, 2), (2, 3), (0, 3)]
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)    # 无向图

print(graph[0])   # [1, 3]
print(graph[2])   # [1, 3]
#include <vector>
using namespace std;

vector<vector<int>> graph(4);
void addEdge(int u, int v) {
    graph[u].push_back(v);
    graph[v].push_back(u);    // 无向图
}

addEdge(0, 1);
addEdge(1, 2);
addEdge(2, 3);
addEdge(0, 3);

for (int neighbor : graph[0]) {
    cout << neighbor << " ";   // 输出 1 3
}
第 4 小节

综合实战：图的 DFS 遍历

从起点开始尽可能往深处走

深度优先搜索（DFS）会从一个顶点出发，先走到一个邻居，再沿着这个邻居继续走到底，直到没路可走了再回退。非常适合判断连通性、寻找路径等问题。

实现 DFS 通常用递归或显式栈，并需要一个 visited 集合防止重复访问。

图：从节点 0 出发的 DFS 访问顺序（蓝边为走过的路径，节点里的数字即访问次序：0 → 1 → 2 → 3）
def dfs(graph, node, visited):
    visited.add(node)
    print(node, end=' ')
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

visited = set()
dfs(graph, 0, visited)   # 输出 0 1 2 3（顺序可能因邻居顺序不同）
#include <vector>
#include <iostream>
using namespace std;

vector<bool> visited(4, false);

void dfs(const vector<vector<int>>& graph, int node) {
    visited[node] = true;
    cout << node << " ";
    for (int neighbor : graph[node]) {
        if (!visited[neighbor]) {
            dfs(graph, neighbor);
        }
    }
}

// 使用前需要先建好 graph
dfs(graph, 0);
