第 1 小节

爬虫是什么

像图书管理员一样自动收集公开信息

想象一下，你想整理全校图书馆的书目：书名、作者、放在哪个书架。如果一本本手动抄，效率低得离谱。于是你派了一个机器人：它按照你给的规则，在书架间走动，把书名和作者自动抄下来，最后汇总成一张表格。这个机器人，就是现实世界里爬虫的雏形。

在互联网上，网页就是书架，网页里的文字、图片、链接就是书。爬虫是一段程序，它自动访问网页，把需要的信息摘出来，存到文件或数据库里。我们这门课用 Python 来写爬虫。

💡 爬虫的本质

爬虫 = 自动化的「浏览 + 复制 + 整理」。它不会创造新信息，而是把已经公开的信息按我们需要的方式重新组织。

一个简单的 Python 爬虫长这样：先用 requests 把网页内容下载下来，再用 BeautifulSoup 解析其中的标题。

first_crawl.py
import requests
from bs4 import BeautifulSoup

url = "https://example.com"
resp = requests.get(url)              # 向网页发出请求
soup = BeautifulSoup(resp.text, "html.parser")
print(soup.title.string)              # 提取网页标题

代码虽然短，但它已经做了爬虫最核心的两件事：请求和解析。后面的模块会分别把这两件事讲透。

第 2 小节

法律与道德边界

公开不等于可以随意使用

爬虫能做的事很多，但不是想抓就能抓。网页虽然是公开的，里面的数据仍然受法律、网站服务条款和道德约束。写爬虫之前，先问自己三个问题：

⚠️ 三问原则

1. 这些信息允许被机器大规模抓取吗？

2. 抓取后我会不会侵犯别人的隐私或版权？

3. 我的行为会不会给目标网站造成负担？

例如，抓取天气预报、公开的课程表、公告栏信息，通常是允许的；但抓取个人隐私、付费内容、需要登录才能看到的内部数据，往往越界。很多网站会在页脚写明「使用条款」，访问即代表同意。

在中国，爬虫相关的法律主要有《网络安全法》《数据安全法》《个人信息保护法》等。违反robots.txt、绕过技术保护措施、抓取个人信息并出售，都可能触犯法律。初学者最容易踩的坑是：觉得「网页公开就可以随便抓」。

ethics_check.py
# 抓取前先做伦理自查清单
can_crawl = [
    "数据是公开可见的",
    "不涉及个人隐私",
    "不违反网站使用条款",
    "不会高频请求造成服务器压力",
]

for item in can_crawl:
    print("检查：", item)

本课程所有示例都会选择明显允许抓取的公开站点，或只在本地文件中演示解析过程。你在自己实践时，也要先确认目标是否允许被抓取。

第 3 小节

robots.txt：网站的「访客须知」

学爬虫前先学会看门牌

几乎所有正规网站都会在根目录放一个叫 robots.txt 的文件，用来告诉爬虫：哪些页面可以抓，哪些页面请不要碰。它就像图书馆门口的「访客须知」，不遵守会被请出去，严重时还会被法律追责。

例如，一个典型的 robots.txt 内容如下：

robots.txt 示例
User-agent: *
Disallow: /admin/
Disallow: /private/
Allow: /public/
Crawl-delay: 2

含义是：所有爬虫（User-agent: *）不要访问 /admin/ 和 /private/，可以访问 /public/，并且请求间隔至少 2 秒。

用 Python 读取 robots.txt 很简单：

read_robots.py
import requests

url = "https://example.com/robots.txt"
resp = requests.get(url)
print(resp.text)
🔑 本小节小结

robots.txt 不是技术障碍，而是道德与法律的边界提示。写爬虫前先读它，是合格爬虫工程师的基本素养。

第 4 小节

综合实战

为指定网站写一份「抓取合规检查表」

实战不需要写复杂代码。选择一个你感兴趣的公开网站（例如 Wikipedia、某个大学公告栏、或政府公开数据站），完成下面这份检查表：

checklist.py
# 抓取合规检查表（在浏览器或 Python 中填写）
site = "https://zh.wikipedia.org"

# 1. 打开并阅读 robots.txt
robots_url = site + "/robots.txt"
print("robots.txt 地址：", robots_url)

# 2. 检查目标页面是否在 Disallow 列表中
print("目标页面是否允许抓取：", "需要人工检查")

# 3. 确认数据是否公开、是否涉及版权或个人隐私
print("是否公开数据：", "需要人工确认")

# 4. 设定抓取间隔（秒）
crawl_delay = 3
print("请求间隔：", crawl_delay, "秒")

完成后，把上面的 site 换成你要实践的网站，先用浏览器打开它的 robots.txt，看看目标路径有没有被 Disallow。如果明确被禁止，就换另一个目标。这个习惯能帮你避开 90% 的法律风险。

🔑 模块 1 小结

✅ 爬虫是自动抓取公开信息的程序。

✅ 抓取前必须考虑法律、道德和网站条款。

✅ robots.txt 是判断能否抓取的第一道门。
