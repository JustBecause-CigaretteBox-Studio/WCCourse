第 1 小节

为什么要画图表

一图胜千言

同样的数据，用表格看可能需要反复对比，用图表看却能一眼看出规律。数据可视化的作用不是让图更好看，而是让数据更快被理解。

Python 里最常用的两个可视化库是 Matplotlib 和 Plotly。Matplotlib 像一支铅笔，简单、直接，适合快速出图；Plotly 像一台智能绘图仪，能做出交互式图表，鼠标悬停就能看到具体数值。本模块会分别介绍它们的基本用法。

first_plot.py
import matplotlib.pyplot as plt

# 一周步数
week = ["周一", "周二", "周三", "周四", "周五", "周六", "周日"]
steps = [6500, 7200, 8000, 5600, 9100, 12000, 3000]

plt.plot(week, steps, marker="o")
plt.title("一周步数趋势")
plt.xlabel("日期")
plt.ylabel("步数")
plt.savefig("steps.png")      # 保存为图片
plt.show()

这段代码做了四件事：导入工具、准备数据、画图、保存/显示。初学者最容易忘的是 plt.show()，没有它，程序运行完图可能一闪而过。

第 2 小节

常用图表：柱状图与饼图

对比与占比

不同的图表适合回答不同的问题。想看「谁多谁少」，用柱状图；想看「占总体的比例」，用饼图；想看「随时间变化的趋势」，用折线图。选对图表，表达效率会高很多。

下面这段代码用 Matplotlib 画柱状图，展示各品类的销售额；再用饼图展示支出占比。

bar_pie.py
import matplotlib.pyplot as plt

# 柱状图：各品类销售额
categories = ["数码", "食品", "服饰", "书籍"]
sales = [5600, 2100, 3400, 1200]

plt.figure(figsize=(8, 4))
plt.bar(categories, sales, color=["#0ea5e9", "#10b981", "#f59e0b", "#ef4444"])
plt.title("各品类销售额")
plt.ylabel("销售额（元）")
plt.savefig("sales_bar.png")
plt.show()

# 饼图：月度支出占比
labels = ["房租", "餐饮", "交通", "娱乐", "其他"]
costs = [2500, 1800, 400, 600, 300]

plt.figure(figsize=(6, 6))
plt.pie(costs, labels=labels, autopct="%1.1f%%")
plt.title("月度支出占比")
plt.savefig("cost_pie.png")
plt.show()

autopct="%1.1f%%" 是饼图里的格式化写法，作用是把百分比显示在扇区上。学会它，以后做报告就不用再手动贴数字了。

第 3 小节

交互式图表：用 Plotly 讲动态故事

鼠标悬停看细节

Matplotlib 的图是静态的，适合做报告插图。如果你想在网页或演示中让别人自己探索数据，Plotly 更合适。它会生成 HTML 文件，里面包含可缩放、可悬停的交互式图表。

plotly_demo.py
import plotly.express as px

# 准备数据
df = px.data.gapminder().query("country == 'China'")

# 画交互式折线图：中国 GDP 随时间变化
fig = px.line(df, x="year", y="gdpPercap", title="中国人均 GDP 变化趋势")
fig.write_html("china_gdp.html")
fig.show()

Plotly 的写法和 Pandas 很像：先准备 DataFrame，再告诉它 x 轴、y 轴、标题分别是什么。fig.write_html() 可以把图表保存成网页，双击就能打开。发给别人看的时候非常方便。

plotly_bar.py
import plotly.express as px
import pandas as pd

df = pd.DataFrame({
    "商品": ["耳机", "鼠标", "键盘", "显示器"],
    "销量": [30, 50, 20, 15]
})

fig = px.bar(df, x="商品", y="销量", title="商品销量对比", color="商品")
fig.write_html("sales_interactive.html")

有了 Matplotlib 和 Plotly，你就能同时应付「快速出图」和「交互式展示」两种需求。下一节把它们和 Pandas 串起来，完成一个完整的数据报告。

第 4 小节

综合实战：班级成绩可视化报告

读数据、做统计、画图表一气呵成

这一节的任务是把前面模块 3 的成绩分析结果可视化：用柱状图对比各班平均分，用饼图展示优秀学生（总分 >= 250）和普通学生的比例，再用折线图展示每个人的总分。

grade_visualization.py
import pandas as pd
import matplotlib.pyplot as plt

# 1. 读数据并计算总分
df = pd.DataFrame({
    "姓名": ["阿明", "小红", "小刚", "小丽", "小军", "小芳"],
    "班级": ["A班", "A班", "B班", "B班", "A班", "B班"],
    "语文": [85, 92, 58, 76, 88, 95],
    "数学": [90, 88, 62, 95, 70, 85],
    "英语": [78, 95, 70, 82, 65, 90]
})
df["总分"] = df["语文"] + df["数学"] + df["英语"]

# 2. 各班平均分柱状图
class_avg = df.groupby("班级")["总分"].mean()
plt.figure(figsize=(6, 4))
plt.bar(class_avg.index, class_avg.values, color=["#0ea5e9", "#10b981"])
plt.title("各班平均总分")
plt.ylabel("平均分")
plt.savefig("class_avg.png")
plt.show()

# 3. 优秀学生占比饼图
excellent = (df["总分"] >= 250).sum()
normal = len(df) - excellent
plt.figure(figsize=(5, 5))
plt.pie([excellent, normal], labels=["优秀", "普通"], autopct="%1.1f%%", colors=["#f59e0b", "#94a3b8"])
plt.title("学生成绩分布")
plt.savefig("grade_pie.png")
plt.show()

print("图表已生成：class_avg.png, grade_pie.png")

这个项目展示了完整的数据分析流程：数据 → 清洗/计算 → 统计 → 可视化。到这一步，你已经能做出一份像模像样的数据报告了。下一个模块会把这套流程应用到你自己的真实数据上。
