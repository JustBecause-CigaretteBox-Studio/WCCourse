第 1 小节

创建游戏窗口

做任何 Pygame 项目，第一步都是打开一个窗口。你可以把窗口想象成剧院的舞台：观众只能看到舞台上发生的事，所有角色、灯光、特效都要放在舞台里。

下面这行代码会创建一个 800×600 像素的窗口，并把标题设为「我的第一个游戏」：

window.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("我的第一个游戏")

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

pygame.quit()

关键点：pygame.display.set_mode((宽, 高)) 返回的 screen 就是「舞台」。后续所有绘制都在 screen 上进行。

第 2 小节

在画布上画图

有了窗口，我们就可以在「画布」上画画。画布就是 screen 这个对象。Pygame 提供了很多画图函数：矩形、圆、直线、多边形都可以直接画。

想象你拿着画笔在一张白纸上作画：screen.fill() 先铺好背景色，pygame.draw.rect() 画矩形，pygame.draw.circle() 画圆。

draw.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("画布练习")

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((30, 30, 30))                 # 深灰背景
    pygame.draw.rect(screen, (0, 200, 255), (100, 100, 120, 80))
    pygame.draw.circle(screen, (255, 100, 100), (400, 300), 50)
    pygame.display.flip()                   # 把画好的内容显示出来

pygame.quit()

注意：所有绘制操作都先在内存里完成，必须调用 pygame.display.flip() 才能真正刷新到屏幕上。忘了这行，窗口会一直黑屏。

第 3 小节

游戏循环

游戏和普通的程序最大的区别是：游戏需要一直运行，不断更新画面、处理输入。这个不停转动的核心就叫做游戏循环。

游戏循环就像电影放映机：每一帧都是一张静止的画面，但以每秒 60 张的速度连续播放，人眼就看成了动画。

loop.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()          # 控制帧率

x = 100
running = True
while running:                       #你是否记得之前教程里的一句话：游戏是一个巨大的while循环
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    x = (x + 2) % 800                # 每帧向右移动 2 像素

    screen.fill((20, 20, 20))
    pygame.draw.circle(screen, (100, 255, 150), (x, 300), 30)
    pygame.display.flip()
    clock.tick(60)                   # 每秒最多 60 帧

pygame.quit()

clock.tick(60) 让循环以稳定的 60 FPS 运行。如果没有它，游戏速度会随电脑性能变化，导致动画忽快忽慢。

第 4 小节

综合实战：弹跳的色块

把前面的知识串起来：创建一个窗口，画一个方块，让它在窗口里来回反弹。

bounce.py
import pygame

pygame.init()
screen = pygame.display.set_mode((640, 480))
pygame.display.set_caption("弹跳的色块")
clock = pygame.time.Clock()

rect = pygame.Rect(50, 100, 60, 60)
speed = [4, 3]

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    rect.x += speed[0]
    rect.y += speed[1]

    if rect.left < 0 or rect.right > 640:
        speed[0] = -speed[0]
    if rect.top < 0 or rect.bottom > 480:
        speed[1] = -speed[1]

    screen.fill((25, 25, 35))
    pygame.draw.rect(screen, (255, 200, 80), rect)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

练习：尝试把速度改成 [6, 6]，或者把方块大小改成 (30, 30)，观察变化。
