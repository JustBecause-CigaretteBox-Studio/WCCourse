Vibe coding：有 AI 还学什么算法

以前，想做出主页下方那些「项目」，你得先练很久很久的题。 然而本教程编写于 2026 年，作者会告诉你： 编程水平不会成为你做项目的限制，想象力才是。 这一章，我们就用 vibe coding 做出一个看起来有点难的项目。

第 1 小节

什么是 Vibe coding

你负责描述想法，AI 负责写代码

如果你在初学时点开了主页下方的「项目」，你可能会觉得这些项目有些困难。 本教程练习项目一栏的描述是这么写的：

以前，你需要回到题目练习里练题，慢慢提升自己的编程水平，才有能力做项目。

然而此教程编写于 2026 年，因此作者会告诉你：练题只是为了好玩，如果觉得不好玩了就不要练了。 因为如今——编程水平不会成为你做项目的限制，想象力才是。

vibe coding 可以让不那么熟练的初学者也完成项目。

🔑 定义

Vibe coding，就是「你负责描述想法，AI 负责写代码，你只把关不手敲」的开发方式。

总之就是：自己手搓 → AI 帮你搓。

但是我们应当写些什么呢？这里需要记住 vibe coding 中三件十分重要的事情：

🪄 三个法宝

复制：按！住！Ctrl！再！按！C！（苹果电脑是 ⌘+C）

粘贴：按！住！Ctrl！再！按！V！（苹果电脑是 ⌘+V）

不！会！就！让！ A！ I！ 做！

第 5 小节

第二步：把提示词发给 AI

新建会话，粘贴，发送

AI 会生成一份像样的提示词。接下来新建一个会话， 把这份提示词复制粘贴上去。提示词大概长这样： 

## 项目：口算题自动生成器

### 目标
开发一个交互式「出题自动机」，能够根据用户输入自动生成加减乘除口算题并给出答案。

### 功能需求
1. 参数采集
   - 询问用户想生成多少道题（正整数，默认 10 道）
   - 询问数字范围（最小值、最大值，默认 1~20）
   - 询问是否包含乘除法（默认包含，可开关）
2. 题目生成
   - 随机生成指定数量的口算题
   - 运算符：+、-、×、÷
   - 减法结果不得为负数
   - 除法必须为整除（余数为 0）
   - 每道题的数字必须在用户指定的范围内
   - 题目格式：A [运算符] B = ?
3. 答案输出
   - 每道题后附正确答案
   - 可选：将题目和答案导出为文本文件
4. 交互体验
   - 友好的命令行/终端界面，或简单的 GUI
   - 输入校验（非法输入时提示重新输入）
   - 支持重新生成新的一批题目

你也可以把目标说得详细一点，例如让它做一个 Web 应用 / 单文件 HTML 应用。 你正在看的这个教程就是一个 Web 应用——单文件 HTML 应用打开会非常方便，双击就能用。 只需把「目标」那段改成： 

### 目标
开发一个交互式「出题自动机」（一个单文件 HTML 应用），能够根据用户输入自动生成加减乘除口算题并给出答案。
