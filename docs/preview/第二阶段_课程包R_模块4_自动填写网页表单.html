第 1 小节

让程序替你操作浏览器

浏览器自动化的基本概念

有些工作必须在网页上完成：填表、查数据、下载报表。如果每次都要手动点开浏览器、输入账号、点按钮，就很低效。浏览器自动化就是让 Python 替你开车：你告诉它「打开哪个网页、点哪里、输什么」，它就能自动执行。

目前最常用的两个工具是 Selenium 和 Playwright。Selenium 资历老、资料多；Playwright newer、速度更快、语法更现代。两者思路一样：启动浏览器 → 定位元素 → 操作元素。

本模块以 Selenium 为例讲解概念，同时也给出 Playwright 的对照写法，帮助你举一反三。

第 2 小节

定位元素与填写输入框

找到网页上的输入框

网页上的每个输入框、按钮，在代码里都是一个「元素」。我们要先找到它，再操作它。最常用的定位方式是 id 和 name。

selenium_input.py
from selenium import webdriver
from selenium.webdriver.common.by import By

# 启动浏览器（需要安装对应浏览器的驱动）
driver = webdriver.Chrome()

# 打开网页
driver.get("https://example.com/login")

# 找到用户名输入框并填写
username = driver.find_element(By.ID, "username")
username.send_keys("my_name")

# 找到密码框并填写
password = driver.find_element(By.NAME, "password")
password.send_keys("my_password")

# 退出浏览器
driver.quit()

这里 find_element(By.ID, "username") 就像在说「找 id 是 username 的那个输入框」。send_keys() 则是往框里打字。

如果用 Playwright，写法会是这样：

playwright_input.py
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto("https://example.com/login")
    page.fill("#username", "my_name")
    page.fill("input[name='password']", "my_password")
    browser.close()
第 3 小节

点击按钮与提交表单

让程序按下提交键

填完账号密码后，还要点登录按钮。Selenium 用 .click()，Playwright 用 .click()，名字一样，思路也一样。

selenium_click.py
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("https://example.com/login")

driver.find_element(By.ID, "username").send_keys("my_name")
driver.find_element(By.NAME, "password").send_keys("my_password")

# 点击登录按钮
driver.find_element(By.CSS_SELECTOR, "button[type='submit']").click()

# 等待页面加载（简单等待，实际建议用显式等待）
driver.implicitly_wait(3)

print("当前标题：", driver.title)
driver.quit()

真实项目中，网页加载需要时间，建议用「显式等待」而不是固定 sleep，这样更稳定。不过作为入门，先理解「定位 → 输入 → 点击」这三步最重要。

第 4 小节

综合实战：自动登录示例

把打开、填写、点击串起来

下面是一个相对完整的自动登录脚本。它打开登录页、填账号密码、点登录、检查页面标题，最后关闭浏览器。

auto_login.py
from selenium import webdriver
from selenium.webdriver.common.by import By

def auto_login(url, username, password):
    driver = webdriver.Chrome()
    try:
        driver.get(url)

        driver.find_element(By.ID, "username").send_keys(username)
        driver.find_element(By.ID, "password").send_keys(password)
        driver.find_element(By.ID, "login-btn").click()

        # 简单等待页面跳转
        driver.implicitly_wait(5)

        if "首页" in driver.title:
            print("登录成功")
        else:
            print("登录失败，请检查账号密码或页面结构")
    finally:
        driver.quit()

auto_login("https://example.com/login", "my_name", "my_password")

这个脚本把前面三节的内容串了起来：启动浏览器、定位元素、输入内容、点击按钮、判断结果。你可以把登录换成任何表单操作，比如自动填问卷、自动查快递。
