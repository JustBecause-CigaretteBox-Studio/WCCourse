第 1 小节

函数自己调用自己

递归看起来就像俄罗斯套娃，最经典的例子是:从前有座山，山上有座庙，庙里有个老和尚在给小和尚讲故事，老和尚讲：“从前有座山，山上有座庙……”

再例如，计算阶乘：5! = 5 × 4 × 3 × 2 × 1。如果我们知道 4! 是多少，5! 就是 5 × 4!；而 4! 又是 4 × 3!……一直拆到 1! = 1。

也就是说，一个函数在解决问题时，调用了同一个函数来处理更小的子问题，这就是递归。

Python 阶乘
def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120
C++ 阶乘
#include <iostream>
using namespace std;

int factorial(int n) {
    if (n == 1) return 1;
    return n * factorial(n - 1);
}

int main() {
    cout << factorial(5) << endl;  // 120
    return 0;
}
图示 · 阶乘的递归过程：先一层层“调用进去”，再一层层“返回出来”

注意 factorial(5) 会调用 factorial(4)，后者再调用 factorial(3)，直到 factorial(1) 直接返回 1，然后一层一层返回结果。也就是说factorial(1)是最先被知道的，然后是factorial(2)、factorial(3)……。

第 2 小节

递归的两个关键

写递归时，一定要想清楚两件事，缺一不可：

  • 终止条件：什么时候不用再拆下去了？阶乘里就是 n == 1。
  • 递推关系：怎么把大问题变成小问题？阶乘里就是 n! = n × (n-1)!。

如果忘了终止条件，函数会永远调用自己，直到程序崩溃，俗称“栈溢出”。开头那个“从前有座山……”的故事就是一个没有终止条件的递归。

再看一个例子：斐波那契数列，第 n 个数等于前两个数之和。

Python 斐波那契
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

for i in range(8):
    print(fib(i), end=" ")
# 0 1 1 2 3 5 8 13
C++ 斐波那契
#include <iostream>
using namespace std;

int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}

int main() {
    for (int i = 0; i < 8; i++)
        cout << fib(i) << " ";
    // 0 1 1 2 3 5 8 13
    return 0;
}
图示 · 斐波那契的递归调用树：同一个子问题被反复计算

同一份子问题反复计算，就是朴素递归的代价（模块 6 会讲怎么优化）。

这里有两个终止条件：fib(0)=0 和 fib(1)=1。少了任意一个，递归就会一直算到负数。

第 3 小节

递归和循环可以互换

很多能用循环解决的问题，也能用递归解决，只是表达角度不同。循环更像“我要重复做 n 次”，递归更像“这个问题和更小的同类问题有关”。

比如计算 1 到 n 的和，循环版本是从 1 一路加过去，递归版本是“n 加上 1 到 n-1 的和”。

递归求和
def sum_recursive(n):
    if n == 1:
        return 1
    return n + sum_recursive(n - 1)

print(sum_recursive(10))  # 55
sum_recursive.cpp
#include <iostream>
using namespace std;

int sum_recursive(int n) {
    if (n == 1) return 1;
    return n + sum_recursive(n - 1);
}

int main() {
    cout << sum_recursive(10) << endl;  // 55
    return 0;
}

递归并不是在所有地方都比循环好。它的优点是代码更贴近问题本身，缺点是调用层级太深会消耗更多内存。实际使用时，如果问题天然适合拆分，就用递归；否则用循环更稳妥。

第 4 小节

综合实战：爬楼梯

用递归解决经典的爬楼梯问题

问题：你每次可以走 1 级或 2 级台阶，问爬 n 级楼梯一共有多少种不同的走法？

这个问题天然适合递归：最后一步要么是从 n-1 级跨 1 级上来，要么是从 n-2 级跨 2 级上来。所以 f(n) = f(n-1) + f(n-2)，是不是很眼熟？这其实和斐波那契数列是同一个结构。

Python 爬楼梯
def climb(n):
    if n == 1:
        return 1
    if n == 2:
        return 2
    return climb(n - 1) + climb(n - 2)

for i in range(1, 8):
    print(f"爬 {i} 级有 {climb(i)} 种走法")

# 爬 1 级有 1 种走法
# 爬 2 级有 2 种走法
# 爬 3 级有 3 种走法
# 爬 4 级有 5 种走法
# ...
C++ 爬楼梯
#include <iostream>
using namespace std;

int climb(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return climb(n - 1) + climb(n - 2);
}

int main() {
    for (int i = 1; i <= 7; i++)
        cout << "爬 " << i << " 级有 " << climb(i) << " 种走法" << endl;
    return 0;
}

动手把 n 改成 10、15、20，观察程序运行时间的变化。你会发现这个版本的递归会重复计算很多子问题，这正是下一模块“综合实战”要升级的方向。
