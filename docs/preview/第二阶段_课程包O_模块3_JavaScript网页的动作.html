事件、DOM 操作、交互

第 1 小节

事件

HTML 是骨架，CSS 是衣服，而 JavaScript 是让网页动起来的神经系统。没有 JS，网页就像一幅画；有了 JS，网页才能响应你的点击、输入和滑动。

事件（Event）就是用户或浏览器发出的「信号」。最常见的有：

  • click：点击
  • mouseover：鼠标移上去
  • input：输入框内容变化
  • submit：表单提交

给按钮添加点击事件最简单的方式是 addEventListener：

事件监听
// 先找到页面上的按钮
const btn = document.getElementById("myBtn");

// 当按钮被点击时，执行后面的函数
btn.addEventListener("click", function () {
  alert("你点了我一下！");
});

也可以把事件直接写在 HTML 标签上，但不推荐，因为会把结构和行为混在一起：

行内事件（不推荐）
<button onclick="alert('你点了我一下！')">点我</button>

事件就像门铃：有人按门铃（触发事件），门铃响（执行函数）。JS 的工作就是帮你在合适的地方装上「门铃」。

第 2 小节

DOM 操作

DOM（Document Object Model）是浏览器把 HTML 文档转换成的一棵「树」。每个标签都是树上的一个节点，JS 可以通过 DOM 来查找、修改、添加或删除这些节点。

最常用的查找方法：

查找元素
// 根据 id 查找（id 在页面中应唯一）
const title = document.getElementById("title");

// 根据 class 查找，返回一组元素
const items = document.querySelectorAll(".item");

// 查找第一个匹配的元素
const firstItem = document.querySelector(".item");

找到元素后，可以修改它的内容、样式或类名：

修改元素
const box = document.getElementById("box");

// 改文字
box.textContent = "新文字";

// 改样式
box.style.backgroundColor = "#0ea5e9";

// 添加 / 移除类名
box.classList.add("active");
box.classList.remove("hidden");
box.classList.toggle("dark");

DOM 操作就像遥控电视：你先选中电视（查元素），然后按按钮换台（改内容）、调音量（改样式）或开关机（加/减类名）。

第 3 小节

交互

事件 + DOM 操作 = 真正的交互。下面我们做一个「实时字数统计」小功能：用户在输入框里打字，旁边实时显示字数。

实时字数统计
<input type="text" id="nameInput" placeholder="请输入你的名字">
<p>已输入 <span id="count">0</span> 个字</p>

<script>
  const input = document.getElementById("nameInput");
  const count = document.getElementById("count");

  input.addEventListener("input", function () {
    count.textContent = input.value.length;
  });
</script>

这段代码把三件事连在了一起：

  • 找到输入框和显示字数的元素。
  • 监听 input 事件，每次输入都触发。
  • 用 input.value.length 拿到当前字数，更新到页面上。

交互的本质就是这样：监听用户动作 → 读取或修改页面 → 给用户反馈。掌握了这条链路，你就能做出按钮、表单验证、轮播图、待办清单等常见效果。

第 4 小节

综合实战

做一个点击计数器

现在动手做一个「点赞/计数器」：页面上有一个数字和一个按钮，每点一次按钮，数字加 1。

counter.html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>点击计数器</title>
  <style>
    body { text-align: center; padding-top: 80px; font-family: sans-serif; }
    #number { font-size: 64px; font-weight: 900; color: #0ea5e9; }
    button { padding: 12px 24px; font-size: 16px; margin-top: 16px; cursor: pointer; }
  </style>
</head>
<body>
  <div id="number">0</div>
  <button id="addBtn">+1</button>

  <script>
    let count = 0;
    const number = document.getElementById("number");
    const addBtn = document.getElementById("addBtn");

    addBtn.addEventListener("click", function () {
      count = count + 1;
      number.textContent = count;
    });
  </script>
</body>
</html>

实战任务：

  1. 把上面的代码保存为 counter.html，用浏览器打开。
  2. 添加一个「-1」按钮，点击时数字减 1。
  3. 尝试当数字大于 10 时，把数字颜色变成红色。
  4. 挑战：给计数器加一个「重置为 0」按钮。
