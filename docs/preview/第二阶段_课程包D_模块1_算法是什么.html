第 1 小节

算法就在生活里

“算法”听起来很高深，其实它就是你解决一件事的清晰步骤。比如早上做一杯手冲咖啡：烧水、磨豆、润湿滤纸、注水、等待滴滤——这一套步骤就是一种算法。

编程里的算法也一样：把“我想算什么”拆成一步一步，让计算机照着做。计算机很听话，但也很死板，它不会猜你的心思，所以步骤必须清楚、无歧义。

举个例子：怎么在一串钥匙里找到家门钥匙？一种办法是从左到右逐个看，直到找到为止。这个“逐个看”的步骤，就是一种最简单的查找算法。

find_key.py
keys = ["车钥匙", "自行车钥匙", "家门钥匙", "公司门禁卡"]
target = "家门钥匙"

for key in keys:
    if key == target:
        print("找到了：", key)
        break
else:
    print("没找到")
find_key.cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    vector<string> keys = {"车钥匙", "自行车钥匙", "家门钥匙", "公司门禁卡"};
    string target = "家门钥匙";
    bool found = false;

    for (const string& key : keys) {
        if (key == target) {
            cout << "找到了：" << key << endl;
            found = true;
            break;
        }
    }
    if (!found) {
        cout << "没找到" << endl;
    }
    return 0;
}

这段代码的核心不是语法，而是它背后的思路：一个个检查，遇到目标就停下来。把生活里的方法翻译成代码，就是算法入门的第一步。

第 2 小节

算法长什么样

一个算法通常包含三个部分：输入、处理步骤、输出。输入是你要处理的数据，步骤是你要计算机做的事，输出是最后得到的结果。

比如判断一个数是奇数还是偶数：输入是一个整数，处理步骤是“除以 2 看余数”，输出是“奇数”或“偶数”。

判断奇偶
def odd_or_even(n):
    if n % 2 == 0:
        return "偶数"
    else:
        return "奇数"

print(odd_or_even(7))   # 奇数
print(odd_or_even(10))  # 偶数
odd_even.cpp
#include <iostream>
#include <string>
using namespace std;

string odd_or_even(int n) {
    if (n % 2 == 0) return "偶数";
    else return "奇数";
}

int main() {
    cout << odd_or_even(7) << endl;   // 奇数
    cout << odd_or_even(10) << endl;  // 偶数
    return 0;
}

好的算法还有两个重要特点：

  • 有穷性：步骤必须在有限步内结束，不能无限跑下去。
  • 确定性：每一步做什么必须明确，不能模棱两可。

只要满足这些，它就是一个合格的算法。至于是用 Python 还是 C++ 写出来，只是“穿什么衣服”的问题，思路才是内核。

第 3 小节

把思路写成代码：累加

回忆这个问题：计算 1 加到 n 的总和。比如 n=5，结果就是 1+2+3+4+5=15。

最直观的思路是用循环逐个加。这对应我们小时候“掰着手指一个一个数”的方法，计算机特别擅长这种重复工作。

循环累加
def sum_to_n(n):
    total = 0
    for i in range(1, n + 1):
        total = total + i
    return total

print(sum_to_n(5))   # 15
print(sum_to_n(100)) # 5050
sum_loop.cpp
#include <iostream>
using namespace std;

int sum_to_n(int n) {
    int total = 0;
    for (int i = 1; i <= n; i++) {
        total = total + i;
    }
    return total;
}

int main() {
    cout << sum_to_n(5) << endl;   // 15
    cout << sum_to_n(100) << endl; // 5050
    return 0;
}

数学家高斯小时候发现了一个更快的办法：1+100、2+99、3+98……每一对都是 101，一共有 50 对，所以结果是 5050。写成公式就是：

公式法
def sum_to_n_fast(n):
    return n * (n + 1) // 2

print(sum_to_n_fast(100))  # 5050
sum_formula.cpp
#include <iostream>
using namespace std;

int sum_to_n_fast(int n) {
    return n * (n + 1) / 2;
}

int main() {
    cout << sum_to_n_fast(100) << endl;  // 5050
    return 0;
}

两种方法结果一样，但第二种只需要一次乘法。算法世界里，经常会有“跑得一样对，但速度不同”的解法，这就是下一模块要讲的时间复杂度。

第 4 小节

综合实战：判断闰年

把输入、判断、输出串起来

来做一个小项目：输入一个年份，判断它是不是闰年。闰年规则是：能被 4 整除，但不能被 100 整除；或者能被 400 整除。

把这个规则翻译成代码，就是一组清晰的判断步骤：先读入年份，然后按规则判断，最后输出结果。

闰年判断器
def is_leap_year(year):
    if year % 400 == 0:
        return True
    if year % 100 == 0:
        return False
    if year % 4 == 0:
        return True
    return False

year = int(input("请输入年份："))
if is_leap_year(year):
    print(year, "是闰年")
else:
    print(year, "不是闰年")
leap_year.cpp
#include <iostream>
using namespace std;

bool is_leap_year(int year) {
    if (year % 400 == 0) return true;
    if (year % 100 == 0) return false;
    if (year % 4 == 0) return true;
    return false;
}

int main() {
    int year;
    cout << "请输入年份：";
    cin >> year;
    if (is_leap_year(year)) {
        cout << year << " 是闰年" << endl;
    } else {
        cout << year << " 不是闰年" << endl;
    }
    return 0;
}

这个程序虽然小，但已经具备了一个完整算法的三个要素：输入年份、按规则处理、输出结论。你可以试试 2000、1900、2024、2025 这几个年份，看看结果是否符合常识。
