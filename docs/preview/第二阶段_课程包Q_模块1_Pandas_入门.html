第 1 小节

Excel 的末日：为什么用 Pandas

用代码处理表格，比手动拖拽更高效

你有没有过这样的经历：Excel 里几千行数据，想筛选、排序、求和，光是拖拽公式就累得不行；一不小心改错一个单元格，整张表都乱套了。Pandas 就是 Python 世界里的「超级 Excel」，它把表格变成了一行行代码，能自动、快速、可重复地处理数据。

如果把 Excel 比作「手动榨汁机」，Pandas 就是「全自动果汁工厂」：你写好一次配方，之后无论来多少水果，它都能按同样的流程处理。更重要的是，它可以和前面学过的文件读写、循环判断无缝结合，让数据分析真正成为程序的一部分。

本模块不会涉及复杂的数学，只要求你记住一个核心概念：DataFrame。你可以把它理解成「Python 里的电子表格」——有行、有列，每列是同一种数据类型，可以用代码快速增删改查。

hello_pandas.py
import pandas as pd

# 用字典造一张最简单的表
data = {
    "姓名": ["阿明", "小红", "小刚"],
    "年龄": [18, 20, 19],
    "成绩": [85, 92, 78]
}

df = pd.DataFrame(data)
print(df)

上面的代码里，pd.DataFrame(data) 就像对 Python 说：「帮我把这个字典变成一张表」。运行后会看到整齐的行列，和 Excel 的观感几乎一样，但它完全由代码控制。

shape_info.py
# 看看这张表的基本信息
print("行数, 列数:", df.shape)      # (3, 3)
print("列名:", df.columns.tolist())
print("数据类型:")
print(df.dtypes)

先记住这两个工具：一个是 pd.DataFrame() 用来造表，另一个是 df.shape 用来快速查看表的规模。下一个小节，我们会学习怎么从这张表里「拿数据」。

第 2 小节

DataFrame：行、列与单元格

像查字典一样取数据

学会造表之后，下一步是学会「读表」。在 Pandas 里，取一列、取一行、取一个单元格都有专门的写法。你只要记住一句话：先选列，再选行。

比如你想看所有人的成绩，可以直接用 df["成绩"]；想看第 0 行的所有信息，用 df.iloc[0]；想看小红的年龄，用 df.loc[1, "年龄"]（因为小红在第 1 行）。

select_data.py
import pandas as pd

df = pd.DataFrame({
    "姓名": ["阿明", "小红", "小刚"],
    "年龄": [18, 20, 19],
    "成绩": [85, 92, 78]
})

# 取一列
print(df["成绩"])

# 取一行（按位置，第 0 行）
print(df.iloc[0])

# 取一个单元格（第 1 行，"年龄" 列）
print(df.loc[1, "年龄"])

这里有两个容易混淆的方法：loc 和 iloc。可以简单记忆：i 代表 index（位置编号），所以 iloc[0] 永远是第一行；而 loc 更灵活，可以用行标签和列名组合。

modify_data.py
# 新增一列：是否及格
df["是否及格"] = df["成绩"] >= 60

# 修改小刚的成绩
df.loc[2, "成绩"] = 80

print(df)

从取数据到改数据，核心思路始终没有变：先告诉 Pandas 你要哪一列，再告诉它你要哪一行。下一节，我们会把这些操作串起来，做一个能自动判断成绩的小工具。

第 3 小节

动手：成绩登记表

创建、读取、修改一气呵成

前面两节分别学了「造表」和「取数」。现在把它们连起来：做一张成绩登记表，自动计算每个人的总分，并给不及格的同学标红提示。

score_tool.py
import pandas as pd

df = pd.DataFrame({
    "姓名": ["阿明", "小红", "小刚", "小丽"],
    "语文": [85, 92, 58, 76],
    "数学": [90, 88, 62, 95],
    "英语": [78, 95, 70, 82]
})

# 新增一列：总分
df["总分"] = df["语文"] + df["数学"] + df["英语"]

# 新增一列：是否全科及格
df["全科及格"] = (df["语文"] >= 60) & (df["数学"] >= 60) & (df["英语"] >= 60)

print(df)

注意代码里判断多个条件时，用的是 & 而不是 and。因为 Pandas 的一列是很多个 True/False，& 能逐个元素对比，而 and 会报错。这是新手最常见的坑之一。

who_failed.py
# 找出所有没有全科及格的同学
failed = df[df["全科及格"] == False]
print("需要补考的同学：")
print(failed[["姓名", "语文", "数学", "英语"]])

到这里，你已经能用 Pandas 完成：创建表格、读取列、计算新列、按条件筛选。这些就是数据分析的最小可用技能包。下一节会把它们放进一个小项目里。

第 4 小节

综合实战：班级成绩分析器

用 DataFrame 生成一份完整统计

假设你是班长，班主任让你统计一次小测的成绩。要求很简单：列出全班名单、算出总分和平均分、找出最高分，并标出哪些同学需要补考。用 Pandas 几分钟就能搞定。

class_report.py
import pandas as pd

# 1. 创建成绩表
df = pd.DataFrame({
    "姓名": ["阿明", "小红", "小刚", "小丽", "小军"],
    "语文": [85, 92, 58, 76, 88],
    "数学": [90, 88, 62, 95, 70],
    "英语": [78, 95, 70, 82, 65]
})

# 2. 计算总分和平均分
df["总分"] = df["语文"] + df["数学"] + df["英语"]
df["平均分"] = df["总分"] / 3

# 3. 标记是否全科及格
df["全科及格"] = (df["语文"] >= 60) & (df["数学"] >= 60) & (df["英语"] >= 60)

# 4. 输出统计信息
print("=== 全班成绩 ===")
print(df)

print("\n=== 最高总分 ===")
print(df["总分"].max())

print("\n=== 需要补考的同学 ===")
print(df[df["全科及格"] == False][["姓名", "语文", "数学", "英语"]])

这个项目的关键在于：先用 DataFrame 把数据结构化，再用列运算批量计算。一旦数据变多，你只需改前面的字典，后面的统计会自动生效。这就是代码优于手动表格的地方。

进阶挑战：试着把「姓名」列设成表格的索引，用 df.set_index("姓名")，然后用 df.loc["小红", "总分"] 直接查某个人的总分。
