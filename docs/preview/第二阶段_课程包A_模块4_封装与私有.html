第 1 小节

为什么要封装

当类的属性可以被外部随意修改时，很容易写出隐患重重的代码。比如一个钱包类，如果允许直接把余额改成任意数字，那就失去了「存钱、取钱」的意义。

bad_wallet.py
class Wallet:
    def __init__(self):
        self.balance = 0

w = Wallet()
w.balance = -100000   # 余额居然能变成负数？
print(w.balance)
bad_wallet.cpp
#include <iostream>
using namespace std;

class Wallet {
public:
    int balance = 0;
};

int main() {
    Wallet w;
    w.balance = -100000;   // 余额居然能变成负数？
    cout << w.balance << endl;
    return 0;
}

这种情况在真实项目中非常危险。封装的意思是：把内部状态保护起来，只允许通过指定的方法访问或修改。就像自动售货机，你不会直接伸手进去拿饮料，而是按按钮、投币，由机器内部完成操作。

第 2 小节

私有属性

Python 用双下划线开头表示私有属性。C++ 用 private: 关键字声明私有成员。被标记为私有后，外部代码就不应该直接访问它们。

private.py
class Wallet:
    def __init__(self):
        self.__balance = 0    # 私有属性

    def save(self, amount):
        if amount > 0:
            self.__balance += amount

    def get_balance(self):
        return self.__balance

w = Wallet()
w.save(100)
print(w.get_balance())   # 100
private.cpp
#include <iostream>
using namespace std;

class Wallet {
private:
    int balance = 0;       // 私有成员

public:
    void save(int amount) {
        if (amount > 0) balance += amount;
    }

    int getBalance() {
        return balance;
    }
};

int main() {
    Wallet w;
    w.save(100);
    cout << w.getBalance() << endl;   // 100
    return 0;
}

注意：Python 的私有属性只是「约定+改名」，有经验的程序员仍然可以强行访问，但对于C++私有成员，外部直接访问会报错。

第 3 小节

getter 与 setter：受控访问

有时候我们希望外部能读取某个属性，但不能随便修改；或者修改时必须经过检查。这种通过方法间接访问属性的设计，就叫做 getter 和 setter。

getter_setter.py
class Student:
    def __init__(self, name):
        self.__name = name

    def get_name(self):          # getter
        return self.__name

    def set_name(self, new_name): # setter
        if len(new_name) > 0:
            self.__name = new_name

s = Student("小明")
print(s.get_name())
s.set_name("")
print(s.get_name())   # 仍然是 小明，因为空字符串被拒绝了
getter_setter.cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
private:
    string name;
public:
    Student(string n) { name = n; }

    string getName() {          // getter
        return name;
    }

    void setName(string newName) { // setter
        if (newName.length() > 0) name = newName;
    }
};

int main() {
    Student s("小明");
    cout << s.getName() << endl;
    s.setName("");
    cout << s.getName() << endl;   // 仍然是 小明，因为空字符串被拒绝了
    return 0;
}

在这个例子里，__name 被封装起来。外部代码无法直接改成空字符串，必须经过 set_name 的检查。name 被放在 private: 里。外部代码无法直接改成空字符串，必须经过 setName 的检查。这样即使以后规则变得更复杂（比如名字不能超过 10 个字），也只需要改 setter 一个地方。

第 4 小节

综合实战：安全的银行账户

把本模块内容用起来

请你完成下面的 BankAccount 类：余额为私有属性，提供 deposit（存款，拒绝负数）、withdraw（取款，余额不足时拒绝）、get_balancegetBalance（查询余额）三个方法。

bank_account.py
class BankAccount:
    def __init__(self):
        self.__balance = 0

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            print("存入", amount)
        else:
            print("存款金额必须大于 0")

    def withdraw(self, amount):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print("取出", amount)
        else:
            print("余额不足或金额无效")

    def get_balance(self):
        return self.__balance

acc = BankAccount()
acc.deposit(1000)
acc.withdraw(300)
print("当前余额：", acc.get_balance())
bank_account.cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    int balance = 0;
public:
    void deposit(int amount) {
        if (amount > 0) {
            balance += amount;
            cout << "存入 " << amount << endl;
        } else {
            cout << "存款金额必须大于 0" << endl;
        }
    }

    void withdraw(int amount) {
        if (0 < amount && amount <= balance) {
            balance -= amount;
            cout << "取出 " << amount << endl;
        } else {
            cout << "余额不足或金额无效" << endl;
        }
    }

    int getBalance() {
        return balance;
    }
};

int main() {
    BankAccount acc;
    acc.deposit(1000);
    acc.withdraw(300);
    cout << "当前余额：" << acc.getBalance() << endl;
    return 0;
}
