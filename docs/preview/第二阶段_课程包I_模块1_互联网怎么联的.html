第 1 小节

互联网是一张巨大的快递网络

很多人觉得互联网很抽象：打开浏览器，输入网址，页面就神奇的出现了。其实它本质上和现实中的快递系统没什么区别——你的请求被打包成一个个小包裹，经过无数台路由器和交换机，最终被送到目的地服务器，服务器再把回应包裹送回来。

快递需要「发件人地址」「收件人地址」「包裹内容」，网络数据也需要类似的字段。只不过网络上的地址是 IP 地址，包裹内容被拆分成 数据包（Packet），而负责搬运包裹的设备叫 路由器（Router）。

💡 核心类比

互联网 = 全球快递网络；数据包 = 快递包裹；路由器 = 分拣中心；网线/光纤 = 高速公路。

下面这段 Python 代码用最简单的方式展示了「两台电脑通过 IP 和端口建立连接」的概念。它不会真的访问外网，只能在本地跑，但能帮你直观理解「地址 + 端口 = 收发窗口」：

local_echo.py
import socket

# 在本机（127.0.0.1 叫“回环地址”，代表自己）开一个“收件窗口”
server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(("127.0.0.1", 9000))  # 地址 + 端口号
server.listen(1)
print("小服务器已开张，等待包裹...")

conn, addr = server.accept()      # 等待有人连上来
msg = conn.recv(1024).decode()    # 接收一个包裹
print("收到：", msg)
conn.sendall("收到啦！".encode())   # 回一个包裹
conn.close()
server.close()

上面代码里的 127.0.0.1 是一个特殊 IP，意思是「我自己」。端口 9000 则像快递柜台编号：同一台电脑可以同时开很多个服务，靠端口号区分。

第 2 小节

数据包怎么找到路？

现实中的快递会经过多个中转站，网络数据包也一样。它不会「直线飞行」，而是被沿途的路由器一次次转发。每一跳（hop）都会把数据包推得更接近目标。

路由器怎么知道往哪走？每台路由器都维护着一张路由表（Routing Table），就像快递分拣中心的全国地图。路由表里写着：「目标 IP 属于哪个网段，应该从哪个出口发出去」。如果路由器不知道具体位置，它会把包裹交给「上一级」更大的路由器，直到找到认识路的那一台。

局域网 LAN
你家、公司、学校的内部网络。设备靠交换机相连，IP 通常是 192.168.x.x。
广域网 WAN
跨城市、跨国的骨干网络。由运营商的大路由器和光纤组成。

你可以用 Python 调用系统命令 traceroute（Windows 上是 tracert）来看数据包到你家门外后走了哪些地方。注意： 校园网或某些网络可能会屏蔽这个命令。

trace_route.py
import subprocess
import platform

target = "www.example.com"
cmd = ["tracert", target] if platform.system() == "Windows" else ["traceroute", target]

# 运行系统命令，看数据包经过多少跳路由器
result = subprocess.run(cmd, capture_output=True, text=True, encoding="utf-8", errors="ignore")
print(result.stdout)
⚠️ 注意

这段代码在本地运行需要系统支持 tracert/traceroute。部分网络环境会禁止或显示星号（*），这不代表代码错了，而是路由器选择不回应探测包。

第 3 小节

动手：看看本机网络配置

每台联网的设备都有自己的「名片」：IP 地址、子网掩码、默认网关、DNS 服务器。这些信息决定了数据包能不能顺利出家门、能不能找到域名对应的 IP。

在 Python 里，我们可以用标准库 socket 和 subprocess 快速查看本机主机名和 IP。更详细的网络信息可以调用系统命令 ipconfig（Windows）或 ifconfig/ip（Linux/macOS）。

my_network.py
import socket
import subprocess
import platform

# 获取本机主机名和局域网 IP
hostname = socket.gethostname()
local_ip = socket.gethostbyname(hostname)
print("主机名：", hostname)
print("局域网 IP：", local_ip)

# 查看更详细的网络配置（Windows 用 ipconfig，其他系统用 ip/ifconfig）
sys = platform.system()
cmd = "ipconfig" if sys == "Windows" else "ip a"
print("\n系统网络配置：")
print(subprocess.getoutput(cmd))

运行后你会看到类似 192.168.31.105 的地址，这就是你家路由器给你这台电脑分配的「门牌号」。如果手机和电脑连的是同一个 Wi-Fi，它们的前三段（比如 192.168.31）通常相同，说明它们在同一个局域网。

第 4 小节

综合实战：模拟一次“发快递”

用 Python 把信息分成小包并记录每站

真正的大规模网络会把长数据切成小块传输，每一块都写上序号、目标地址和校验信息。接收方收到后再按序号拼回来。下面我们用 Python 模拟一个极简版「分片-编号-重组」过程。

packet_journey.py
import random

message = "野鸡动画编程课：数据包的环球旅行"
chunk_size = 6  # 每 6 个字符一个小包裹
packets = []

# 1. 发送端：分片、编号
for i in range(0, len(message), chunk_size):
    payload = message[i:i + chunk_size]
    packets.append({"seq": i // chunk_size, "data": payload})

print("=== 发送端分片 ===")
for p in packets:
    print(f"包 {p['seq']}: {p['data']}")

# 2. 网络传输：随机打乱顺序，模拟不同路径
random.shuffle(packets)
print("\n=== 网络中顺序被打乱 ===")
for p in packets:
    print(f"到达 包 {p['seq']}")

# 3. 接收端：按序号重组
packets.sort(key=lambda x: x["seq"])
reassembled = "".join(p["data"] for p in packets)
print("\n=== 接收端重组 ===")
print("还原后的消息：", reassembled)

这个练习想让你体会三件事：

1. 分片：大数据被切成小块，方便在网络中传输。

2. 编号：每个小包带序号，接收方才知道怎么拼。

3. 乱序到达：真实网络中不同小包走不同路径，到达顺序可能不一样。

🔑 模块 1 小结

互联网 = 快递网络；数据包 = 包裹；IP 地址 = 门牌号；端口 = 窗口；路由器 = 分拣中心。真正的网络还会做分片、编号、重组、错误恢复。
