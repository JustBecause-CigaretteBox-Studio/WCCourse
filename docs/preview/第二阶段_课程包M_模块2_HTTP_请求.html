第 1 小节

GET 与 POST 的区别

HTTP 协议定义了多种「动作」，最常见的两种是 GET 和 POST。 你可以把它们理解成餐厅里的两种点单方式：

  • GET：在菜单上直接指「我要这个」，参数写在 URL 里，像贴在订单上的便签。适合获取数据，比如查天气。
  • POST：扫码下单，下单信息给服务员看，参数放在请求体里，不暴露在地址栏。适合提交数据，比如登录、下单。

打个比方：在搜索引擎输入关键词并回车，浏览器发送的是 GET 请求；填写账号密码点击登录，浏览器发送的是 POST 请求。

get_vs_post.py
import requests

# GET：参数拼在 URL 里
weather_url = "https://api.example.com/weather?city=北京"
result_get = requests.get(weather_url)

# POST：参数放在 data / json 里
login_url = "https://api.example.com/login"
payload = {"username": "xiaoming", "password": "123456"}
result_post = requests.post(login_url, json=payload)

print("GET 状态码:", result_get.status_code)
print("POST 状态码:", result_post.status_code)

注意：这只是示例 URL，真实接口需要换成你能访问的地址。重点是记住两种请求在代码写法上的差别。

第 2 小节

用 GET 请求带参数

用 GET 请求时，除了直接把参数写在 URL 里，也可以交给 params 参数。 这样 requests 会自动帮你拼成完整的 URL，避免手写出错。

get_params.py
import requests

url = "https://httpbin.org/get"
params = {
    "city": "北京",
    "units": "metric"
}

response = requests.get(url, params=params)
print("最终 URL：", response.url)
print("状态码：", response.status_code)
print(response.json()["args"])

httpbin.org 是一个专门用来练习 HTTP 请求的网站， 它会把你发送的内容原样返回，非常适合学习测试。

response.json()["args"] 就是服务器收到的参数列表， 你应该能看到 city 和 units。

第 3 小节

用 POST 请求提交 JSON

POST 常用于「提交信息」。如果服务器要求提交 JSON 格式，就用 json=字典。 如果要求普通表单格式，则用 data=字典。

post_json.py
import requests

url = "https://httpbin.org/post"
payload = {
    "username": "xiaoming",
    "message": "你好，服务器！"
}

# 提交 JSON，requests 会自动设置请求头
response = requests.post(url, json=payload)
print("状态码:", response.status_code)

# httpbin 会把我们提交的数据放在 "json" 字段里返回
data = response.json()
print("服务器收到的 JSON：", data["json"])

状态码 200 或 201 一般表示成功； 400 表示请求参数有问题； 404 表示找不到接口； 500 表示服务器内部出错。

第 4 小节

综合实战：简易登录模拟器

GET 查状态 + POST 提交账号

这个实战把 GET 和 POST 串起来：先用 GET 检查服务是否在线，再用 POST 模拟提交账号。 这里用的是练习网站 httpbin.org， 所以你不需要担心泄露真实密码。

login_simulator.py
import requests

base = "https://httpbin.org"

# 第一步：GET 检查服务状态
health = requests.get(base + "/get")
if health.status_code == 200:
    print("服务在线，准备提交账号...")
else:
    print("服务不可用")
    exit()

# 第二步：POST 提交登录信息
url = base + "/post"
info = {"username": "learner", "password": "hello-api"}
response = requests.post(url, json=info)

if response.status_code == 200:
    result = response.json()
    print("服务器收到：", result["json"])
    print("登录成功（模拟）")
else:
    print("提交失败，状态码：", response.status_code)

这个小程序展示了真实开发里的常见套路：

  • 先用 GET 或 ping 确认服务活着。
  • 再用 POST 把数据送过去。
  • 最后根据状态码判断结果，给用户反馈。
