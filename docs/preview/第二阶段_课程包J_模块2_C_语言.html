第 1 小节

C 语言：现代系统的基石

C 语言诞生于 1972 年，由贝尔实验室的丹尼斯·里奇设计。它最初是为了重写 UNIX 操作系统而生，后来却成了影响最深远的编程语言之一。

Windows、Linux、macOS、Android、iOS 等主流系统的内核，以及 Python 解释器、Node.js 引擎、数据库 MySQL 等关键软件，底层几乎都有 C 语言的身影。可以说：C 语言是计算机世界里的英语。

C 语言的设计哲学很简单：给程序员足够的控制力，同时保持相对紧凑的语法。它不像 Python 那样内置丰富的高级工具，也不像汇编那样直接绑定某款 CPU。它处在“人和机器之间”的黄金位置。

C
#include <stdio.h>

int main() {
    printf("Hello from C\n");
    return 0;
}

这段代码虽小，却已经包含 C 的核心元素：#include 引入工具库、int main() 程序入口、printf 输出、return 0 告诉系统“正常结束”。

第 2 小节

指针：C 语言最锋利的工具

如果说变量是一个装着数据的盒子，那么指针就是盒子的地址。在 C 语言里，每个变量都住在内存的某个房间里，指针告诉你房间号。

用生活中的比喻：变量是快递柜里的包裹，指针是取件码。知道取件码，你就能找到包裹，也能把包裹换成别的。

C
#include <stdio.h>

int main() {
    int a = 10;
    int *p = &a;   // p 存储的是 a 的地址

    printf("a = %d\n", a);     // 10
    printf("p 指向的值 = %d\n", *p);  // 10

    *p = 20;       // 通过指针修改 a 的值
    printf("a = %d\n", a);     // 20
    return 0;
}

上面的 &a 表示“取 a 的地址”，*p 表示“访问 p 指向地址里的值”。指针让 C 能直接操作内存，效率极高，但也要求程序员对内存负责。

为什么需要指针？ 因为它们让函数可以“远程”修改外部变量，也让数组、字符串、链表等结构成为可能。没有指针，C 语言会立刻失去大半威力。

第 3 小节

动手试一试：指针修改数组

数组在 C 里其实是连续排列的变量。数组名本身就是一个指向首元素的指针。通过指针移动，我们可以依次访问每个元素。

C
#include <stdio.h>

int main() {
    int nums[] = {10, 20, 30, 40, 50};
    int *p = nums;  // p 指向 nums[0]

    // 用指针遍历数组
    for (int i = 0; i < 5; i++) {
        printf("nums[%d] = %d\n", i, *(p + i));
    }

    // 通过指针把每个数加 1
    for (int i = 0; i < 5; i++) {
        *(p + i) += 1;
    }

    printf("修改后：nums[0] = %d\n", nums[0]);  // 11
    return 0;
}

注意 *(p + i) 和 p[i] 在 C 里几乎是等价的。这体现了 C 语言一个核心思想：指针和数组共享同一片内存语义。

初学者常犯的错误是以为“指针很神秘”。其实它只是一个整数，存储的是内存地址。真正需要小心的，是访问“已经不属于你的房间”——也就是野指针。

第 4 小节

综合实战：交换两个数

传值与传指针的区别

C 函数默认是传值调用：把实参复制一份给形参。如果想在函数内部真正修改外部变量，必须传递指针。这是 C 语言最经典的小实验之一。

C
#include <stdio.h>

// 错误示范：传值交换，外部不变
void swap_bad(int a, int b) {
    int tmp = a;
    a = b;
    b = tmp;
}

// 正确做法：传指针，直接改内存
void swap(int *a, int *b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

int main() {
    int x = 5, y = 10;
    swap(&x, &y);
    printf("x = %d, y = %d\n", x, y);  // x = 10, y = 5
    return 0;
}

对比 Python，交换变量则简单得多，因为它内部已经用引用机制处理好了：

Python
def swap(a, b):
    return b, a

x, y = 5, 10
x, y = swap(x, y)
print(x, y)  # 10 5

C 语言需要手动管理指针，这既是它的力量来源，也是新手最容易踩坑的地方。理解指针，你就理解了 C 的灵魂。
