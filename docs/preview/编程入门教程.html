💡 为什么 C++ 一定要先说种类？

因为不同的东西，占的格子大小不一样，读取的规矩也不一样。

电脑必须提前知道：这个格子留多大？按整数的规矩读，还是按小数的规矩读？ 所以 C++ 要求你在贴标签时就说清楚种类。

💡 「18」和 18 是两回事

格子里的 18 是数，可以加减乘除；格子里的 "18" 是 两个字拼起来的文字，就像 "你好" 一样，不能当数算。

想把文字变成数，用 int("18")，得到的就是真正的 18 了。

种类不同，算账的规矩也不同

这一点在除法上最容易看出来：int 格子和 int 格子相除，小数部分会被直接丢掉； 只有让 double 参与，才能得到小数结果：

cout << a / b << "\n";   // int 除以 int：小数部分被丢掉

double c = 7.0;
cout << c / b << "\n";   // 有 double 参与：得到小数

int x = 3.9;
cout << x;                // 小数硬塞进 int 格子：砍掉尾巴

第 3 小节

输入与输出

cin 听，cout 说

到目前为止，a 和 b 都是我们在代码里提前写好的。 但第 1 小节那个任务说了：a、b 的值在某一时刻才给出。 所以电脑需要学会两件事：听 和 说。

cout <<

电脑在说：把东西说给屏幕（也就是你）听。 箭头 << 指向 cout，东西流向屏幕。

cin >>

电脑在听：把你敲进去的数放进格子。 箭头 >> 指向变量，东西流进格子。

💡 记忆法

箭头指哪儿，东西就去哪儿。cout << a：a 流向屏幕； cin >> a：你输入的东西流向 a。

print()

电脑在说：把括号里的东西说给屏幕（也就是你）听。

input()

电脑在听：停下来等你敲键盘，把你输入的东西拿回来。 外面套一层 int()，把听到的话变成整数。

💡 记忆法

print(a + b) 念作「说出 a + b」；a = int(input()) 念作 「听一个整数，放进 a」。听来的东西先放进格子，后面才能用。

第 4 小节

判断：电脑的选择题

if 如果，else 否则

人类在生活中经常要做选择题。「如果下雨，就带伞；否则，戴帽子。」 电脑也会做选择题，而且它做选择题的句子几乎一模一样：

如果下雨，就带伞；否则，戴帽子。

if (下雨) { 带伞 }
else { 戴帽子 }

if 下雨:
    带伞
else:
    戴帽子

if 就是「如果」，else 就是「否则」。

程序不再只是从头跑到尾，而是会根据情况选路走。

每走到一个 if，就检查条件。

条件是真的，就走第一条路，把大括号里的事做完。

条件是假的，就走 else 那条路。

每走到一个 if，就检查条件。

条件是真的，就走第一条路，把缩进里面的事做完。

条件是假的，就走 else 那条路。

条件的真面目：bool 值

第 2 小节我们认识了 int、double、string 三种格子。其实还有一种非常特别的格子， 它只能装两样东西：真 和 假。这种格子叫 bool（布尔值）——它是专门为「判断」而生的类型。

bool布尔值
装什么
只有两种可能：true（真）和 false（假），没有第三种。
举个例子
bool isRaining = true;
一个叫 isRaining 的 bool 格子，放着「真」——意思是：正在下雨
小提醒
用 cout 输出 bool 时，true 会显示成 1，false 会显示成 0。
bool布尔值
装什么
只有两种可能：True（真）和 False（假）。注意首字母必须大写！
举个例子
is_raining = True
一个叫 is_raining 的 bool 格子，放着「真」——意思是：正在下雨
小提醒
用 print 输出 bool 时，会直接显示 True 或 False。

有了 bool，if 的秘密就可以揭开了：if 判断的就是一个 bool 值。 你在 if 后面写的 a > b 看起来像一个问题，但在电脑眼里它是一个 表达式——会先被算出一个结果，而这个结果恰好就是一个 bool 值。

if (a > b) 是我问电脑的问题：a 比 b 大吗？

电脑回答「是」就走第一条路，回答「不是」就走另一条路。

a 是 7，b 是 3， 7 > 3——成立，于是整个表达式 a > b 变成了 true。

所以 if 看到的根本不是「a > b」，而是 if (true)。它只看这个 bool 值是真是假，然后选路走。

int a = 7, b = 3;

bool result = a > b;   // 比较的结果是一个 bool 值，存进格子
cout << result << "\n";  // true 输出为 1

if (a > b) {            // 等效于 if (result)，也等效于 if (true)
    cout << "a 更大";
}

a 更大
💡 不信？直接把 bool 值塞给 if

既然 if 只认 bool 值，那写一个 if (true)（Python 写 if True:）， 它永远走if；写 if (false) / if False:，就永远走 else。

这没什么实际用处，但它证明了一件事：if 不关心你写了多复杂的表达式，它只关心最后算出来的那个 bool 值。

细节深挖：C++ 的大括号 {} 与 Python 的缩进

无论是 C++ 还是 Python，if / else 都像路口的分岔牌。分岔之后，每条路上可能不止一件事要做。 我们必须让电脑知道：「这几行代码是一伙的，要走一起走，要跳过一起跳过。」

C++ 和 Python 用了完全不同的方式画这条边界，但意思完全一样。

C++ · 大括号像包装盒
if (a > b) {
    cout << a;
    cout << " 更大";
}
  • { 表示「从这里开始，后面是一伙的」
  • } 表示「这一伙到这里结束」
  • 大括号里的所有代码，要么一起执行，要么一起跳过
Python · 缩进像排队
if a > b:
    print(a)
    print(" 更大")
  • : 表示「接下来开始排队」
  • 下面缩进的行（通常 4 个空格）都是同一伙
  • 一旦某行不再缩进，就表示这伙人结束了
💡 一个记忆法

C++ 用花括号画边界，Python 用对齐画边界。 边界里面的代码是一伙的；边界外面的代码，不归 if 管。

当「一伙代码」超过一行时

如果 if 里只有一件事，写法可以很紧凑；但现实中常常要连续做很多事，这时边界就格外重要。

C++
if (score >= 60) {
    cout << "及格";
    cout << "，恭喜！";
    pass = pass + 1;
}
cout << "检查结束";

前 3 行在 {} 里，只有分数及格才会执行；最后一行在 {} 外，不管怎样都会执行。

Python
if score >= 60:
    print("及格")
    print("，恭喜！")
    pass_count = pass_count + 1
print("检查结束")

前 3 行缩进了，只有分数及格才会执行；最后一行没缩进，不管怎样都会执行。

新手最容易踩的坑

C++ 常见错误
  • 只写了 {，忘了写 }
  • 复制代码时丢掉了一半括号
  • if 后面没写 {}，结果只有第一行受 if 控制
Python 常见错误
  • 同一伙代码缩进不一致，有的 2 空格、有的 4 空格
  • 混用 Tab 键和空格键
  • 复制代码时行首空格丢了一半

实战：谁大就输出谁

#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    if (a > b) {
        cout << a;   // 条件成立：a 更大
    } else {
        cout << b;   // 条件不成立：b 更大（或一样大）
    }
    return 0;
}
a = int(input())
b = int(input())

if a > b:
    print(a)   # 条件成立：a 更大
else:
    print(b)   # 条件不成立：b 更大（或一样大）

条件怎么写？

写法意思
a > ba 比 b 大吗？
a < ba 比 b 小吗？
a == ba 和 b 相等吗？（注意是两个等号！）
a != ba 和 b 不相等吗？
⚠️ 本节最大的坑：= 和 ==

a = b 是「把 b 放进 a」（赋值）； a == b 才是「a 和 b 相等吗」（比较，等效为一个bool值）。

在 if 里写成 if (a = b) 是无数新手踩过的第一个大坑。

在 if 里写成 if a = b: 是无数新手踩过的第一个大坑。

1. if（如果）…… else（否则）……，电脑每次只走一条路。

2. if 判断的是一个 bool 值（真 / 假）：>、<、==、!= 这些比较表达式会先被算成一个 bool 值，再决定走哪条路。

暴力出奇迹

让电脑重复做事的句子叫循环，最常用的是 for 循环：

#include <iostream>
using namespace std;

int main() {
    int sum = 0;                      // 准备一个装总和的格子
    for (int i = 1; i <= 100; i++) {  // i 从 1 数到 100
        sum = sum + i;                // 每次把 i 加进总和
    }
    cout << sum;                      // 说出答案
    return 0;
}
sum = 0                  # 准备一个装总和的格子
for i in range(1, 101):  # i 从 1 数到 100
    sum = sum + i        # 每次把 i 加进总和
print(sum)               # 说出答案
▶ 运行结果
5050

把 for 拆开看

for 的括号里有三句话，用分号隔开，像一份「重复说明书」：

for (int i = 1 ; i <= 100 ; i++)
从哪开始：i 一开始是 1
到什么时候停：i 不超过 100 就继续
每轮结束做什么：i 增加 1（i++ 就是 i = i + 1）

Python 的 for 循环像一句口令：「让 i 挨个取这些数，每取一个做一遍缩进里的事」：

for i in range(1, 101):
i：轮流当值的格子，每一轮换一个数
range(1, 101)：从 1 数到 100（到 101 为止，但不包括 101）

我只需要说清楚重复什么、重复多少次。

i <= n表示重复n次。

range(1, n + 1)表示重复n次。

第一轮：i 是 1，把 1 加进 sum。

第二轮：i 是 2，把 2 加进 sum。

……

第一百轮：i 是 100，把 100 加进 sum。

第一百零一轮：i 是 101，超过 100 了，停！走出循环，说出 sum。

第一百零一轮：数完了，没数可取了，停！走出循环，说出 sum。

还有一种循环：while

for 循环适合「知道要重复多少次」的事，比如从 1 加到 100。 但有些事我们不知道要重复多少次，只知道什么时候该停：

📋 任务

你有 1 块钱，每天翻一倍（1 → 2 → 4 → 8 ……），多少天后能超过 1000 块？

几天？算之前谁也不知道。这时候用 while 循环—— 它只说一句话：「只要条件还成立，就再来一轮」。 

#include <iostream>
using namespace std;

int main() {
    int money = 1, day = 0;
    while (money <= 1000) {  // 钱还没超过 1000，就继续
        money = money * 2;    // 翻一倍
        day = day + 1;        // 过一天
    }
    cout << day;             // 走出循环，说出天数
    return 0;
}
money = 1
day = 0
while money <= 1000:  # 钱还没超过 1000，就继续
    money = money * 2  # 翻一倍
    day = day + 1      # 过一天
print(day)             # 走出循环，说出天数
▶ 运行结果
10

把 while 拆开看——它比 for 简单得多，括号里只有一个条件：

while (money <= 1000)
每轮开始前：检查一次条件
条件成立：做一遍循环里的事，然后回来再检查
条件不成立：停！走出循环

我只用说「钱没超过 1000 就继续翻倍」，重复几次根本不用我操心。

第 1 天：1 → 2。第 2 天：2 → 4。第 3 天：4 → 8。……

第 9 天：256 → 512，还没超过 1000，继续。

第 10 天：512 → 1024，超过 1000 了，停！说出 10。

⚠️ 小心死循环

while 只认条件。如果条件永远成立，电脑就永远停不下来——这叫死循环。 比如上面那段代码里如果忘了写 money = money * 2， 钱永远是 1 块，电脑会一直在原地转圈，程序卡死。 所以写 while 时多问自己一句：循环里有没有让条件「趋向不成立」的那句话？

正因如此，通常认为for循环更安全，但while循环在某些情况下更适用，例如很多游戏的代码就是写在一个巨大的while循环（游戏主循环）里的。

循环的开关：布尔值

我们知道条件判断，本质上是判断一个bool值是真是假，其实循环也是这样。 

while (1) {
    cout << "你好";
}
while 1:
    print("你好")
▶ 运行结果
你好你好你好你好你好……（永远停不下来）

这段代码会永远输出「你好」，因为它是一个死循环。 括号里的 1 表示「真」，电脑一看到「真」，就会继续循环； 如果换成 0，就表示「假」，循环一次也不会执行。

💡 布尔值

这种只有「真 / 假」两种取值的类型，叫做布尔值（bool）。 在 C++ 里，true 和 false 是它的两个值； 在 Python 里，是 True 和 False。 不过为了方便，C++ 也允许用 1 代替 true，用 0 代替 false。但是也有用0代表true，1代表false的规则。

所以 while (1) 和 while (true) 是一个意思，while 1 和 while True 是一个意思： 条件永远为真，循环就永远跑下去。

1. 循环让电脑重复做事。

2. for（起点 ; 继续的条件 ; 每轮的变化），适合知道重复多少次。

3. i++ 的意思是 i = i + 1，让 i 往前走一步。

4. while（条件）只要条件成立就再来一轮，适合只知道什么时候停；注意别让条件永远成立，否则死循环。

🔑 第 5 小节小结

1. 循环让电脑重复做事。

2. for i in range(起点, 终点+1)，i 会挨个取这些数，适合知道重复多少次。

3. 缩进里的代码就是每一轮要做的事。

4. while 条件: 只要条件成立就再来一轮，适合只知道什么时候停；注意别让条件永远成立，否则死循环。
