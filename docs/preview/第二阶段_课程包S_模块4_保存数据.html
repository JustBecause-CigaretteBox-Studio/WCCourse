第 1 小节

为什么要保存数据

抓到的内容要落盘才有意义

爬虫如果只是把结果打印在屏幕上，关掉终端就全没了。真正的价值在于把数据持久化——存进文件、表格或数据库，方便后续分析、统计或可视化。

新手阶段最常用的三种格式：

  • CSV：纯文本表格，用逗号分隔，Excel 和 Python 都能直接打开。
  • Excel（.xlsx）：适合需要格式化、多工作表的场景。
  • SQLite 数据库：轻量级本地数据库，适合数据量大或需要查询的场景。
💡 选择建议

如果只是做练习，CSV 最简单；如果需要给非技术人员查看，Excel 更友好；如果要长期积累或做条件查询，用 SQLite。

第 2 小节

保存到 CSV

标准库 csv 模块一行一行写

Python 标准库里的 csv 模块，不需要额外安装，就能读写 CSV 文件。

save_csv.py
import csv

# 假设已经从网页中提取到这些数据
rows = [
    ["标题", "链接", "日期"],
    ["Python 入门", "https://example.com/python", "2026-08-01"],
    ["爬虫基础", "https://example.com/crawl", "2026-08-05"],
]

with open("articles.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(rows)

print("已保存到 articles.csv")

关键点：

  • newline=""：避免 Windows 下出现多余的空行。
  • encoding="utf-8"：确保中文正常保存。
  • writer.writerows(rows)：一次性写入多行。
⚠️ 中文乱码

如果 Excel 打开 CSV 显示乱码，通常是因为编码不是 UTF-8。保存时显式指定 encoding="utf-8-sig" 可以让 Excel 正确识别。

第 3 小节

保存到 Excel 与 SQLite

更正式的两种持久化方案

如果目标读者习惯看 Excel，可以用 openpyxl：

save_excel.py
# pip install openpyxl
from openpyxl import Workbook

wb = Workbook()
ws = wb.active
ws.title = "文章"

rows = [
    ["标题", "链接", "日期"],
    ["Python 入门", "https://example.com/python", "2026-08-01"],
]

for row in rows:
    ws.append(row)

wb.save("articles.xlsx")
print("已保存到 articles.xlsx")

如果数据需要查询、去重、长期积累，SQLite 是更好的选择：

save_sqlite.py
import sqlite3

conn = sqlite3.connect("articles.db")
c = conn.cursor()

# 创建表
c.execute("""
    CREATE TABLE IF NOT EXISTS articles (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT,
        url TEXT,
        date TEXT
    )
""")

# 插入数据
c.execute(
    "INSERT INTO articles (title, url, date) VALUES (?, ?, ?)",
    ("Python 入门", "https://example.com/python", "2026-08-01")
)

conn.commit()
conn.close()
print("已保存到 articles.db")
🔑 本小节小结

CSV 适合简单练习，Excel 适合展示，SQLite 适合管理和查询。根据场景选择即可。

第 4 小节

综合实战

抓取文章标题并保存为 CSV

把前面模块的内容串起来：用 requests 请求、BeautifulSoup 解析、csv 保存。下面是一个完整的示例框架：

full_pipeline.py
import csv
import requests
from bs4 import BeautifulSoup

# 1. 请求（请换成允许抓取的公开网址，或在本地用 html_doc 练习）
url = "https://example.com"
resp = requests.get(url)

# 2. 解析
soup = BeautifulSoup(resp.text, "html.parser")
articles = []
for a in soup.find_all("a"):
    title = a.get_text(strip=True)
    link = a.get("href")
    if title and link:
        articles.append([title, link])

# 3. 保存
with open("articles.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["标题", "链接"])
    writer.writerows(articles)

print(f"已保存 {len(articles)} 篇文章")

练习任务：把 url 换成一个允许抓取的博客或新闻列表页，用浏览器开发者工具找到文章标题和链接所在的标签，修改解析逻辑，把结果保存到 CSV。完成后用 Excel 或文本编辑器打开 CSV 检查。

✅ Excel 适合给人看，SQLite 适合管理和查询。

✅ 保存时注意编码和换行符问题。
