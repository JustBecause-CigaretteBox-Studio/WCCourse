第 1 小节

robots.txt 是底线

先敲门，再问能不能进

robots.txt 是网站放在根目录的「访客须知」，用来告诉爬虫哪些路径允许访问、哪些不允许。它虽然不具有强制技术封锁能力，但在法律和行业内普遍被视为必须遵守的约定。

一个 robots.txt 可能长这样：

robots.txt 示例
User-agent: *
Disallow: /api/
Disallow: /login/
Allow: /public/
Crawl-delay: 1

User-agent: BadBot
Disallow: /

含义：

  • User-agent: *：对所有爬虫生效。
  • Disallow: /api/：不要爬 /api/ 路径下的内容。
  • Crawl-delay: 1：每次请求间隔至少 1 秒。
  • 针对 BadBot 的 Disallow: /：名为 BadBot 的爬虫被全站禁止。
check_robots.py
import requests

url = "https://example.com/robots.txt"
try:
    resp = requests.get(url, timeout=10)
    print(resp.text[:1000])
except Exception as e:
    print("无法读取 robots.txt:", e)
⚠️ 重要提醒

违反 robots.txt 去抓取被禁止的内容，可能被认定为不正当竞争或侵犯数据权益。写爬虫前，先读 robots.txt 是职业习惯，也是法律风险的防火墙。

第 2 小节

反爬机制与尊重

识别信号，不硬闯

网站为了保护服务器和数据，会设置各种「反爬」手段。常见的有：

  • 请求频率限制：同一 IP 短时间内请求太多，返回 429 或封禁 IP。
  • User-Agent 检测：过滤掉不像真实浏览器的请求头。
  • 验证码 / 登录：需要人机验证或账号权限。
  • JavaScript 动态渲染：内容由 JS 生成，普通请求拿不到。
  • IP 黑名单：把异常 IP 加入黑名单。

遇到反爬，第一反应不应该是「如何绕过」，而是：

  1. 检查自己是否违反了 robots.txt 或请求过频。
  2. 确认目标数据是否有公开的 API 或下载入口。
  3. 如果确实需要，联系网站获取授权。
💡 合法替代品

很多网站提供官方 API、RSS 订阅或数据下载入口。用这些方式获取数据，既稳定又合规。

第 3 小节

请求频率控制

慢一点，大家都舒服

爬虫最怕的就是「太勤快」。一秒钟请求几十次，对小型网站来说就像遭到了攻击。作为有素养的爬虫作者，要主动控制频率。

最常用的方法是每次请求后暂停一段时间：

rate_limit.py
import time
import requests

urls = [
    "https://example.com/page1",
    "https://example.com/page2",
    "https://example.com/page3",
]

for url in urls:
    resp = requests.get(url)
    print(url, resp.status_code)
    time.sleep(2)   # 每次请求后休息 2 秒

此外，建议给请求加上合理的 User-Agent，让服务器知道你是谁、怎么联系：

polite_headers.py
import requests

headers = {
    "User-Agent": "MyLearningBot/1.0 (myemail@example.com)",
}

resp = requests.get("https://example.com", headers=headers)
print(resp.status_code)
🔑 礼貌爬虫三件套

1. 遵守 robots.txt。

2. 控制请求频率，必要时加 sleep。

3. 使用真实、可识别的 User-Agent。

第 4 小节

综合实战

写一个有礼貌的小爬虫模板

实战任务是：写一个「礼貌爬虫模板」，在访问每个页面前，先读取 robots.txt，并保证每次请求之间有固定间隔。模板如下，请把它保存并运行：

polite_spider.py
import time
import requests
from urllib.parse import urljoin

BASE_URL = "https://example.com"      # 练习时请换成允许抓取的公开站点
DELAY = 2                            # 请求间隔秒数

headers = {
    "User-Agent": "MyLearningBot/1.0 (myemail@example.com)",
}

def fetch(path):
    url = urljoin(BASE_URL, path)
    print(f"正在请求：{url}")
    resp = requests.get(url, headers=headers, timeout=10)
    print(f"状态码：{resp.status_code}")
    time.sleep(DELAY)
    return resp

# 先读 robots.txt
robots = fetch("/robots.txt")
print(robots.text[:500])

# 再请求允许访问的页面
# fetch("/allowed-page")

练习任务：把 BASE_URL 换成一个允许抓取的公开网站，先运行上面的模板，确认 robots.txt 内容，再选择允许访问的路径进行请求。观察状态码和响应内容。

🔑 模块 5 小结

✅ robots.txt 是爬虫的道德与法律底线。

✅ 遇到反爬应先反思自身行为，而不是硬绕。

✅ 控制请求频率、使用真实 User-Agent 是基本礼仪。

✅ 合法替代方案（API、RSS、官方下载）通常更好。
