第 1 小节

天气 API 实战

第三方 API 就是别人写好、公开或付费提供的服务。我们不需要知道天气预报怎么算出来，只要按文档说明调用接口，就能拿到结果。

Open-Meteo 是一个免费的天气接口，不需要申请 Key，直接传入经纬度即可。

weather.py
import requests

url = "https://api.open-meteo.com/v1/forecast"
params = {
    "latitude": 39.9,    # 北京大致纬度
    "longitude": 116.4,  # 北京大致经度
    "current_weather": "true"
}

response = requests.get(url, params=params)
data = response.json()

weather = data["current_weather"]
print(f"当前温度: {weather['temperature']}°C")
print(f"风速: {weather['windspeed']} km/h")

注意：免费接口可能有访问频率限制，真实项目中建议先查看服务条款，并处理好网络异常。

第 2 小节

翻译 API 实战

翻译接口通常需要把要翻译的文字作为参数发送。很多公开翻译接口用 GET 或 POST 都可以，下面以 MyMemory API 为例演示 GET 方式。

translate.py
import requests
import urllib.parse

text = "Hello, world!"
encoded = urllib.parse.quote(text)

url = f"https://api.mymemory.translated.net/get?q={encoded}&langpair=en|zh"
response = requests.get(url)
data = response.json()

print("原文：", text)
print("译文：", data["responseData"]["translatedText"])

这里用 urllib.parse.quote 把中文或特殊字符编码成 URL 安全的形式， 避免请求地址里出现空格或标点导致报错。

第 3 小节

AI 接口实战

调用 AI 接口（如 OpenAI、Claude 等）通常需要两个东西： API Key 和 请求体。 API Key 相当于你的身份凭证，必须妥善保管，不要直接写在公开代码里。

ai_chat.py
import requests
import os

# 从环境变量读取 Key，不要硬编码
api_key = os.environ.get("OPENAI_API_KEY")

url = "https://api.openai.com/v1/chat/completions"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}
body = {
    "model": "gpt-3.5-turbo",
    "messages": [{"role": "user", "content": "用一句话解释什么是 API"}]
}

response = requests.post(url, headers=headers, json=body)
print(response.json()["choices"][0]["message"]["content"])

如果还没有 API Key，这段代码无法真正运行，但结构是通用的： 设置请求头、构造 JSON 请求体、解析返回结果。大多数 AI 接口都遵循这套模式。

第 4 小节

综合实战：城市天气速查小工具

输入城市名，返回温度和一句翻译

这个练习把前面三个接口的思路串起来： 先用天气接口查询气温，再用翻译接口把天气描述翻译成英文。 为了简化，天气描述用固定文字，重点练习「组合多个 API 调用」的流程。

city_weather_tool.py
import requests
import urllib.parse

def get_temperature():
    url = "https://api.open-meteo.com/v1/forecast"
    params = {"latitude": 39.9, "longitude": 116.4, "current_weather": "true"}
    response = requests.get(url, params=params)
    return response.json()["current_weather"]["temperature"]

def translate(text):
    encoded = urllib.parse.quote(text)
    url = f"https://api.mymemory.translated.net/get?q={encoded}&langpair=zh|en"
    response = requests.get(url)
    return response.json()["responseData"]["translatedText"]

temp = get_temperature()
desc = f"今天北京气温 {temp} 摄氏度，天气晴朗。"
english = translate(desc)

print("中文：", desc)
print("英文：", english)

在这个项目里，我们分别调用了天气和翻译两个第三方服务，再把结果组合输出。 这正是「站在巨人肩膀上」编程的感觉： 用别人写好的能力，快速搭出自己想要的功能。
