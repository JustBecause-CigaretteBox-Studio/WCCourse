第 1 小节

矩形碰撞

大部分 2D 游戏用矩形作为碰撞框，因为判断两个矩形是否重叠非常快。Pygame 的 Rect 已经内置了 colliderect() 方法。

你可以把两个矩形想象成两张贴纸：只要它们在 x 方向和 y 方向都有重叠，就发生了碰撞。

rect_collision.py
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

a = pygame.Rect(100, 100, 80, 80)
b = pygame.Rect(300, 200, 80, 80)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    b.center = pygame.mouse.get_pos()

    color = (255, 100, 100) if a.colliderect(b) else (100, 200, 255)

    screen.fill((25, 25, 25))
    pygame.draw.rect(screen, color, a)
    pygame.draw.rect(screen, (255, 255, 255), b)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

当白色矩形碰到红色矩形时，红色矩形会变成粉色。这就是 colliderect() 的效果。

第 2 小节

圆形碰撞

有些物体用矩形判断不够精确，比如球体。这时可以用圆心距离来判断：如果两个圆心的距离小于半径之和，就相撞了。

circle_collision.py
import pygame
import math

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

ball1 = {"pos": (200, 300), "r": 40, "color": (100, 200, 255)}
ball2 = {"pos": (500, 300), "r": 40, "color": (255, 255, 255)}

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    ball2["pos"] = pygame.mouse.get_pos()

    dx = ball1["pos"][0] - ball2["pos"][0]
    dy = ball1["pos"][1] - ball2["pos"][1]
    distance = math.sqrt(dx * dx + dy * dy)

    if distance < ball1["r"] + ball2["r"]:
        ball1["color"] = (255, 100, 150)
    else:
        ball1["color"] = (100, 200, 255)

    screen.fill((20, 20, 20))
    pygame.draw.circle(screen, ball1["color"], ball1["pos"], ball1["r"])
    pygame.draw.circle(screen, ball2["color"], ball2["pos"], ball2["r"])
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

小技巧：如果只想比较大小，可以比较「距离的平方」和「半径和的平方」，避免开平方，计算更快。

第 3 小节

碰撞后的反应

检测到碰撞只是第一步，更重要的是「撞了之后怎么办」。常见的反应有：反弹、扣血、消失、得分、播放音效等。

下面我们做一个简单的反弹示例：小球碰到墙壁就反向。

bounce_response.py
import pygame

pygame.init()
screen = pygame.display.set_mode((640, 480))
clock = pygame.time.Clock()

ball = pygame.Rect(50, 50, 30, 30)
speed = [5, 4]

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    ball.x += speed[0]
    ball.y += speed[1]

    if ball.left < 0 or ball.right > 640:
        speed[0] = -speed[0]
    if ball.top < 0 or ball.bottom > 480:
        speed[1] = -speed[1]

    screen.fill((25, 25, 25))
    pygame.draw.ellipse(screen, (255, 220, 100), ball)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

pygame.draw.ellipse() 用矩形作为边界来画椭圆/圆。这里我们让小球在碰到边界时把对应方向的速度反向，实现反弹。

第 4 小节

综合实战：收集金币

做一个简单的收集游戏：玩家控制一个方块去碰金币，碰到后金币消失并加分。这个例子把矩形碰撞和列表操作结合了起来。

collect_coins.py
import pygame
import random

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()
font = pygame.font.SysFont("simhei", 32)

player = pygame.Rect(375, 275, 50, 50)
coins = [pygame.Rect(random.randint(50, 750), random.randint(50, 550), 25, 25)
         for _ in range(8)]
score = 0

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:  player.x -= 5
    if keys[pygame.K_RIGHT]: player.x += 5
    if keys[pygame.K_UP]:    player.y -= 5
    if keys[pygame.K_DOWN]:  player.y += 5

    player.clamp_ip(screen.get_rect())

    new_coins = []
    for c in coins:
        if player.colliderect(c):
            score += 10
        else:
            new_coins.append(c)
    coins = new_coins

    screen.fill((30, 30, 30))
    pygame.draw.rect(screen, (0, 200, 255), player)
    for c in coins:
        pygame.draw.rect(screen, (255, 220, 0), c)

    text = font.render("分数: " + str(score), True, (255, 255, 255))
    screen.blit(text, (20, 20))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()

练习：金币被收集完后，按空格键重新生成；或者让金币随机移动，增加难度。
