第 1 小节

API：程序之间的服务窗口

我们前面一直在说浏览器和服务器对话。其实不只是浏览器，任何两个程序之间都可以对话。A 程序把自己的功能「暴露」出来，B 程序按照规定格式调用，这就是 API（Application Programming Interface，应用程序接口）。

你可以把 API 想象成餐厅的点餐窗口：墙上贴着菜单（API 文档），你告诉服务员要什么菜（请求参数），服务员把菜递出来（返回结果）。你不需要知道厨房怎么炒菜，只需要会看菜单、会点餐。

💡 生活中的 API

手机天气 App 不自己测量气温，而是调用气象部门的 API；地图 App 调用导航 API；支付 App 调用银行 API。API 让不同公司的程序可以互相协作。

Web API 通常基于 HTTP。调用方发送一个 HTTP 请求，服务方返回数据。返回的数据格式有很多，其中最流行的就是 JSON。下一节我们就专门学 JSON。

下面这段代码调用一个公开的测试 API，获取当前 IP 信息（需要联网）：

call_api.py
from urllib.request import urlopen
import json

url = "https://httpbin.org/get"
with urlopen(url, timeout=5) as resp:
    raw = resp.read().decode("utf-8")
    data = json.loads(raw)  # 把 JSON 字符串解析成 Python 字典
    print("状态码：", resp.status)
    print("返回的数据：")
    print(json.dumps(data, indent=2, ensure_ascii=False))

httpbin.org/get 是一个测试接口，它会把你请求里的信息（比如你的公网 IP、浏览器/程序信息）以 JSON 格式返回。注意：如果你的网络无法访问该站点，代码会报错，这是正常的网络限制。

第 2 小节

JSON：程序世界的通用便签

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式。它的语法和 Python 字典非常像：用花括号表示对象，用方括号表示数组，键值对用冒号连接，字符串用双引号。

JSON 之所以流行，是因为它对人类可读、对机器好解析，而且几乎所有编程语言都内置了 JSON 支持。API 返回的数据、配置文件、前后端通信，到处都能看到 JSON。

json_basics.py
import json

# Python 字典 -> JSON 字符串
person = {
    "name": "野鸡动画",
    "age": 3,
    "skills": ["Python", "动画", "网络"],
    "online": True
}
json_str = json.dumps(person, ensure_ascii=False, indent=2)
print("JSON 字符串：")
print(json_str)

# JSON 字符串 -> Python 字典
parsed = json.loads(json_str)
print("\n解析后：", parsed["name"])
print("技能：", parsed["skills"])

注意两个核心函数：

json.dumps()
把 Python 对象（字典、列表等）转成 JSON 字符串，方便保存或发送。
json.loads()
把 JSON 字符串转回 Python 对象，方便程序读取和处理。

ensure_ascii=False 很重要，它让中文字符原样输出而不是变成 \uXXXX 转义。indent=2 则让输出带缩进，方便人类阅读。

第 3 小节

动手：调用 API 并解析 JSON

现在把 API 和 JSON 结合起来：向公开测试接口发请求，拿到 JSON，提取出我们关心的字段。jsonplaceholder.typicode.com 提供了一批假数据，非常适合练手。

parse_api_json.py
from urllib.request import urlopen
import json

url = "https://jsonplaceholder.typicode.com/posts/1"
try:
    with urlopen(url, timeout=5) as resp:
        raw = resp.read().decode("utf-8")
        post = json.loads(raw)

    print(f"用户 ID：{post['userId']}")
    print(f"标题：{post['title']}")
    print(f"正文：{post['body']}")
except Exception as e:
    print(f"请求失败：{e}")

这段代码展示了调用 API 的标准流程：

1. 发请求：用 urlopen 访问 API 地址。

2. 读响应：把服务器返回的字节串解码成文本。

3. 解析 JSON：用 json.loads 转成 Python 字典。

4. 取数据：像操作普通字典一样读取字段。

⚠️ 注意

调用外部 API 需要联网。如果网络不可用，可以使用本地 JSON 字符串练习 json.loads，把 raw 替换成一个写好的 JSON 文本即可。

第 4 小节

综合实战：做一个 API 数据读取器

输入用户 ID，列出该用户的所有文章标题

把前面三节串起来，我们做一个实用小工具：调用 JSONPlaceholder 的 API，根据用户 ID 获取该用户发布的所有文章，并打印标题。你还可以把它改成保存到本地 JSON 文件，或者做成交互式程序。

api_reader.py
from urllib.request import urlopen
import json

def fetch_posts_by_user(user_id):
    url = f"https://jsonplaceholder.typicode.com/posts?userId={user_id}"
    print(f"正在获取用户 {user_id} 的文章...")
    try:
        with urlopen(url, timeout=5) as resp:
            raw = resp.read().decode("utf-8")
            posts = json.loads(raw)
        return posts
    except Exception as e:
        print(f"请求失败：{e}")
        return []

if __name__ == "__main__":
    uid = 1  # 可以改成 input("请输入用户 ID：")
    posts = fetch_posts_by_user(uid)
    print(f"\n共找到 {len(posts)} 篇文章：\n")
    for post in posts:
        print(f"- {post['title']}")

这个程序用到了 URL 参数：?userId=1 告诉服务器「只返回用户 1 的数据」。这是 Web API 最常见的过滤方式之一。

如果你想让它离线也能演示，可以把请求部分注释掉，直接用一个写好的 JSON 字符串赋给 raw，然后再解析。这样在没有网络的环境里也能练习 JSON 解析逻辑。

🔑 模块 5 小结

API 是程序之间的服务窗口；JSON 是程序之间交换数据的通用便签格式。Python 用 json.dumps/loads 处理 JSON，用 urllib 调用 HTTP API。掌握了这两个工具，你就可以让程序去互联网上「点餐」了。
