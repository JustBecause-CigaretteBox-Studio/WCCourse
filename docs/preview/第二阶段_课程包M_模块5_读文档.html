第 1 小节

为什么读文档是程序员的必修课

写代码不是背代码。现实世界里有成千上万的库和接口，没人能记住所有函数的名字和参数。 学会读文档，就像学会看说明书：拿到一个新工具，先看它能干什么、怎么用，再去动手。

以 requests 为例， 你可能已经会 requests.get(url)， 但文档里还告诉你怎么加请求头、设置超时、处理 Cookie、上传文件等等。这些功能不需要死记硬背，用的时候查文档即可。

好的文档通常分为几个部分：

  • Quick Start / 快速开始：用最短代码让你跑起来。
  • API Reference / API 参考：每个函数、每个参数的详细说明。
  • Examples / 示例：常见场景的完整代码。
第 2 小节

文档里应该看什么

拿到一个陌生库的文档，不要从头到尾读。先问自己三个问题：

  • 这个库是干什么的？
  • 最简单的用法是什么？
  • 我现在要用的功能，对应哪个函数或类？

然后按下面顺序翻阅：

doc_reading.py
# 以 requests 文档中的 timeout 参数为例
# 文档告诉我们：可以给 get/post 传 timeout，单位是秒

import requests

# 如果 3 秒内没有响应，就抛出异常
response = requests.get("https://api.example.com", timeout=3)
print(response.status_code)

读文档时，重点关注函数签名： requests.get(url, params=None, headers=None, timeout=None, ...)。 括号里的名字就是你能调整的参数。

第 3 小节

快速上手的「复制-修改」法

新手读文档最高效的方法不是硬啃，而是： 找到一段能运行的示例 → 复制到本地 → 改成自己需要的样子。

比如 requests 文档里有一段「发送 JSON POST 请求」的例子，你可以复制下来，把 URL 和 JSON 内容换成自己的接口。

copy_modify.py
import requests

# 这是从文档里改出来的示例
url = "https://httpbin.org/post"
headers = {"User-Agent": "my-app/1.0"}
payload = {"name": "xiaoming", "age": 18}

response = requests.post(url, headers=headers, json=payload)
print(response.status_code)
print(response.json()["json"])

每次修改一个参数，运行一次，观察结果。这样即使报错，也很容易定位是哪一步出了问题。

第 4 小节

综合实战：照着文档下载一张图片

学会查、复制、改、运行

这个实战任务是：使用 requests 从网络下载一张图片，并保存到本地。 步骤全部来自 requests 官方文档的相关章节。

download_image.py
import requests

url = "https://picsum.photos/400/300"
response = requests.get(url)

# 检查状态码，确保请求成功
if response.status_code == 200:
    # 图片是二进制数据，用 content 获取
    with open("downloaded.jpg", "wb") as f:
        f.write(response.content)
    print("图片已保存为 downloaded.jpg")
else:
    print("下载失败，状态码：", response.status_code)

关键要点：

  • 文本数据用 response.text。
  • 图片、音频等二进制数据用 response.content。
  • 保存二进制文件时，打开模式要用 "wb"。

运行后，在项目文件夹里会多出一个 downloaded.jpg， 这就是你按文档操作的成功证明。
