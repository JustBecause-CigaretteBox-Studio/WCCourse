HTML：网页的骨架

标签、结构、语义化

开始模块 1 第 1 小节 → 模块 1 · 4 个小节 · 进度自动保存
第 1 小节

标签

HTML 是 HyperText Markup Language 的缩写，翻译成中文就是「超文本标记语言」。你可以把它理解成网页的骨架：它决定了页面上有什么内容，以及这些内容是什么关系。

HTML 用「标签」来标记内容。标签通常成对出现：一个开始标签，一个结束标签，中间包裹内容。比如下面这段代码会用大字号显示一句话：

index.html
<h1>欢迎来到我的网站</h1>
<p>这是我写的第一个网页。</p>

<h1> 是「一级标题」标签，<p> 是「段落」标签。浏览器看到这些标签，就知道「哦，这里是一段文字，那里是一个大标题」。

除了文字，标签还能放链接、图片、列表等。下面这张「常用标签速查卡」可以先收藏起来：

常用标签速查
<!-- 标题：h1 最大，h6 最小 -->
<h1>大标题</h1>
<h2>小标题</h2>

<!-- 段落与换行 -->
<p>这是一段文字。</p>
<br>  <!-- 单独使用，表示换行 -->

<!-- 链接与图片 -->
<a href="https://example.com">点我跳转</a>
<img src="photo.jpg" alt="描述文字">

<!-- 无序列表 -->
<ul>
  <li>第一项</li>
  <li>第二项</li>
</ul>

你可以把标签想象成给内容贴便利贴：这张便利贴上写「这是标题」，那张写「这是图片」。浏览器按照便利贴的指示，把内容组织成完整的页面。

第 2 小节

结构

来看这个HTML文档。

一份完整的 HTML 文档
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的第一个网站</title>
</head>
<body>
  <h1>你好，世界！</h1>
  <p>这是我的第一个网页。</p>
</body>
</html>

每个部分都有明确分工：

  • <!DOCTYPE html>：告诉浏览器「这是 HTML5 文档」。
  • <html>：整个文档的根容器。
  • <head>：放浏览器看的信息，比如标题、字符编码、样式引用。
  • <body>：放用户看的内容，比如标题、段落、图片。

标签还需要正确嵌套：外套不能穿在内衣里面。结束标签的顺序要和开始标签相反：

正确的嵌套
<!-- 正确：先开始 p，再开始 strong，先结束 strong，再结束 p -->
<p>这句话里<strong>有一部分加粗</strong>。</p>

<!-- 错误：标签交叉了 -->
<p>这句话里<strong>有一部分加粗</p></strong>

把这段代码保存为 .html 文件，然后用浏览器打开，你就能看到自己的第一个网页了。

第 3 小节

语义化

网页不仅给浏览器看，也给搜索引擎、屏幕阅读器和未来的你自己看。语义化就是选择「有含义」的标签，让任何人（包括机器）一眼就知道这块内容是什么。

比如下面两种方式都能显示一个页面头部，但语义化写法更清楚：

div 写法 vs 语义化写法
<!-- 没有语义：全是 div，只能靠 class 猜 -->
<div class="header">
  <div class="nav">...</div>
</div>
<div class="main">...</div>
<div class="footer">...</div>

<!-- 语义化写法：标签本身就说明作用 -->
<header>
  <nav>...</nav>
</header>
<main>...</main>
<footer>...</footer>

常用的语义化标签有：

  • <header>：页面或区块的顶部。
  • <nav>：导航链接区域。
  • <main>：页面的主要内容。
  • <section>：一个主题区块。
  • <article>：一篇独立的文章。
  • <footer>：页面或区块的底部。

语义化不会立刻让页面变漂亮（那是 CSS 的工作），但它让页面更容易维护、更容易被搜索引擎理解，也更方便视障用户通过屏幕阅读器浏览。

第 4 小节

综合实战

用纯 HTML 写一张自我介绍页

现在把前三节的内容串起来：用纯 HTML 写一张「自我介绍页」。先不要管好不好看，重点是结构正确、标签用得恰当。

about-me.html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>关于我</title>
</head>
<body>
  <header>
    <h1>我是阿杰</h1>
    <p>一个正在学习网页开发的新手</p>
  </header>

  <main>
    <section>
      <h2>我的兴趣</h2>
      <ul>
        <li>编程</li>
        <li>动画</li>
        <li>跑步</li>
      </ul>
    </section>

    <section>
      <h2>我的目标</h2>
      <p>学完这个课程包后，做出自己的<strong>个人作品集网页</strong>。</p>
    </section>
  </main>

  <footer>
    <p>联系方式：<a href="mailto:example@email.com">example@email.com</a></p>
  </footer>
</body>
</html>

实战任务：

  1. 把上面的代码复制到记事本或 VS Code 中。
  2. 把「阿杰」改成你的名字，把兴趣和目标换成你自己的。
  3. 保存为 about-me.html，双击用浏览器打开。
  4. 尝试再添加一个 <section>，比如「我喜欢的项目」或「我正在学的技术」。
