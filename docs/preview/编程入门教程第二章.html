第 2 章 · 函数与数组

把功能打包

上一章我们让电脑算出了 a + b。这一章解决一个新问题： 同一段功能要用上成百上千次时，怎么办？答案是把功能 打包成函数，顺便认识一下能装下一排数据的 数组。

第 1 小节

回忆：a + b 的老朋友

重复的烦恼

回忆上一章的 a + b 问题：现在你已经学会了如何把两个数加在一起—— 读入 a 和 b，算出 a + b，把结果输出来。 

int a, b;
cin >> a >> b;
cout << a + b;
a = int(input())
b = int(input())
print(a + b)

然而这只是一个很小的功能。在实际的大型项目中， 这样的小功能会被成百上千次地使用。

想象一下：如果每用一次「两数相加」，都要把这几行代码重新写一遍——

// 第 1 次：算两个数的和
int a1, b1;
cin >> a1 >> b1;
cout << a1 + b1;

// 第 2 次：再算两个数的和
int a2, b2;
cin >> a2 >> b2;
cout << a2 + b2;

// 第 3 次：……
// 第 1000 次：😵
# 第 1 次：算两个数的和
a1 = int(input())
b1 = int(input())
print(a1 + b1)

# 第 2 次：再算两个数的和
a2 = int(input())
b2 = int(input())
print(a2 + b2)

# 第 3 次：……
# 第 1000 次：😵

先不说写起来有多累——如果哪天需求变了，比如「加法之前先检查一下输入是否合法」， 你就得把这一千处挨个改一遍。漏掉一处，就是一个 bug。

面对「同一个东西要反复使用」的情况，人类的通用做法是什么？ 下一小节我们会从一个意想不到的例子——DNA——里找到答案。

🔑 简写的本质

简写，就是给一个反复出现的东西起一个短名字。 名字背后是什么不重要，重要的是：用的时候写名字就行。

第 3 小节

函数：把功能打包

参数与返回值

同样地，对于代码中重复使用的功能，我们通常将它们封装为一个函数。

其实，函数的英文 function，翻译为「功能」更加易于理解： 一个函数，就是一个被打包好的、可以随时取用的功能。

我们先来试着封装一个函数——把上一章的「两数相加」打包起来：

int a_plus_b(int a, int b) {
    return a + b;
}
def a_plus_b(a, b):
    return a + b

这三行（Python 是两行）包含了函数的全部要素。逐个拆开看：

函数名：a_plus_b
给这个功能起的「短名字」，就像给 DNA 起名字一样。以后想用这个功能，喊它的名字就行。
参数：(int a, int b) / (a, b)
功能运转需要的「原料」。这个函数需要两个整数才能干活，所以括号里写着 a 和 b。 调用它的时候，把具体的数塞进来。当然，函数可以没有参数，返回值也一样
返回值：return a + b
功能干完活之后「交回来」的结果。return 的意思是： 算出 a + b，把这个结果交还给调用它的人，然后函数结束。 最前面的 int 是在声明：这个函数交回来的结果是一个整数。

封装好之后，「两数相加」这个功能就变成了一行调用：

int result = a_plus_b(3, 4);
cout << result;
▶ 运行结果
7
result = a_plus_b(3, 4)
print(result)
▶ 运行结果
7

a_plus_b(3, 4) 的意思是： 把 3 和 4 作为参数交给 a_plus_b，等它算完，把返回值拿回来。 至于里面具体怎么加的——不用关心，就像用 DNA 三个字母时不用念全称一样。

别光看，下面这个运行台里已经封装好了 a_plus_b，直接调用它试试：

🖥️ 迷你运行台 —— cout << a_plus_b(a, b); 🖥️ 迷你运行台 —— print(a_plus_b(a, b))
函数的返回值：
调用 a_plus_b(20, 22)，返回值是多少？
🔑 第 3 小节小结

1. 函数 = 打包好的功能，英文 function 翻译成「功能」更贴切。

2. 三要素：名字（怎么喊它）、参数（给它什么原料）、返回值（它交回什么结果）。

3. 用的时候写 函数名(参数)，这一整坨会被替换成返回值。

第 4 小节

没有返回值的函数

只做事情，不交回结果

上一小节的函数都像一台"计算器"：输入原料，加工后交回一个结果。 但生活中还有很多函数不需要交回结果，它们只是把事情做完。

比如，每天早上闹钟响了，你不需要它"返回"一个值，只需要它响铃； 打印机打印文件，也不需要返回数字，只需要把纸印出来。

💡 想一想

下面这些功能，哪些需要返回结果，哪些只是"做事情"？
计算圆的面积 · 把一段文字显示在屏幕上 · 判断一个数是不是偶数 · 播放一段音乐

代码里也有同样的区分，C++用void表示函数没有返回值，Python更加简便，函数里不写return即可。下面这个函数只是向屏幕打一声招呼，不需要返回任何值：

#include <iostream>
using namespace std;

void say_hi(string name) {
    cout << "你好，" << name << "！" << endl;
}
def say_hi(name):
    print("你好，" + name + "！")

调用它的时候，不需要用变量接住返回值，直接写函数名：

int main() {
    say_hi("小明");
    say_hi("小红");
    return 0;
}
▶ 运行结果
你好，小明！
你好，小红！
say_hi("小明")
say_hi("小红")
▶ 运行结果
你好，小明！
你好，小红！

在 C++ 里，这种不返回值的函数用 void 开头，意思是"空"。 在 Python 里，函数可以没有 return 语句，函数执行完就自然结束。

再来看一个"画分隔线"的函数：输入一个数字，打印那么多个横线。

void print_line(int n) {
    for (int i = 0; i < n; i++) {
        cout << "-";
    }
    cout << endl;
}
def print_line(n):
    for i in range(n):
        print("-", end="")
    print()
print_line(10);
print_line(10)
▶ 运行结果
----------
🔑 有返回值 vs 没有返回值

有返回值：等效为一个变量，调用它是为了拿到结果，通常用变量接住。

没有返回值：等效为一串代码，调用它是为了让它完成某件事，不需要接结果。

下面哪个函数没有返回值？
void show_time(int h, int m) {
    cout << h << ":" << m;
}

int double_it(int x) {
    return x * 2;
}
def show_time(h, m):
    print(str(h) + ":" + str(m))

def double_it(x):
    return x * 2
第 5 小节

再来一个函数

二进制，反码和 ones_complement 函数

刚刚我们封装了a_plus_b函数，但是你可能发现：a_plus_b(1,1)甚至没有直接写1+1方便

这是因为刚才只是向你演示如何封装函数，实际上计算加法这个功能过于简单，没有必要封装为函数

我们再来完成一个更复杂的功能，体验函数是如何简化代码的


我们日常最熟悉的是十进制，逢十进一。但电脑内部只认 0 和 1，也就是二进制。

💡 十进制 vs 二进制

十进制的 13 表示 1×10^1 + 3×10^0。
二进制的 1101 表示 1×2^3 + 1×2^2 + 0×2^1 + 1×2^0
（问问AI ^ 是什么意思，或者自己猜出来）
同一个数，写法不同，但值可以相同。

计算机里表示负数的方式有好几种。我们先看最直观的一种，叫反码（one's complement）： 把二进制每一位上的 0 换成 1、1 换成 0，就得到了反码。

ones_complement：输入十进制，输出反码的十进制

现在我们要写一个函数 ones_complement(x)： 输入一个十进制数 x，输出它的二进制数的反码对应的十进制数，按下面三步得到结果：

  1. 把 x 转成二进制：有多少位就算多少位，逐位取出 0 或 1
  2. 把每一位取反：0 变 1，1 变 0
  3. 把取反后的二进制重新转回十进制并返回
int ones_complement(int x) {
    if (x == 0) return 1;
    int result = 0;
    int place = 1;
    while (x > 0) {
        int bit = x % 2;        // 第 1 步：取出最低位的二进制数字
        int flipped = 1 - bit;  // 第 2 步：取反
        result = result + flipped * place;  // 第 3 步：拼到结果里
        x = x / 2;
        place = place * 2;
    }
    return result;
}
def ones_complement(x):
    if x == 0:
        return 1
    result = 0
    place = 1
    while x > 0:
        bit = x % 2        # 第 1 步：取出最低位的二进制数字
        flipped = 1 - bit  # 第 2 步：取反
        result = result + flipped * place  # 第 3 步：拼到结果里
        x = x // 2
        place = place * 2
    return result
⚠️ 注意

这里只处理非负整数。0 比较特殊：它的二进制只有一位 0，取反后是 1，所以返回 1。

来试试看——输入一个十进制数，看它生成的反码再转回十进制是多少：

🖥️ 迷你运行台 —— cout << ones_complement(x); 🖥️ 迷你运行台 —— print(ones_complement(x))
反码转回十进制的结果：
ones_complement(13) 的返回值是多少？

像这样我们就成功封装了一个生成反码的函数。以后使用只需要写一行ones_complement(x)调用这个函数，不再需要写很多行代码。

💡 扩展函数的功能

其实你还可以扩展函数功能，例如给函数多加一个参数numeral_base，表示输入的数字是几进制的，这样就可以计算任意进制数的反码了。 例如也可以再加一个参数numeral_out，表示输出的反码是几进制的。

第 6 小节

数组：一排编好号的格子

下标从 0 开始

函数解决的是「功能重复」的问题。但数据也有类似的烦恼—— 假设要记录一个小组 5 位同学的成绩，难道要起 5 个变量名？ 

int score1 = 83;
int score2 = 92;
int score3 = 77;
int score4 = 88;
int score5 = 95;
// 如果一个班有 50 个人呢……
score1 = 83
score2 = 92
score3 = 77
score4 = 88
score5 = 95
# 如果一个班有 50 个人呢……

和函数的思路一样：把一排同类的数据打包，起一个名字。 这个打包好的「一排格子」，叫做数组，Python 中称为列表 

int scores[5] = {83, 92, 77, 88, 95};
scores = [83, 92, 77, 88, 95]

它长这样——5 个格子排成一排，每个格子有自己的编号：

83
scores[0]
92
scores[1]
77
scores[2]
88
scores[3]
95
scores[4]
⚠️ 易错点：编号从 0 开始

数组格子的编号（术语叫「下标」）是从 0 开始的，不是 1。 所以第一个格子是 scores[0]，第五个格子是 scores[4]。 至于 scores[5]——这个格子不存在，强行访问就会出错。

取数据的方式是 scores[下标]。 比如 scores[2] 就是 77。来亲手取一下：

🖥️ 迷你运行台 —— cout << scores[i];（scores = {83, 92, 77, 88, 95}） 🖥️ 迷你运行台 —— print(scores[i])（scores = [83, 92, 77, 88, 95]）
结果：
scores[0] + scores[4] 等于多少？

数组里的类型规矩

在 C++ 里，这一排格子有一个严格的规矩：一整排必须是同一种类型。 int scores[5] 这排格子就只能装 int， 想装小数得换成 double scores[5]。

为什么要这么严格？因为电脑取 scores[2] 时，用的是一条捷径： 第一个格子的位置 + 2 × 每个格子的大小，直接跳过去拿。不同格子大小不一样。 int 格子每个占 4 个字节，double 格子每个占 8 个字节—— 只有整排格子大小完全一致，这条捷径才算得出来。这也是数组取数据飞快的原因。 

int a[3] = {1, 2, 3.9};      // 3.9 硬塞进 int 格子：砍掉尾巴
double b[3] = {1, 2, 3.9};   // double 格子：相安无事
string c[2] = {"小明", "小红"}; // 装文字就用 string 数组

cout << a[2] << "\n";   // 不是 3.9，也不是 4
cout << b[2] << "\n";
cout << c[1];
▶ 运行结果
3
3.9
小红
⚠️ 类型注意事项（C++）

1. 创建数组时类型就定死了，整排必须一致，不能这一格 int、下一格 string。

2. 小数塞进 int 数组会被砍掉尾巴（3.9 变 3，不是四舍五入）。

3. 选类型时想清楚这排格子要装什么：成绩用 int，单价用 double，名字用 string。

列表的格子什么都能装

Python 的格子会「自动认货」，所以列表没有 C++ 那样的严格规矩—— 同一排里可以混装不同类型的东西： 

bag = [18, 3.14, "小明"]   # 整数、小数、文字，混装也没问题

print(bag[0])
print(bag[2])
▶ 运行结果
18
小明

不过要注意：能混装，不代表该混装。 实际写程序时，一排列表通常还是装同类数据（比如一排成绩、一排名字）， 处理起来才不容易乱。

列表还有几个常用本领，记住这四个就够用：

scores = [83, 92, 77]

scores.append(88)     # 往排尾再加一个格子
print(len(scores))    # len：数数有几个格子
print(scores[0])      # 取下标：看第一个格子

scores[0] = 90        # 改格子：把 83 换成 90
print(scores)
▶ 运行结果
4
83
[90, 92, 77, 88]
⚠️ 类型注意事项（Python 列表）

1. 列表可以混装类型，但同排装同类数据更不容易出错。

2. len(scores) 是格子个数，最后一个合法下标是 len(scores) - 1。

3. append 加在排尾，下标会随着格子变多而往后顺延。

字典：带名字的格子

列表靠「编号」找格子。但生活中我们常常是靠「名字」找东西的—— 比如查通讯录：你不会说「第 137 个联系人是谁」，而是说「小明的电话是多少」。 这种按名字找格子的结构，叫做字典。 

phone = {"小明": "13800000001", "小红": "13800000002"}

print(phone["小明"])        # 按名字取格子

phone["小刚"] = "13800000003"  # 存一个新格子
phone["小明"] = "13900000001"  # 改格子里的东西

print("小红" in phone)      # 查一查这个名字在不在
print(len(phone))           # 字典里有多少个格子
▶ 运行结果
13800000001
True
3

字典里的「名字」叫键，格子里装的东西叫值，一对键值（键值对）就是一个格子。

⚠️ 易错点：取不存在的键会报错

phone["小王"] 如果「小王」还没存进去，程序会直接报错（KeyError）。 取之前先用 "小王" in phone 问一句，就安全了。

什么时候用列表

数据是一排有顺序的东西：成绩表、购物车、排行榜。 按位置（第几个）取用。

什么时候用字典

数据是一堆带名字的东西：通讯录、商品价格、用户信息。 按名字（键）取用。

小试牛刀：下面程序的输出是什么？
phone = {"小明": "138"}
phone["小红"] = "137"
phone["小明"] = "139"
print(phone["小明"], len(phone))
🔑 第 6 小节小结

1. 数组/列表 = 一排编好号的格子，装一排同类的数据，共用一个名字。

2. 取数据用 名字[下标]，下标从 0 开始，合法下标是 0 ~ 个数-1。

3. C++ 数组整排必须同一种类型（靠统一格子大小才能按捷径取数据）；小数塞进 int 数组会被砍尾巴。

3. Python 列表可以混装类型，但建议同排装同类；append 加排尾，len 数格子。

4. Python 字典按「名字（键）」找格子：存、改、取、in 检查；取不存在的键会报错。

第 8 小节

注释与伪代码

先想清楚再写

写程序的时候，我们不仅要让电脑看懂，也要让以后的自己看懂。 注释就是写在代码里的说明，电脑会跳过它，但人可以读懂。 

// 这是单行注释：说明下面这行在做什么
int score = 85;

/*
  这是多行注释。
  可以写好几行，用来解释一段代码的整体思路。
*/
int bonus = 10;
# Python 里用井号开头表示注释
score = 85

# 也可以写在代码后面，解释这行的作用
bonus = 10  # 额外加分

好的注释通常不写「这句在做什么」——因为代码本身已经说明了。 更好的注释写「为什么要这样做」，或者把一大段代码的意图概括出来。

💡 想一想

下面两段代码，哪一段更容易看懂？ 

int a = 10;
int b = 20;
int c = a + b;
a = 10
b = 20
c = a + b
// 计算语文和数学的总分
int chinese = 10;
int math = 20;
int total = chinese + math;
# 计算语文和数学的总分
chinese = 10
math = 20
total = chinese + math

除了注释，还有另一种常用的工具：伪代码。 伪代码不是真正的程序，而是用接近自然语言的方式，把解题步骤先写下来。

比如，要计算 1 到 100 的和，可以先用伪代码描述：

1. 准备一个变量 sum，初始值为 0
2. 让 i 从 1 走到 100
3. 每次把 i 加到 sum 里
4. 循环结束后，输出 sum

把伪代码翻译成真正的代码，就清晰多了。 遇到复杂问题时，先写伪代码再写代码，能大大减少出错。

🔑 这一小节的核心

注释是给人看的说明，电脑会忽略。

好注释解释「为什么」，而不是重复「做什么」。

伪代码是用自然语言描述的解题步骤，写代码之前先想清楚。
